问题解决#

请先确认与症状相符的项目。如果难以找到设置，可以在顶部的放大镜里搜索名称。

启动与角色#

症状 首先尝试的方法
启动不顺利 按住 Shift 启动，以使用无摄像头、无麦克风的安全模式。
文件显示已更改 将购买时收到的原始 ZIP 文件解压到新文件夹中并运行。
角色不可见 按脸部、上半身、全身的构图重新调整。
部分呈现粉色 检查原始 Unity 项目的材质和着色器后再导出。
头发纠结 点击顶部的初始化按钮。

脸部与手部#

症状 首先尝试的方法
摄像头无法开启 检查是否有其他应用在使用摄像头。
角色不动 在“设备 → 追踪源”中确认各部位是否使用实际连接的设备。
脸部方向偏斜 面向正前方，点击正面校正。
眨眼无效 单独更改眨眼方式。
表情过大或过小 进行自动脸部设置或调整脸部敏感度。
手指抖动 适当提高手部抖动校正。
伸手时手臂会扭曲 关闭实验性的手部深度估计，并与之前的手臂方式进行比较。
不会变为空闲姿势 指定空闲姿势，并在菜单 → 基本·AFK 姿势中确认等待时间。
连接 iPhone 后没有反应 确认手机应用是否发送到 PC 地址，并从正面开始校准。
VMC 姿势错位 检查输入状态，并调整到 T 姿势·对齐。

OBS 与视频输出#

症状 先尝试的操作
没有 Spout2 Capture 安装 OBS 用的 Spout2 插件后重新启动 OBS。
没有 NDI Source 安装 DistroAV 和该版本要求的 NDI Runtime。
背景显示为黑色 将 Avatar Live 背景设为透明，OBS 源使用 Alpha 合成。
更改传输名称后没有显示 在 OBS 源中重新选择新名称。
虚拟摄像头不在列表中 注册设备后，完全重新启动接收应用。
我的屏幕与广播构图不同 确认传输目标是场景视图还是工作室摄像头。

详细安装顺序请查看 输出。

屏幕共享#

  • 在 Discord 列表中找不到：打开屏幕共享，在应用程序选项卡中查找 Avatar Live Share Output。
  • 游戏画面变黑：尝试将游戏切换为无边框窗口模式。
  • 共享无声音：请检查音频目标和应用音量。如有虚拟音频设备提示，请参考 VB-CABLE 指南。
  • 通话声音又能听到：请确认要分享的应用中是否包含 Discord。

远程联播#

联播会话位于直播 → 连接的最下方。首先确认房主是否开启了服务器，以及参加的地址、端口、密码是否正确。如果外部的朋友无法连接，请展开查看连接不上时的端口转发和防火墙指南。

如果对方看起来像替代化身，请确认查看化身和数据传输同意。无法传输的模型请作为替代化身使用。

直播联动无法使用时#

直播联动是测试版 (Beta)。事件到来但角色没有反应时，请依次确认。

  1. 在直播 → 连接中，确认该平台的卡片显示已连接。登录失效时，关闭再打开开关重新登录。
  2. 在直播 → 互动中，确认该条目的开关已开启，触发的最低金额·奖励标题正确。
  3. 用条目的 ▶ 测试，看看是否出现反应。测试也没有反应时，请检查动作设置（物体·图片是否为空）。
  4. 在冷却时间内再次到来的相同事件不会运行。
  5. Discord 需要应用正在运行，并且频道在已连接的频道列表中。朋友看到“已关闭”时，说明应用或 Discord 开关处于关闭状态。

仍然不行时，请在问题发生后立即通过设置 → 诊断 → 发送错误报告告诉我们。报告中包含以下内容，便于追查原因。

  • 各平台·Discord 连接的状态记录（断开原因和代码）、登录权限、订阅响应、失败的请求
  • 最近 16 个事件，以及简易设置条目·图对每个事件做了什么，或为什么没有做

诊断资料中会隐藏令牌·认证标头·Cookie·代码·会话密钥·订单号·电子邮件·文件路径。报告只在用户选择发送时才会传送。

当屏幕变慢或模糊时#

  1. 尝试降低输出分辨率和FPS。
  2. 减少多视图的刷新率和格数。
  3. 关闭未使用的摄像头的 Spout2 输出。
  4. 一一尝试关闭环境光遮蔽、景深、体积光等效果。
  5. 如果整体模糊，请检查 Bloom 强度·阈值和模糊。

如果无法解决#

在 设置 → 诊断 → 发送错误报告 中填写以下内容。

  • 按了哪个按钮或更改了哪些设置
  • 出现了什么异常情况
  • 使用的设备和角色类型
  • 再次出现相同问题的顺序

实际发送将在用户选择时进行。

支持范围#

  • .vavatar 和 VRM 0.x·1.0 角色
  • 角色的表情菜单、动画器、PhysBone 等支持的功能
  • 包含在角色中的面部追踪设置和表情
  • 摄像头、麦克风、iPhone、VMC 输入

某些 VRM 0.x 的特殊着色器可能不受支持。应用中实验性显示的功能可能因设备和环境不同而产生不同的结果。
