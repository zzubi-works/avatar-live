Windows 版 VTuber 软件

让 VRChat 角色
原样成为 VTuber#

无需转换为 VRM。无需重新设置着色器、摆动骨骼、表情菜单和服装开关。
你在 VRChat 中看到的角色会随摄像头和麦克风动起来，并直接输出到 OBS、Discord 和 Zoom。

在 BOOTH 购买 开始阅读指南 →

以往的做法#

大多数免费 VTuber 软件以 VRM 格式 为基础。要使用 VRChat 角色，必须先转换为 VRM，重新制作着色器，并重新设置摆动骨骼、表情和服装开关。结果，在 VRChat 中看到的角色与直播中出现的角色并不一样。 而且每次修改角色都要重复这一过程。

Avatar Live 的不同之处#

🎨

原有着色器原样使用#

Poiyomi、lilToon 等角色所用的着色器无需更换，直接使用。

💇

PhysBone 原样使用#

头发、裙子、尾巴的摆动与 VRChat 设置相同。还可以用鼠标拉拽并固定姿势。

📋

表情菜单原样使用#

VRChat Expression 菜单中的开关、按钮、Radial、Puppet，手势表情，以及 Contact 和 Parameter Driver 均可运行。

🙂

面部追踪自动对接#

直接使用角色自带的面部追踪设置。按引导操作即可完成自动面部设置。

⌨️

桌面手部动作#

即使摄像头看不到手，角色也会配合真实的键盘和鼠标打字。不会记录输入的内容。

🎮

Discord 中的游戏 + 角色#

无需 OBS，即可在 Discord 屏幕共享中合成游戏与角色并发送。你自己只看到游戏。

一览对比#

基于 VRM 的软件（一般情况） Avatar Live
角色准备 VRM 转换 + 重新设置着色器、摆动和表情 导出器一键完成
着色器 常需更换为 VRM 用着色器 原有着色器原样使用
摆动骨骼 用 SpringBone 重新设置 PhysBone 原样使用
服装、发型开关和表情菜单 大多需要重新制作 VRChat 菜单原样使用
FX 动画器、Contact 机关 无法运行 可以运行
反映角色修改 从转换开始重做 只需重新导出
