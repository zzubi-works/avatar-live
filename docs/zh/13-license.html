许可证使用条件（摘要）#

  • 许可证为 一人一台设备。
  • 转移到其他电脑 仅限一次。转移后之前的电脑将无法使用，之后无论任何情况都无法再次转移（即使联系我们也无法为您转移）。
  • 激活和许可证确认需要连接互联网。
  • 禁止再分发、销售、出租、共享、逆向工程、修改以及规避许可证确认。

完整条件以 使用条款 为准。

升级与试用版#

  • Basic → Pro 升级：在 BOOTH 购买 升级（Upgrade） 商品，并在使用 Basic 的电脑上于 设置 › 许可证 › 升级到 Pro 中输入，即可将此电脑的许可证升级为 Pro。合并后的购买归属于此许可证，不能在其他电脑上单独使用。单独注册升级商品时可作为 Basic 使用；已是 Pro 的电脑无法输入。
  • 在试用期间购买时，请在 设置 › 许可证 › 输入购买的代码 中输入。购买的许可证将取代试用版。
  • 试用期结束后，会显示"试用期已结束"的提示和输入界面。如需继续使用，请输入购买的许可证。

实验性功能#

标记为“实验性”的功能（Ultraleap、OSC·VMC、舌头与脸颊的摄像头检测）预计能够正常运行，但这些设备和应用尚未在开发者环境中测试。

自己制作的文件#

  • 用导出器制作的 .vavatar / .vprop 文件归用户所有。其中角色、服装和着色器的权利归各自的制作者所有，共享时请遵守原制作者的条款。
  • 直播和视频中出现的角色，其使用条件也请遵守各制作者的条款。

独立性声明#

Avatar Live 和 Avatar Exporter 是 由 Curious Bobby Co. 独立开发的软件。

  • 不使用或包含 VRChat SDK 的代码，也不分发 VRChat SDK。
  • 不包含或分发 NDMF、Modular Avatar、VRCFury 等角色制作工具。 这些工具是用户自行安装到自己项目中，并在用户环境中运行的。
  • 不与 VRChat 服务器或账号通信，也没有获取他人角色的功能。
  • 本产品并非与 VRChat Inc. 或各工具开发者合作或经其认可的产品。
