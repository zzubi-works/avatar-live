更新记录#

Avatar Live各版本的更新内容，按最新版本优先排列。

2026/10/11 — v1.1.0#

  • MediaPipe 摄像头接收： 改进了UDP数据包接收及跟踪丢失、重启时的处理，避免把重复或过时的检测结果当作新的动作。
  • 手臂和手腕稳定性： 调整了跟踪时间戳、肩部基准点、手肘方向和手腕修正，以减少报告过的严重手臂抖动。实际效果可能因摄像头和环境而异。
  • 基础姿势与等待姿势分离： 可以分别设置正常使用时的基础姿势和跟踪中断时的等待姿势。重新检测到动作后恢复跟踪，手动应用的姿势优先。
  • 等待表情： 可将保存在 我的表情 中的表情设置为跟踪丢失时的等待表情，也可以不设置等待姿势、只应用表情。
  • 摄像头手部前伸（实验性）： 增加了利用摄像头视场角（FOV）和身体尺寸估算手部深度，以及按摄像头和分辨率保存校准的功能。
  • 设置与更新可靠性： 改进配置保存顺序、失败后的恢复，以及更新中断时的文件还原处理。
  • Discord 屏幕共享音频： 缺少可用的虚拟音频设备时显示警告与 安装虚拟音频驱动 按钮。经用户同意后，可以安装由VB-Audio开发的 VB-CABLE；已有兼容设备则无需安装。请参阅安装、许可和捐助说明。

手部深度估算仍是开发中的实验性功能，可能不稳定。 虽可减少手臂抖动，但也可能使正常手臂动作不自然，甚至导致手臂或手腕扭曲。如遇此问题，请在 动作 › 手部 › 摄像头手部前伸 › 深度估算 中将其 关闭。实际摄像头环境下的验证与改进仍在进行中。

2026/10/11 — v1.0.10#

  • 改善了 PhysBone 的部分过度运动。本次修复是临时改善，后续计划继续改进。
  • 正在输出画面时关闭窗口，无论默认关闭设置如何，程序都会最小化到托盘。
  • 照片的视角和范围与预览保持一致，并修复了启用暗角时输出背景失去透明度的问题。
  • 热键支持 F13～F24 和修饰键。右键点击自定义表情或姿势可添加或移除快捷操作。
  • 摄像头预览在确认后先显示 MediaPipe 跟踪；显示实际摄像头画面需要另一次确认，以减少意外露脸的风险。
  • 全部重置也会重置网格修改。左上角图标可直接返回虚拟形象选择界面。
  • 可输入虚拟形象的 X/Y/Z 缩放，并解除比例关联以单独调整各轴。
  • 每个姿势可保存脸部、手臂、手指和躯干的跟踪许可，并可通过右键菜单复制姿势。
  • 可对灯光分组并调整组的位置、旋转和亮度。场景与灯光菜单的选择相互联动，并支持右键删除。
  • 可拖动各页面的主要折叠区标题调整顺序，顺序按页面保存。
  • 背景颜色立即生效，移除了手势功能的重复说明，并保留了现有场景保存方式。

2026/10/11 — v1.0.9#

  • 我的表情：右键设置全局快捷键，支持按住／按下切换，快捷键表情优先于自动表情
  • 保存姿势：右键或 ⋯ 菜单设置快捷键，按一次应用，再按一次松开，按模型保存
  • 场景 > 场景：背景、灯光、对象、姿势、表情和摄像机连同缩略图一起保存，一键恢复，支持 Ctrl+Z
  • 拖动表情菜单和我的表情卡片调整顺序
  • 选择模型：无需重启应用即可返回列表并切换模型
  • 每个姿势可允许追踪，对象分组与姿势文件夹，支持比例联动的 X/Y/Z 对象尺寸输入
  • 改善桌前只看到肩部时的上半身动作，提供独立开关和强度调整
  • 简化设置 > 许可证界面

2026/10/09 — v1.0.8#

  • 面部自动设置：表情做得较弱时该表情会过于敏感（嘴角一直上扬）的问题已修复；重新设置会清除之前的设置并从头开始（如已出现此问题，请再进行一次自动设置）
  • Discord 屏幕共享：Basic 水印几乎不可见；修复开启 HDR 的游戏发白的问题
  • 只运行一个 Avatar Live：在托盘中时再次启动会打开已运行的窗口，而不是再开一个
  • X 按钮默认退出（可在设置中选择隐藏到托盘）
  • 左下角电源按钮：无论托盘设置如何都立即退出；左上角标志菜单改为“选择角色”
  • 每个灯光新增“随相机移动”开关
  • 摄像头全身和手指关节追踪成为正式功能，新电脑默认开启
  • 修复更新说明被截断或上方留空的问题；错误报告包含性能和屏幕共享信息

2026/10/09 — v1.0.7#

  • 1.0.6 中追踪被转到 VMC 的电脑：一次性恢复摄像头对手臂、手、头部和身体的追踪（不使用 VMC 时模型不动的问题）

  • 桌面姿势手臂更流畅：身体大幅晃动时肘部不再跳动，放下手立即回到桌面姿势，抬起时平滑恢复；修复坐姿下肘部抬起的问题

  • 摄像头上半身：开启全身后，即使看不到腿，仅靠肩膀也能让上半身倾斜和转动

  • VMC 手臂输入中断时，手臂放回桌面（键盘和鼠标）

  • 平行光：用 X/Y/Z 旋转环代替移动箭头

  • 层级与网格：顶部“全部重置”，树的“全部折叠”；修复全身开关标题显示错误的问题

2026/10/09 — v1.0.6#

  • VMC 可作为分部位追踪来源：手臂、手、手指、身体（髋部、脊柱、腿）、头部和眼睛均可分别来自 VMC（手套、全身追踪器、其他应用），其他部位仍用摄像头、iPhone 或 Ultraleap

  • VMC：应用每个手指关节的旋转、张开和拇指；按模型自身的基础姿势校正；对齐 / T 姿势 / 重置；显示接收状态

  • 在 设备 › 追踪来源 中新增“身体”部位

  • 全身（实验性，默认关闭）：开启 身体 › 全身 后跟随摄像头中可见的躯干和腿；画面外的腿显示为推定

  • 手指关节追踪（实验性，默认关闭）：在手指下方开启后，用摄像头跟随手指关节、张开和拇指

2026/10/09 — v1.0.5#

  • iPhone 面部输入：直接连接 iFacialMocap、FaceMotion3D，按原样使用 52 个 ARKit 表情，面部风格预设

  • 整理追踪来源：在面部引擎中选择摄像头引擎或面部应用（iPhone、VMC），各设备设置显示在其追踪部位下方；在手部选择 Ultraleap

  • 手部防抖：摄像头追踪的手和手指静止时不再抖动（设备 › 追踪来源）

  • 摄像头微笑：修复张嘴微笑时嘴变尖的问题（露出上唇和牙齿的大笑）

  • 躯干倾斜跟随头部动作

  • 姿势编辑：随骨骼大小变化的旋转控件、对称编辑、面向镜头、贴合地面、Alt+拖动肘部和膝盖、“完成”保存为姿势、“放弃”后 Ctrl+Z 恢复、内置站立和坐姿

  • 姿势库：将 .anim 姿势文件夹显示为此模型的缩略图，可应用、编辑、保存

  • 模型菜单：层级结构，网格开关与隐藏，点击网格在侧面板编辑形态键

  • 我的表情：在侧面板中以录制方式编辑形态键，预览强度

  • 灯光：颜色编辑器（色块、RGB、HEX、吸管），在视图中显示灯光范围、方向手柄、X/Y/Z 移动箭头

  • 照片：无 UI / 含 UI / 仅背景透明，以及“眼睛看镜头”

  • 背景图片缩放与位置调整；所有滑块数值均可直接输入；景深说明更清楚

  • 右键快捷键即可添加到快捷操作；屏幕共享的更多来源可拖动排序

  • 最小化或在托盘中时大幅降低 CPU 占用（输出或共享时不变）

  • 应用内公告；设置 › 关于 ›“发送改进建议”

  • 许可证界面简化（版本和输入代码）；修复已保存视图的重命名框不显示等问题

2026/10/09 — v1.0.4#

  • 桌面姿势：手会停留在最后使用的位置（鼠标或键盘）。如需旧行为，请开启“不用鼠标时回到键盘”。

2026/10/09 — v1.0.3#

  • 桌面姿势：鼠标手更靠近身体，并可调整鼠标手的位置。

2026/10/09 — v1.0.2#

  • 修复安装路径包含非 ANSI 字符（如韩文）时，摄像头追踪无法启动的问题。

2026/10/09 — v1.0.1#

  • 修复更改追踪质量后追踪中断的问题。
  • 使用 iFacialMocap 时无需手动输入 iPhone 地址。
  • 改善设置面板的固定功能。
  • 修复 Eco 模式的追踪行为。
  • 改善 PhysBone 姿势保持处理。
  • 更新升级商品的表述。
