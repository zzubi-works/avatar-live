更新记录#

Avatar Live各版本的更新内容，按最新版本优先排列。

如果更新没有完成、应用没有重新启动，请关闭 Discord、网页浏览器、OBS 等所有使用摄像头的程序，然后重新更新。

2026/10/26 — v2.2.5#

  • 液体声音： 修复了在液体设置中选择其他声音后仍播放默认声音的问题。现在倾倒期间会反复播放所选声音；不选声音则无声。保留默认「啪叽」时，仍是原来的泼溅声和液体声。
  • 选择声音： 新规则一开始开启的默认声音（液体的「啪叽 · 随机」、投掷、贴纸）会在你选择其他声音时被替换。之前保存的规则若同时开启了默认声音和所选声音，会随机播放其中之一，请关闭默认的「啪叽 · 随机」。

2026/10/26 — v2.2.4#

  • 屏幕共享指示： 修复了屏幕共享已关闭时，顶部栏仍显示「屏幕共享」已开启的问题。现在只在真正共享时才显示。
  • 嘴部来源： 驱动嘴部的来源只在 设备 › 追踪来源 的「嘴」一处选择。动作 › 嘴 · 舌头 · 脸颊 中只显示当前使用的来源。
  • 混合方式： 同时使用面部与麦克风时，可选择「说话时用麦克风」或「最大值」。「麦克风混入 iPhone 嘴形」开关也移到了同一位置。
  • 说明文字： 提示已改为：只有开启「麦克风混入 iPhone 嘴形」时，iPhone 的嘴部才会与麦克风混合。使用手册的设备、动作页面也整理了四种嘴部来源、混合方式和灵敏度（0–100%）。

2026/10/26 — v2.2.3#

  • 直播叠加画面与预览： 修复缩小后的预览变成黑屏，以及旋转叠加画面后变黑或颜色变暗的问题。颜色和上下方向现在可以正确显示。
  • 直播画面： 重新调整了画面捕获、合成和输出流程，改善游戏画面与头像的叠加输出，以及输出中断后的恢复处理。
  • 移动游戏窗口： 修复游戏窗口移到另一台显示器后，仍按原显示器判断捕获状态的问题。
  • 直播分辨率： 调整应用窗口大小时，直播用的头像画面会保持设置的输出分辨率。
  • 直播规则： 修复关闭或编辑规则时发生错误后，旧规则仍继续运行或响应测试按钮的问题。单个规则出错时，不再阻塞其他规则及应用功能。
  • 灯光效果： 修复点击灯光设置中的“添加效果”按钮后菜单没有打开的问题。
  • 性能与内存： 改善未使用的直播输出与共享纹理的释放，以及 GPU 优先级设置的应用和恢复处理。
  • 液体效果： 减少湿润表面的重复计算，对设置为不显示液体的摄像机跳过液体渲染，并释放闲置液体效果的资源。
  • 口型与唇形同步： 统一了口型输入设置，并按头像保存面部追踪与麦克风的混合设置。唇形同步灵敏度改为按百分比调节。
  • 房间照明： 修复在明亮房间中头像皮肤看起来透明的问题。

2026/10/26 — v2.2.2#

  • 简易设置与直播联动: 修复了 2.2.0、2.2.1 中简易设置规则无法生效、错误不断出现,同时导致 CHZZK 等直播连接和应用其他功能停止的问题。
  • 节点编辑器: 在 2.2.0、2.2.1 中制作的图表连线会保持连接。
  • 即使某条规则无法生成,其他规则和应用也会继续运行,错误只记录一次。

2026/10/25 — v2.2.1#

  • iPhone 面部追踪: 修复了姿势固定头部时,身体仍随 iPhone 的头部动作横移或转动的问题。现在固定头部的姿势也会让身体保持不动。
  • 面板颜色: 在设置 › 界面 › 主题中可选择浅色、深色、白色、黑色和自定义。自定义只需选择底色和强调色,其余颜色会自动搭配,并且无论什么颜色文字都会调整为清晰可读。侧边菜单也可以单独使用其他主题(例如菜单白色、面板黑色)。
  • 面板外观: 浅色主题改为柔和的香草与薰衣草色。侧边菜单贴住窗口边缘,打开的面板叠在其下方并带有阴影;背景更通透,浮在上面的卡片更清晰。
  • 投掷演播室物体 (Pro): 简易设置的投掷规则也可以选择并投掷你放入演播室的 3D 模型(用 Prop Exporter 制作)。
  • 卡片: 可以拖动排序的卡片重新一张张分开显示。
  • 面部卡片: 「正面校准」和「自动面部设置…」按钮放在同一行。
  • 游戏灯光: 各头像接收的程度改在演播室 › 灯光 › 游戏灯光同步的「按头像」中设置,不再放在角色菜单。
  • 动画层: 因为是直播事件切换的动画,从角色菜单移到直播 › 互动。不设置的话,对平时的追踪没有影响。
  • 错误报告: 现在会包含是什么固定了头部,以及 iPhone 头部数据跳动的幅度,便于更准确地查明原因。

2026/10/25 — v2.2.0#

新功能

  • 直播联动(测试版,PRO): 在新的「直播」页面连接 Twitch、CHZZK、SOOP 或 Discord 后,虚拟形象会对观众的频道点数、聊天、打赏、订阅、气球等事件作出反应。这是测试版功能,如果在实际直播中遇到问题,请通过错误报告告诉我们(报告中会包含直播连接记录,令牌、代码、订单号和邮箱会被隐藏)。
  • 在 Discord 一起玩(测试版,PRO): 把机器人邀请到服务器并将频道与应用连接后,好友可以通过 Discord 的按钮或 /react 命令触发虚拟形象的反应。还有使用点数的小游戏(签到、轮盘、老虎机、二十一点、问答、Boss 战等)。仅在应用运行时有效。
  • 简易设置(测试版,PRO): 点击「+」,依次选择平台 → 事件 → 反应,即可生成马上生效的规则。支持金额范围、按观众的冷却时间,以及根据打赏金额增加投掷数量。
  • 节点编辑器(测试版,PRO): 用节点把事件和反应连起来,自由编排效果。在独立的大窗口中打开,带小地图,每个事件节点都有 TEST 按钮。
  • 投掷、液体、贴纸与倒地(PRO): 可以向虚拟形象投掷物件;泼上水或牛奶等液体后会顺着身体流下并逐渐变干;还能贴上图片、GIF 或观众的头像贴纸。被重重击中会倒地,然后慢慢站起来,并可设置倒地时的表情和起身速度。
  • 测试卡片: 在直播 › 互动的最下方,无需直播即可立即试用投掷、击倒、击中、液体和贴纸。
  • 打赏显示框(PRO): 在场景中的框里显示打赏者的名字和留言。默认关闭。
  • WebSocket(PRO): 只在本机开放的 WebSocket,可与其他程序联动。默认关闭。
  • DLC 房间包: 在 BOOTH 购买追加内容并把订单号输入到原有的代码输入框后,房间列表中会出现 13 个新房间,选择即可下载:日本小巷(白天、夜晚)、日本公寓、学校泳池、展厅画廊、教室(白天、傍晚、夜晚)和联合办公室,都保留了原场景的灯光与氛围。房间的灯可以开关并调整亮度(随房间保存),挡住摄像机的墙只会从画面中去掉。Basic 也可以使用。
  • 屏幕物件: 在工作室 › 物件中添加「屏幕」,即可在场景中显示图片、GIF、显示器或窗口画面,以及 Spout、NDI 画面。

变更

  • 面板设计全面更新: 改为分组卡片、分段标签、右侧按钮,以及能隐约透出背后场景的半透明侧栏和浮动工具栏。竖向布局和左侧菜单保持不变。半透明模糊不会出现在直播、录像和虚拟摄像头画面中;关闭 Windows 的透明效果时会显示为不透明。
  • 菜单位置: Twitch、CHZZK 连接和远程会话移到新的「直播」页面;照片和拍摄画面移到工作室 › 「照片与录像」标签;倒地设置移到直播 › 互动。较长的页面按小标题分组。你自己调整过的卡片顺序和折叠状态会保留。
  • 名称变更: 「待机·叠加动画」→「动画图层」,「眼睛设置」→「眼睛动作」,「视线控制」→「注视目标」。
  • 嘴部动作: 当嘴部来源设为「面部(iPhone)」或「关闭」时,麦克风不再驱动嘴部。若要用声音驱动嘴部,请选择「面部 + 麦克风」或「麦克风」。
  • 应用录像声音: 除了麦克风,共享屏幕时也会一起录下所共享游戏的声音。
  • 右键菜单: 所有列表(虚拟形象、摄像机、场景、物件、预设等)都可以通过右键(或 ⋯)重命名、复制和删除,也支持 Delete 和 F2 键。
  • 会话同意: 加入远程会话现在只需勾选一项并打开「交换数据」开关。原有设置会保留。
  • 代码输入: 升级码和 DLC 代码也统一在「输入其他代码」窗口中输入。
  • 低多边形室内: 移除了「整栋建筑」选项(拆分的房间保持不变)。以整栋建筑保存的场景打开时将没有房间。
  • 选择 DLC 房间时,工作室的环境光、反射强度和雾会按该房间调整一次;之后可以自由更改,并随场景保存。切换到内置房间或不使用房间时会恢复默认值,房间的灯光也不会让角色过亮。
  • 错误报告现在包含直播连接状态和最近的事件,联动出现问题时能更准确地查明原因。
  • 现有 .vavatar 文件可直接使用,无需重新导出。

2026/10/23 — v2.1.2#

  • 修复了摄像机控制模式为「环绕」时，切换视角或移动摄像机后会有一帧从错误位置显示虚拟形象的问题。

2026/10/22 — v2.1.1#

  • 直接抓取摄像机: 开启工作室摄像机的「直接抓取」后，场景画面中会显示摄像机及其拍摄范围，可以像物件一样用箭头和旋转环移动、转动。抓取期间，该摄像机的画面会以小窗显示在角落。摄像机的外形不会出现在直播、录像或照片中，按 Esc 即可放开。

2026/10/22 — v2.1.0#

新功能

  • 灯光扩展: 新增摄影灯光布置和柔光箱等近似灯光，光束质量、gobo(遮光图案)、体积光和局部雾，霓虹、RGB、LED 灯带、蜡烛、显示器、太阳、月亮等装饰与环境灯光，以及摇头灯和激光。灯光还可以脉冲、闪烁、循环变色、平移/俯仰，或随声音变化。
  • 添加灯光窗口与灯光预设: 新增带搜索、收藏和最近使用的添加灯光窗口，以及 18 种灯光预设。
  • 光敏保护: 快速闪烁的灯光会合并所有效果，按整个画面限制为每秒不超过 3 次。只有在这台电脑上确认后才会解除。
  • 灯光时间轴: 可在序列器中为每盏灯打关键帧来编排灯光。支持导入 VMD 的灯光关键帧，并支持关键帧复制粘贴和影响曲线编辑。
  • 游戏灯光同步: 将正在共享的游戏画面的颜色和亮度实时反映到虚拟形象的灯光上。默认关闭。
  • 环境投影: 将游戏画面模糊后的光柔和地映在虚拟形象上，让虚拟形象自然融入画面氛围。只作用于虚拟形象，透明背景保持不变。默认关闭。
  • 天空、雾与光: 新增 4 种天空背景、雾、在墙面反弹的光以及更柔和的阴影。
  • 房间编辑: 可逐个隐藏、移动或还原房间的墙、地板、门、窗和家具。支持按类型一键开关、找回隐藏的部件、房间灯光开关和亮度，以及选择虚拟形象的站立位置。场景中只保存改动的部分。挡住直播相机的墙、挂在墙上的物件以及遮挡视线的物件只会从画面中去掉，阴影和灯光保持不变。
  • 新的室内空间: 新增 4 个房间和一整栋房子，连窗外的景色也包括在内；选择房间时会一并应用适合该房间的氛围(反弹光、角落阴影、反射)。现有的室内空间也可以选择整栋建筑。
  • 序列器: 支持关键帧、摄影表、曲线图、姿势复制、固定、片段混合和烘焙等接近 Blender 的编辑方式。可导入 .vrma、.bvh、.vmd 动作，并按文件记住手臂角度和移动幅度。
  • 自由摆姿势: 拖动手、脚或骨盆时，整个身体会自然跟随。降低骨盆时双脚会留在地面上。
  • 固定姿势时的呼吸: 固定姿势时也会继续呼吸，虚拟形象不再显得僵硬。
  • 启动画面: 重新整理了布局，让虚拟形象、设备和列表一目了然。

修复与改进

  • 修复了部分虚拟形象的头发或服装向上翘起并停在那里的问题。
  • 修复了坐下、躺下等改变姿势后，从身体发出的粒子效果仍从原来站立的位置出现的问题。
  • 修复了半透明头发与画面效果重叠时看起来透明的问题。
  • 远程会话中也会同步柔和阴影设置。
  • 场景保存改进: 每个场景都会分别保存虚拟形象的位置和姿势，打开场景时会原样恢复。在场景中切换虚拟形象后，切换后的虚拟形象会保存到场景中。有未保存的更改时返回虚拟形象列表，会询问是否保存。
  • 修复了上下移动虚拟形象时整个房间一起移动的问题。
  • 灯光、效果和环境光预设按类型折叠显示，自己保存的预设放在最上面。
  • 背景选项整理为纯色、绿幕、透明、图片和天空。原有的蓝色背景会保留为相同颜色的纯色背景。
  • 减少了工作室摄像机列表中的按钮，摄像机名称更容易看清。直接抓取和设为当前画面位于每台摄像机的设置中。
  • 添加灯光窗口始终在按钮下方打开。
  • 现有 .vavatar 文件可直接使用，无需重新导出。

2026/10/19 — v2.0.15#

  • 修复部分虚拟形象的眼睛显示: 修复了眼球骨骼正面参考姿态带有旋转的虚拟形象中，参考旋转被重复应用，导致瞳孔消失或眼部看起来空洞的问题。现在只应用相对于各虚拟形象自身参考姿态的视线变化。现有.vavatar文件可直接使用，无需重新导出。
  • 结束眼睛控制时恢复姿态: 关闭眼睛控制或切换虚拟形象时，无论眼睑网格如何设置，都会将眼球骨骼恢复为原来的动画姿态。

2026/10/19 — v2.0.14#

  • 设置 > 设置文件 > 保存位置中可「更改保存位置」：将设置、角色库、姿势、场景等复制到所选文件夹，下次启动起使用新位置；可「用回默认位置」。旧文件夹不会删除，许可证不会移动。找不到指定位置（如外接硬盘）时从默认位置启动并提示。
  • 设置 > 设置文件新增立即备份、从其他文件夹导入、备份列表（恢复·删除），并可设置启动时自动备份与保留数量（3、5、10、20）。恢复与导入在下次启动时生效，生效前的设置会先自动备份。
  • 输出画面、屏幕共享、窗口和照片的分辨率下方，“自定义尺寸”统一为点击后向下展开宽高输入框；“使用来源分辨率”“使用当前显示器分辨率”也移入展开区域，输入后可按 Enter 应用。
  • 设置 > 快捷键 · 快捷操作 > Stream Deck 的“安装插件”按钮已与其他按钮对齐。

2026/10/18 — v2.0.13#

  • 修复多个 VMC 发送端混合造成的角色跳动，改进姿态和表情数据重新连接。
  • 支持分别选择 VMC 姿态与表情发送端，并防止输出回环。
  • 改进 iPhone、Ultraleap、SteamVR、OpenSeeFace 和 VRCFT 的连接状态与数据处理。

2026/10/18 — v2.0.12#
