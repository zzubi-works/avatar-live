10. 设置#

v2.0.0：性能、界面与更新设置的实际影响#

选项 更改后会发生什么
应用 FPS 限制 提高让画面/物理更频繁更新，但 CPU/GPU 负担增加；降低更节能但动作不够连贯。直播输出还有自己的 FPS 设置。
渲染质量/分辨率 高质量改善发丝和轮廓细节但更占 GPU。程序窗口尺寸与 OBS 发送画面分辨率可能不同。
阴影/后处理 关闭后渲染更轻，但立体阴影及光学效果减少；部分效果跟随工作室分别保存。
窗口大小/置顶 只改变 Windows 中显示的窗口，并不等于修改 Spout2/NDI 画面的输出像素数。
关闭按钮行为 可选择退出或最小化到托盘；直播中最小化可能继续发送画面。
UI 缩放 改变字体与按钮尺寸；缩放太大时窄窗口需要更多滚动。
快捷工具条透明度 提高使空闲按钮更明显，降低使角色较少被遮挡。
自动下载更新 开启可预先下载，关闭仍可在启动时检测并显示更新提示。
发送诊断报告 用户主动选择发送时传送问题资料，建议写明重现步骤。

快捷键在程序位于后台时也可能生效，请避免与游戏按键冲突。表情可以设置为按住生效或按一次切换，支持 F13–F24 及组合键，也可由 Stream Deck 的普通热键触发。

注意保存范围：表情、姿势和保存视角属于角色；房间、舞台灯光、直播摄像机属于工作室；摄像头、话筒可能跟随 Windows 设备变化而需要重新选择。

常规 · 窗口 · 性能#

  • 启动时打开菜单 — 关闭后，将不显示菜单直接启动。
  • 窗口 — 设定窗口大小、全屏、窗口置顶以及 X 按钮的行为。
  • 性能 — 设定帧率和画质。调低可减轻电脑负担。
  • 阴影 — 头发和下巴投在颈部和胸部的阴影。关闭可减轻 GPU 负担。
  • 语言 — 한국어 · English · 日本語 · 简体中文
  • 界面 — 更改主题、面板位置和文字大小。

搜索菜单与设置#

使用右上角的放大镜搜索AFK、镜像、语言、Spout2、目光、桌面模式或快捷键。选择结果后会定位到相应的菜单、设备、动作、工作室、输出或设置页面，并展开相关卡片。AFK时间会定位到动作 › 身体，而不是旧设置位置。

快捷键#

  • 点击 + 添加快捷键，然后选择动作和按键。
  • 在游戏中或 Avatar Live 位于后台时也能使用。
  • 其他程序的按键输入会照常传递。
  • 菜单按钮和手势可以选择 按住时 或 按下切换。

诊断 · 关于 · 更新#

项目 作用
诊断 › 发送错误报告 出现问题时发送说明和日志。仅在点击时发送。
关于 › 发送改进建议 发送希望增加的功能或希望改进的地方。
公告 新公告会在启动时显示一次，以往的公告可以在设置中再次查看。
打开日志文件夹 查看日志文件。
立即检查 · 下载 检查并下载新版本。
重新启动并安装 立即更新。角色和设置保持不变。

Avatar Live 每次启动都会检查一次更新，有新版本时显示绿色提示。开启 设置 › 更新 › 自动下载更新 后会自动下载。安装由单独的 退出时安装 选项或 重新启动并安装 按钮控制。也可以从 BOOTH 重新下载，角色和设置会保留。

启动时自动检查更新#

Avatar Live每次启动都会检查一次是否有新版本。关闭自动下载不会关闭版本检查和新版本提醒。可在更新设置中手动检查或下载，并选择重启后安装或退出时安装。已有角色和保存的设置不会丢失。

发送错误报告#

遇到故障时，请通过设置 › 诊断 › 发送错误报告提供出现问题的操作步骤。诊断数据和复现方法比简单的文字咨询更有助于定位问题。

发送问题 · 建议#

  • 使用中遇到 错误或问题 时，请通过 设置 › 诊断 › 发送错误报告 告诉我们。写上一两句当时的情况，会对查找原因有很大帮助。
  • 如果有 需要的功能或改进建议，请通过 设置 › 关于 › 发送改进建议 发送给我们。收到的意见会反映到更新计划中。
