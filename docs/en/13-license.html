Activation and Upgrade#

  • One license is used by one person on one PC.
  • Internet connection is required for activation and license verification.
  • Direct transfer to another PC is possible once. Further transfers are reviewed upon inquiry.
  • Basic → Pro: After purchasing the upgrade, enter it in Settings → License → Enter another code.
  • Purchase during trial: Enter the license in Settings → License → Enter another code.
  • DLC room packs: Enter the BOOTH order number in the same Enter another code. Your license stays as it is, and that PC can now download the room pack. Direct transfer to another PC is possible once.

Redistribution, rental, sharing, modification, or circumvention of protection measures of the program or license code is not allowed. For more details, please refer to the Terms of Use.

NDI#

NDI® is a registered trademark of Vizrt NDI AB. NDI Official Website

It is an external technology used for delivering network video.

  • The NDI Runtime included in Avatar Live follows the NDI SDK license.
  • The full license text is located in the program's AvatarLive_Data/Plugins/x86_64/Processing.NDI.Lib.Licenses.txt.
  • NDI Tools is a program that must be downloaded separately. It is not included with Avatar Live.
  • DistroAV received from OBS is a separate project and follows the license of that project.

NDI SDK Usage Conditions · How to Connect NDI

Spout2#

An external technology for transferring video between programs on the same Windows PC.

  • KlakSpout, used for Avatar Live's Spout2 integration, follows the Unlicense. The full text can be found in the third-party notices of the distributed package.
  • The OBS Spout2 Capture Plugin is a separate installer and follows the GPL v2 terms of the project.
  • Purchasing Avatar Live does not transfer any copyrights or separate rights of the OBS plugin.

How to Connect Spout2

VB-CABLE#

A separate virtual audio driver created by VB-Audio Software.

  • VB-CABLE is donationware, and the usage, distribution, and licensing conditions are determined by VB-Audio.
  • The install button is the path to install the original driver from VB-Audio. It is not a driver developed by Avatar Live.
  • For the required licenses and sponsorships, please check VB-Audio official license guide.
  • Purchasing or upgrading to Avatar Live Pro does not grant a separate license for VB-CABLE.

Avatars and Props#

The rights to content such as avatars, costumes, textures, shaders, poses, and 3D props belong to each original creator.

When using it for broadcasting, please check the following points and the usage regulations of each original creator before use.

Considerations Protocols to Check
Broadcasting·Video Release Check whether the original creator allows broadcasting or commercial use.
File Modification·Conversion Check the original creator's modification·conversion conditions.
Remote Session Transfer Check whether data transfer and temporary storage are allowed on another PC.
Provided to others Check permission for redistribution or provision to third parties.

Before using avatars and props, check the rights and usage rules of each original creator. It is the user's responsibility to obtain the necessary permissions and follow the rules.

Purchasing or using features of Avatar Live does not grant permission to use the content. Avatar Live and its developers are not responsible for any rights violations or disputes arising from the user's use, modification, transmission, or distribution of content.
