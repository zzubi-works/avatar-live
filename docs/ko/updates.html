2026/10/22 — v2.1.0#

새 기능

  • 조명 확장: 사진 조명 배치와 소프트박스 같은 근사 조명, 빔 품질·고보(쿠키)·볼륨 빛·국소 안개, 네온·RGB·LED·촛불·모니터·해·달 같은 장식·환경 조명, 무빙헤드와 레이저를 추가했습니다. 펄스·깜빡임·색 순환·팬/틸트 같은 조명 애니메이션과 소리에 반응하는 조명도 쓸 수 있습니다.
  • 라이트 추가 창과 조명 프리셋: 검색·즐겨찾기·최근 항목이 있는 라이트 추가 창과 조명 프리셋 18종을 추가했습니다.
  • 광과민성 보호: 빠르게 깜빡이는 조명은 여러 효과를 합쳐 화면 전체 기준 초당 3회를 넘지 않게 제한합니다. 이 PC에서 직접 확인한 경우에만 해제됩니다.
  • 조명 타임라인: 시퀀서에서 라이트마다 키를 찍어 조명을 연출할 수 있습니다. VMD의 조명 키를 가져올 수 있고, 키 복사·붙여넣기와 영향력 곡선 편집을 지원합니다.
  • 게임 조명 동기화: 공유 중인 게임 화면의 색과 밝기를 아바타 조명에 실시간으로 반영합니다. 기본은 꺼져 있습니다.
  • 앰비언트 프로젝션: 게임 화면을 흐리게 만든 빛을 아바타에 은은하게 비춰, 화면 분위기에 아바타가 자연스럽게 어울리게 합니다. 아바타에만 비치고 투명 배경은 그대로입니다. 기본은 꺼져 있습니다.
  • 하늘·안개·빛: 하늘 배경 4종, 안개, 벽에 튕기는 빛, 더 부드러운 그림자를 추가했습니다.
  • 방 편집: 방의 벽·바닥·문·창·가구를 하나씩 숨기거나 옮기고 원래대로 되돌릴 수 있습니다. 종류별로 한 번에 켜고 끄기, 숨긴 조각 다시 보기, 방 불빛 스위치와 밝기, 아바타가 설 곳 고르기를 지원합니다. 바꾼 부분만 씬에 저장됩니다. 방송 카메라를 가리는 벽과 그 벽에 걸린 소품, 시야를 막는 소품은 화면에서만 빠지고 그림자와 불빛은 그대로 남습니다.
  • 새 실내 공간: 방 4개와 집 한 채를 추가했습니다. 창밖 풍경까지 들어 있고, 방을 고르면 그 방에 맞는 분위기(튕기는 빛·구석 그늘·반사)가 함께 적용됩니다. 기존 실내 공간도 건물 전체를 고를 수 있습니다.
  • 시퀀서: 키·도프 시트·그래프·포즈 복사·핀·클립 섞기·굽기 등 Blender에 가까운 편집을 지원합니다. .vrma·.bvh·.vmd 동작을 가져올 수 있고, 파일마다 팔 각도와 이동 크기를 기억합니다.
  • 자유 포즈: 손·발·골반을 끌면 몸 전체가 자연스럽게 따라옵니다. 골반을 내리면 발은 바닥에 그대로 있습니다.
  • 고정 포즈의 숨쉬기: 포즈를 고정해도 숨쉬기가 이어져 아바타가 굳어 보이지 않습니다.
  • 시작 화면: 아바타·장치·목록이 한눈에 들어오도록 배치를 정리했습니다.

수정·개선

  • 일부 아바타에서 머리카락이나 의상이 위로 솟구친 채 멈춰 있던 문제를 수정했습니다.
  • 앉기·눕기처럼 자세를 바꿨을 때, 몸에서 나오는 파티클 효과가 서 있던 자리에서 나오던 문제를 수정했습니다.
  • 반투명 머리카락이 화면 효과와 겹쳐 비쳐 보이던 문제를 수정했습니다.
  • 원격 세션에서 부드러운 그림자 설정이 함께 전달됩니다.
  • 씬 저장 개선: 씬마다 아바타의 위치와 포즈를 따로 저장하고, 씬을 열면 그대로 돌아옵니다. 씬에서 아바타를 바꾸면 바꾼 아바타가 씬에 저장됩니다. 저장하지 않은 변경이 있는 채로 아바타 목록으로 돌아가면 저장할지 묻습니다.
  • 아바타를 위아래로 옮길 때 방 전체가 함께 움직이던 문제를 수정했습니다.
  • 조명·효과·환경광 프리셋을 종류별로 접어서 보여 주고, 직접 저장한 프리셋을 맨 위에 둡니다.
  • 배경 선택을 단색·초록·투명·이미지·하늘로 정리했습니다. 기존 파랑 배경은 같은 색의 단색으로 유지됩니다.
  • 스튜디오 카메라 목록의 버튼을 줄여 카메라 이름이 잘 보이게 했습니다. 직접 잡기와 현재 화면으로는 카메라 설정 안에 있습니다.
  • 라이트 추가 창이 항상 버튼 아래에 열립니다.
  • 기존 .vavatar를 그대로 사용할 수 있으며 재내보내기는 필요하지 않습니다.

  • 메모리·자원 관리: 모션 실행 취소 이력을 압축하고 보관량을 제한했습니다. 모션 소스 제거, 효과 전환, 출력 해상도 변경 후 사용이 끝난 자원의 해제를 보강하고, 곡선 평가의 임시 할당을 줄였습니다.
