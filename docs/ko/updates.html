업데이트 내역#

Avatar Live의 버전별 변경 사항입니다. 최신 업데이트부터 확인할 수 있습니다.

2026/10/11 — v1.0.10#

  • 피직스본의 일부 과한 움직임을 개선했습니다. 이번 수정은 임시 개선이며, 추후 추가 개선 예정입니다.
  • 송출 중 창을 닫으면 기본 종료 설정과 관계없이 트레이로 이동합니다.
  • 사진의 화각과 범위를 미리보기에 맞추고, 비네팅을 켰을 때 송출 배경의 투명도가 유지되도록 수정했습니다.
  • F13~F24 키와 조합키를 핫키로 등록할 수 있습니다. 내 표정과 포즈는 우클릭으로 퀵액션에 추가하거나 제거할 수 있습니다.
  • 캠 미리보기는 안내 후 먼저 MediaPipe 트래킹을 표시합니다. 실제 캠 화면은 별도 확인 후 표시해 얼굴 노출 위험을 줄였습니다.
  • 모두 초기화 시 메쉬 수정값도 초기화되며, 좌측 상단 아이콘으로 아바타 선택 화면에 바로 돌아갈 수 있습니다.
  • 아바타 크기를 X/Y/Z로 입력하고 비례 연결을 끄면 축별로 조절할 수 있습니다.
  • 포즈마다 얼굴·팔·손가락·몸통의 트래킹 허용 여부를 저장할 수 있으며, 우클릭으로 포즈를 복제할 수 있습니다.
  • 라이트를 그룹으로 묶고 그룹의 위치·회전·밝기를 조절할 수 있습니다. 씬과 조명 메뉴의 라이트 선택을 연결하고 우클릭 삭제를 추가했습니다.
  • 각 페이지의 주요 접이식 섹션 제목을 드래그해 순서를 바꿀 수 있으며, 페이지별 순서가 저장됩니다.
  • 배경 색상은 즉시 반영되며 손 제스처의 중복 안내를 정리했습니다. 기존 씬 저장 방식을 유지했습니다.

2026/10/11 — v1.0.9#

  • 내 표정: 우클릭으로 전역 단축키 지정. 누르는 동안 / 눌러 켜고 끄기 지원, 키로 지정한 표정이 자동 표정보다 우선
  • 저장 포즈: 우클릭 또는 ⋯에서 단축키 지정. 한 번 눌러 적용, 다시 눌러 해제 (아바타별 저장)
  • 씬 › 장면: 현재 배경·조명·물체·포즈·표정·카메라를 썸네일과 함께 저장하고 한 번에 복원, Ctrl+Z 지원
  • 아바타 표정 메뉴와 내 표정 타일을 드래그로 정렬
  • 아바타 선택: 앱을 재시작하지 않고 아바타 목록으로 돌아가 다른 아바타로 전환
  • 포즈마다 트래킹 허용 설정, 물체 그룹과 포즈 폴더, 물체 크기 X/Y/Z 입력과 비율 연결
  • 책상에서 어깨가 보일 때 상체 움직임 개선, 상체 추적 스위치와 강도 조절
  • 설정 › 라이선스 화면 정리

2026/10/09 — v1.0.8#

  • 얼굴 자동 설정에서 약하게 인식된 표정이 지나치게 증폭되는 문제를 수정했습니다. 자동 설정을 다시 진행하면 이전 학습 결과를 초기화하고 기본값부터 보정합니다.
  • 웹캠 전신 트래킹과 손가락 관절 추적을 정식 기능으로 전환하고, 신규 환경에서 기본적으로 활성화되도록 변경했습니다 (기존에 꺼둔 설정은 유지됩니다).
  • Discord 화면 공유에서 HDR 게임 화면이 지나치게 밝거나 색이 바래 보이는 문제를 개선하고, HDR 영상을 SDR로 변환하도록 수정했습니다.
  • Discord 화면 공유에 표시되는 라이선스 워터마크를 프로그램 내 표시와 동일하게 작고 옅게 조정했습니다.
  • Avatar Live가 중복 실행되지 않도록 개선했습니다. 다시 실행하면 이미 실행 중인 프로그램 창이 앞으로 나타납니다.
  • 창의 X 버튼을 누르면 기본적으로 프로그램이 종료되도록 변경했습니다. 설정에서 트레이로 최소화하는 동작도 선택할 수 있습니다.
  • 좌측 메뉴에 종료 버튼을 추가했습니다. 로고 메뉴에서는 프로그램을 재시작하지 않고 아바타 선택 화면으로 돌아갈 수 있습니다.
  • 조명마다 '카메라와 함께 이동' 기능을 켜거나 끌 수 있도록 추가했습니다.
  • 설정 화면에서 업데이트 내역이 잘리거나 표시 위치가 어긋나는 문제를 수정했습니다.
  • FPS, CPU·GPU 사용 상태, 프레임 처리 시간, 화면 공유 상태 등을 확인할 수 있도록 진단 로그를 강화했습니다.

2026/10/09 — v1.0.7#

  • v1.0.6 업데이트 후 웹캠의 팔·머리·몸 등 트래킹 소스가 의도치 않게 VMC로 변경되던 문제를 수정하고, 영향을 받은 설정을 웹캠으로 복구하도록 개선했습니다.
  • 책상 자세에서 팔과 팔꿈치가 부자연스럽게 흔들리는 현상을 개선하고, 손을 내리거나 다시 올릴 때 더욱 부드럽게 전환되도록 수정했습니다.
  • 앉은 자세에서도 팔과 손의 위치가 몸의 움직임에 자연스럽게 따라가도록 개선했습니다.
  • VMC 팔 입력이 끊어졌을 때 팔이 부자연스럽게 멈추지 않고 책상 휴식 자세로 돌아가도록 개선했습니다.
  • 웹캠 상체 트래킹을 개선하여 하체 트래킹 없이도 어깨 움직임을 통해 상체의 기울기와 회전을 반영하도록 했습니다.
  • 방향 조명 편집에 X·Y·Z축 회전 링을 추가했습니다.
  • 아바타 계층 구조와 메시 설정에 '모두 초기화', 계층 구조에 '모두 접기' 기능을 추가했습니다.

2026/10/09 — v1.0.6#

  • VMC를 부위별 트래킹 소스로 선택할 수 있습니다 (팔·손·손가락·몸·머리·눈). 장갑, 전신 트래커, 다른 앱의 입력을 웹캠·iPhone·Ultraleap과 함께 쓸 수 있습니다.
  • VMC로 손가락 마디별 회전·벌림·엄지까지 반영하고, 아바타 기본 자세에 맞춰 보정합니다 (정렬·T자세·초기화).
  • 트래킹 소스에 '몸' 부위를 추가했습니다.
  • 웹캠 전신 트래킹을 추가했습니다 (실험적, 기본 꺼짐).
  • 손가락 관절 추적을 추가했습니다 (실험적, 기본 꺼짐).

2026/10/09 — v1.0.5#

  • iPhone 얼굴 입력(iFacialMocap·FaceMotion3D)에 직접 연결되고, ARKit 표정 52개를 그대로 사용합니다. 얼굴 스타일 프리셋을 추가했습니다.
  • 웹캠으로 입을 벌리고 웃을 때 입이 뾰족해지던 문제를 수정했습니다.
  • 트래킹 소스를 정리했습니다 (얼굴 엔진에서 얼굴 앱 선택, 손 부위에서 Ultraleap 선택).
  • 웹캠 손·손가락이 가만히 있을 때 떨리지 않도록 손 떨림 보정을 추가했습니다.
  • 포징을 강화했습니다 (뼈 크기에 맞는 회전 기즈모, 대칭 편집, 카메라 보기, 바닥에 붙이기, 기본 서기·앉기 자세, '완료'로 포즈 저장).
  • 포즈 라이브러리를 추가했습니다 (.anim 포즈를 아바타 썸네일로 보고 적용·편집·저장).
  • 아바타 메뉴에 계층 구조, 메시 켜기·끄기·숨기기, 쉐이프키 편집 패널을 추가했습니다.
  • 내 표정을 옆 패널에서 편집할 수 있습니다.
  • 조명 색 편집기(RGB·HEX·스포이드), 범위 표시, 방향·이동 핸들을 추가했습니다.
  • 사진: UI 없이 / UI 포함 / 배경만 투명, '눈 카메라 보기'를 추가했습니다.
  • 배경 사진 확대·축소·위치 조절, 모든 슬라이더 숫자 직접 입력을 지원합니다.
  • 최소화·트레이 상태의 CPU 사용량을 크게 줄였습니다 (출력·공유 중에는 그대로).
  • 앱 안 공지와 개선 사항 보내기 기능을 추가했습니다.
  • 라이선스 화면을 간소화했습니다.

2026/10/09 — v1.0.4#

  • 책상 자세에서 손이 마지막으로 쓴 곳(마우스 또는 키보드)에 머물도록 했습니다. 예전 동작은 '마우스를 안 쓰면 키보드로 돌아가기'를 켜세요.

2026/10/09 — v1.0.3#

  • 책상 자세에서 마우스 손이 몸 가까이 오도록 했습니다. 마우스 손 위치를 조절할 수 있습니다.

2026/10/09 — v1.0.2#

  • 한국어 등 비ANSI 문자가 포함된 폴더에서도 웹캠 트래킹이 정상적으로 시작되도록 수정했습니다.

2026/10/09 — v1.0.1#

  • 트래킹 품질을 변경한 뒤에도 트래킹이 유지되도록 수정했습니다.
  • iFacialMocap 연동 시 iPhone 주소를 수동으로 입력할 필요가 없어졌습니다.
  • 설정 패널 고정 기능을 개선했습니다.
  • Eco 모드의 트래킹 동작을 수정했습니다.
  • PhysBone 포즈 유지 처리를 개선했습니다.
  • 업그레이드 상품 표기를 변경했습니다.
