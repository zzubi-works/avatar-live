업데이트 내역#

Avatar Live의 버전별 변경 사항입니다. 최신 업데이트부터 확인할 수 있습니다.

2026/10/29 — v2.4.2#

  • 감독 모드 렉 줄임: 아무도 보지 않는 화면은 그리지 않고, 미리보기와 멀티뷰는 가볍게 그립니다. 씬뷰와 외부 출력의 화질은 그대로입니다.
  • 씬 복원: 씬을 열면 저장한 아바타가 저장한 위치와 포즈로 돌아옵니다.
  • 녹화·화면공유에 앱 소리: 던지기·물 뿌리기 같은 Avatar Live 소리가 녹화와 화면공유, 화면공유 녹화에 들어갑니다. 녹화 카드의 「앱 소리」, 공유 오디오의 「Avatar Live 소리」 스위치로 끌 수 있습니다.
  • 서랍 너비: 서랍 가장자리를 끌어 너비를 바꿀 수 있습니다. 더블클릭하면 기본 너비로 돌아갑니다.
  • 공지: 긴 공지가 잘리지 않고 카드 안에서 스크롤됩니다.
  • 방 팩: 하수도·교실·나이트클럽의 일부 벽이 비어 보이던 것을 고쳤습니다(방 팩 1.4.4 업데이트).
  • 기존 .vavatar를 그대로 사용할 수 있으며 재내보내기는 필요하지 않습니다.

2026/10/29 — v2.4.1#

  • 사진 8K: 사진 해상도에 8K(7680×4320, Pro)가 생겼습니다. 가장자리가 더 매끄러워 크게 잘라 써도 선명합니다. PNG를 저장하는 동안 앱이 멈추지 않고, 큰 사진도 피사계 심도·흐림·그레인이 화면과 같게 나옵니다.
  • 방 이름: 방 팩의 방 이름이 앱 언어로 나옵니다. 새 방 팩 업데이트와 함께 적용됩니다.
  • 업데이트 알림: 새 버전의 변경 내용만 보여 줍니다.
  • 기존 .vavatar를 그대로 사용할 수 있으며 재내보내기는 필요하지 않습니다.

2026/10/29 — v2.4.0#

  • MCP로 AI 연출: 연결한 AI 앱이 조명과 프리셋, 게임 조명 동기화, 방, 간편 설정 규칙, 출력, 화면 공유 배치, 노드 그래프를 다룰 수 있습니다. 모든 변경은 승인해야 적용되고 되돌릴 수 있습니다. 빠른 깜빡임은 AI가 켜거나 바꿀 수 없고, AI가 만든 조명 변화도 깜빡임 한도 안에서 움직입니다.
  • 방: 모델 파일(FBX)로 「내 방」을 더할 수 있고, 방의 조명이 원래 방향대로 비춥니다. 방 팩을 골라 목록이나 격자로 볼 수 있습니다. 방마다 「아바타도 비춤」으로 방의 불빛이 아바타도 비출지 고릅니다(기본 켬).
  • 녹화: 게임 화면이 아직 잡히지 않았으면 「대기 중」으로 보여 주고, 화면이 들어오는 즉시 녹화를 시작합니다. 녹화 소리나 마무리에 문제가 생기면 알려 주고, 소리가 끊긴 뒤 녹화가 어긋나던 문제를 고쳤습니다.
  • 방송 미리보기: 미리보기 스위치 하나로 미리보기를 보이고 숨깁니다. 스튜디오 카메라를 잡고 있을 때도 같습니다.
  • 화면 공유 패널: 소스 선택 창이 누른 버튼 자리에서 열리고, 소스·소리·프리셋이 한 카드에 접혀 정리됩니다. 해상도와 FPS는 공유 상태 아래로 돌아왔습니다.
  • 모션 화면: 표정 키가 메시 목록 옆의 자기 목록에 보이고, 글자가 겹치지 않으며, 긴 도움말은 짧은 팁이 되었습니다. 안내와 오류 메시지가 네 언어로 나옵니다.
  • 노드 그래프 실행 중 편집: 실행 중인 그래프를 고쳐도(별도 편집기 창 포함) 진행 중인 대기·쿨다운·포즈와 변수 값이 이어집니다. 두 창에서 같은 그래프를 함께 고치면 덮어쓰지 않고 알려 줍니다.
  • 전체 코드 검토: 앱 전체를 검토해 녹화, 화면 공유, 모션, 사진, 조명 등에서 찾은 문제를 고쳤습니다.
  • 기존 .vavatar를 그대로 사용할 수 있으며 재내보내기는 필요하지 않습니다.

2026/10/28 — v2.3.0#

  • 장시간 방송 최적화: 오래 켜 두어도 CPU·GPU·메모리·VRAM 사용이 쌓이지 않도록 전반을 손봤습니다. 유체와 물리, 아바타, 렌더링, 출력, 녹화를 정리하고 시작할 때 쓰는 메모리를 줄였습니다. 쓰지 않는 출력과 웹캠, 숨겨 둔 창은 자원을 놓아 줍니다.
  • 화면 공유 HDR 색: HDR 모니터의 화면과 창을 공유할 때 색이 SDR 화면과 같은 밝기로 보입니다. 세션을 다시 시작할 때 종료되던 문제도 수정했습니다.
  • 화면 공유 편집 작업 공간: 큰 편집기가 소스 패널 중심의 작업 공간으로 바뀌었습니다. 그림과 글자 소스를 추가하고, 레이어와 프리셋을 한곳에서 다룹니다. 프레임 속도는 방송 출력과 화면 공유 모두 「프레임 속도(FPS)」 하나로 고릅니다.
  • 모션 시퀀서 .anim 저장: 모션 시퀀서에서 저장하면 재생 중인 아바타마다 휴머노이드 .anim이 함께 만들어집니다. 애니메이션 노드에서 이 모션을 골라 재생·정지·속도 조절·반복할 수 있고, 표정 셰이프 키도 함께 재생됩니다. 아바타 하나를 .anim 또는 .vmd로 내보낼 수도 있습니다.
  • 모션 플레이어와 시퀀서: 스튜디오 › 포즈에 모션 플레이어가 생겼습니다. 저장한 시퀀스를 장면의 아바타들이 한 시계에 맞춰 재생하고, 조명·소품·룸·카메라 트랙도 함께 움직이며 거꾸로도 재생합니다. 시퀀서에는 카메라 트랙(선택), 메시 계층별 표정 슬라이더, Alt+화살표로 키를 한 프레임씩 옮기기, 루프 끝·마커 끌기가 생겼습니다. .vmd 내보내기는 VRM 표정을 MMD 표준 모프로, 첫 방향광을 조명 모션으로 씁니다.
  • 소리 재생 노드와 변수: 노드 편집기에 그래프에서 소리를 재생하는 노드가 생겼습니다. 변수, 카메라 연출 켜기·끄기 노드, 입력 값 복사·붙여넣기, 숫자 라벨 끌어서 값 바꾸기, 목록 순서 끌어서 바꾸기도 쓸 수 있습니다.
  • 간편 설정 규칙 스위치: 간편 설정의 규칙마다 켜기·끄기 스위치가 생겼습니다. 노드 편집기에서 고친 규칙도 스위치가 그대로 유지됩니다. 규칙 줄은 한 줄에 읽히도록 정리했습니다.
  • 숫자 칸과 라벨: 숫자 입력 칸의 숫자가 가운데에 놓입니다. 색 채널, 자릿수 입력, 사용자 지정 크기, 모션 숫자 칸도 같습니다. 영어·일본어·중국어·한국어 라벨이 줄에 맞게 줄고, 한글이 단어 단위로 줄바꿈됩니다.
  • 액체 붓기: 액체를 처음 부을 때 잠깐 멈추던 현상을 고쳤습니다.
  • 기존 .vavatar를 그대로 사용할 수 있으며 재내보내기는 필요하지 않습니다.
