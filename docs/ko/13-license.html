13. 에디션 · 라이선스 · 고지#

에디션#

Avatar Live는 유료 소프트웨어이며 BOOTH에서 판매합니다.

Basic Pro
이용 범위 개인적·비공개 사용 방송(라이브 스트리밍)·영상 공개·상업적 이용
아바타·트래킹·메뉴·조명·효과 ✅ ✅
내 표정 · 자동 표정 ✅ ✅
Spout2 · 가상 카메라 · 화면 공유 ✅ ✅
최대 출력 1080p 4K
워터마크 있음 없음
포징 · 오브젝트 · 화면 공유 추가 소스 — ✅

방송, 영상 업로드, 의뢰 작업 등 공개·상업적 용도로 쓰려면 Pro가 필요합니다. Basic은 개인적인 사용을 위한 기본 에디션입니다.

라이선스 이용 조건 (요약)#

  • 1인 1기기입니다.
  • 다른 PC로 옮기는 것은 딱 1회만 가능합니다. 옮긴 뒤에는 이전 PC에서 쓸 수 없고, 이후에는 어떤 경우에도 다시 옮길 수 없습니다 (문의하셔도 옮겨 드릴 수 없습니다).
  • 활성화와 라이선스 확인에 인터넷 연결이 필요합니다.
  • 재배포, 판매, 대여, 공유, 리버스 엔지니어링, 수정, 라이선스 확인의 우회는 금지됩니다.

전체 조건은 이용약관을 따릅니다.

업그레이드와 체험판#

  • Basic → Pro 업그레이드: Basic을 한 번 더 구매해서 설정 › 라이선스 › Pro로 업그레이드에 입력하면 이 PC의 라이선스가 Pro가 됩니다 (Basic 2개 = Pro). 합친 구매는 이 라이선스에 속하며 다른 PC에서 따로 쓸 수 없습니다. 이미 Pro인 PC에는 Basic을 더 넣을 수 없습니다.
  • 체험 중에 구매하면 설정 › 라이선스 › 구매한 코드 입력에 넣으세요. 구매한 라이선스가 체험판을 대신합니다.
  • 체험판이 끝나면 "체험판이 끝났습니다" 안내와 함께 입력 화면이 나옵니다. 계속 쓰려면 구매한 라이선스를 입력하세요.

실험적 기능#

"실험적"으로 표시된 기능(Ultraleap, iFacialMocap, OSC·VMC, 혀·볼 카메라 감지)은 정상 동작을 예상하지만, 해당 장치·앱이 개발자 환경에서 아직 테스트되지 않은 기능입니다.

내가 만든 파일#

  • Exporter로 만든 .vavatar / .vprop 파일은 사용자 소유입니다. 그 안의 아바타·의상·셰이더 권리는 각 제작자에게 있으니, 공유할 때는 원 제작자의 약관을 따르세요.
  • 방송·영상에 나오는 아바타의 이용 조건도 각 제작자의 약관을 따르세요.

독립성 고지#

Avatar Live와 Avatar Exporter는 Curious Bobby Co.가 독자적으로 개발한 소프트웨어입니다.

  • VRChat SDK의 코드를 사용하거나 포함하지 않으며, VRChat SDK를 배포하지 않습니다.
  • NDMF, Modular Avatar, VRCFury 등 아바타 제작 도구를 포함하거나 배포하지 않습니다. 이러한 도구는 사용자가 자신의 프로젝트에 직접 설치한 것이 사용자 환경에서 동작합니다.
  • VRChat 서버나 계정과 통신하지 않으며, 다른 사람의 아바타를 가져오는 기능이 없습니다.
  • VRChat Inc. 및 각 도구의 개발자와 제휴하거나 승인을 받은 제품이 아닙니다.

오픈소스 고지#

포함된 오픈소스 구성 요소는 각 구성 요소의 라이선스를 따릅니다. 고지는 프로그램과 Exporter 패키지에 동봉되어 있습니다.

상표#

VRChat은 VRChat Inc.의 상표입니다. 그 밖의 제품명은 각 소유자의 상표이며, 이 문서에서는 호환성 설명을 위해서만 언급합니다.
