에디션과 라이선스#

Avatar Live의 사용권, 외부 프로그램의 사용권, 아바타·소품의 사용권은 각각 다릅니다.

가격과 판매 조건은 BOOTH 상품 페이지의 표시를 따릅니다.

OBS・카메라 출력에는 Spout2・NDI・가상 카메라가 포함됩니다. 기본 화면 효과는 포스트 프로세싱, 추가 화면 효과는 후처리 효과와 환경 광 차폐입니다.

활성화와 업그레이드#

  • 라이선스 1개는 1명이 1대의 PC에서 사용합니다.
  • 활성화와 라이선스 확인에는 인터넷 연결이 필요합니다.
  • 다른 PC로 직접 옮기기는 1회 가능합니다. 이후 이전은 문의를 통해 검토합니다.
  • Basic → Pro: 업그레이드를 구매한 뒤 설정 → 라이선스 → 다른 코드 입력에 넣습니다.
  • 체험 중 구매: 설정 → 라이선스 → 다른 코드 입력에 라이선스를 넣습니다.
  • DLC 방 팩: BOOTH 주문번호를 같은 다른 코드 입력에 넣습니다. 라이선스는 그대로이고, 그 PC에서 방 팩을 받을 수 있게 됩니다. 다른 PC로 옮기기는 1회 가능합니다.

프로그램·라이선스 코드의 재배포·대여·공유·수정이나 보호 수단 우회는 허용되지 않습니다. 자세한 내용은 이용약관을 따릅니다.

NDI#

NDI®는 Vizrt NDI AB의 등록 상표입니다. NDI 공식 사이트

네트워크 영상 전달에 사용하는 외부 기술입니다.

  • Avatar Live에 포함된 NDI Runtime은 NDI SDK 라이선스를 따릅니다.
  • 라이선스 전문은 프로그램의 AvatarLive_Data/Plugins/x86_64/Processing.NDI.Lib.Licenses.txt에 있습니다.
  • NDI Tools는 별도로 받는 프로그램입니다. Avatar Live에 포함되지 않습니다.
  • OBS에서 받는 DistroAV는 별도 프로젝트이며 해당 프로젝트의 라이선스를 따릅니다.

NDI SDK 이용 조건 · NDI 연결 방법

Spout2#

같은 Windows PC에서 프로그램끼리 영상을 전달하는 외부 기술입니다.

  • Avatar Live의 Spout2 연동에 사용한 KlakSpout은 Unlicense를 따릅니다. 배포본의 서드파티 고지에서 전문을 확인할 수 있습니다.
  • OBS Spout2 Capture 플러그인은 별도 설치 프로그램이며 해당 프로젝트의 GPL v2 조건을 따릅니다.
  • Avatar Live 구매가 OBS 플러그인의 저작권이나 별도 권리를 이전하지는 않습니다.

Spout2 연결 방법

VB-CABLE#

VB-Audio Software가 제작한 별도의 가상 오디오 드라이버입니다.

  • VB-CABLE은 Donationware이며 사용·배포·라이선스 조건은 VB-Audio가 정합니다.
  • 설치 버튼은 VB-Audio의 원본 드라이버를 설치하는 경로입니다. Avatar Live가 개발한 드라이버는 아닙니다.
  • 필요한 라이선스와 후원은 VB-Audio 공식 라이선스 안내를 확인하세요.
  • Avatar Live의 구매·Pro 업그레이드가 VB-CABLE의 별도 라이선스를 대신 부여하지 않습니다.

아바타와 소품#

아바타·의상·텍스처·셰이더·포즈·3D 소품 등 콘텐츠의 권리는 각 원제작자에게 있습니다.

방송에 사용할 때에는 아래 사항과 각 원제작자의 이용 규약을 확인하고 사용하시기 바랍니다.

고려할 사항 확인할 규약
방송·영상 공개 원제작자가 방송·상업적 사용을 허용하는지 확인합니다.
파일 수정·변환 원제작자의 개조·변환 조건을 확인합니다.
원격 세션 전송 다른 PC로 데이터 전송과 임시 저장이 허용되는지 확인합니다.
다른 사람에게 제공 재배포 또는 제3자 제공 허락을 확인합니다.

아바타와 소품을 사용하기 전에 각 원제작자의 권리와 이용 규약을 확인하세요. 필요한 이용 허락을 받고 규약을 지킬 책임은 이용자에게 있습니다.

Avatar Live의 구매나 기능 사용은 콘텐츠의 이용 허락을 대신하지 않습니다. Avatar Live 및 개발사는 이용자의 콘텐츠 사용·수정·전송·배포로 발생하는 권리 침해나 분쟁에 책임을 지지 않습니다.

오픈소스와 독립성#

포함된 오픈소스 구성 요소는 각각의 라이선스를 따릅니다. 프로그램과 Exporter에 동봉된 고지를 확인하세요.

Avatar Live와 Avatar Exporter는 Curious Bobby Co.의 독립 제품입니다. VRChat SDK·NDMF·Modular Avatar·VRCFury를 배포하지 않으며, 각 개발사의 공식 제품이나 승인 제품이 아닙니다. VRChat 계정과 서버에 접속하지 않습니다.

실험적 기능#

앱에서 실험적으로 표시된 기능은 장치와 환경에 따라 동작이 다를 수 있습니다. 구매 전 필요한 장치와 지원 범위를 확인하세요.
