기능

VRChat에서 보던 그 아바타 그대로.

다시 만들지 않아도 됩니다. 아바타에 담긴 것들이 그대로 움직입니다.

VRM 변환 없이

아바타 프로젝트에서 한 번 내보내면 끝. 아바타를 고쳐도 다시 내보내기만 하면 됩니다.

원래 셰이더 그대로

Poiyomi, lilToon 등 아바타에 쓴 셰이더를 그대로 보여 줍니다.

PhysBone과 메뉴 그대로

머리카락의 흔들림, 옷 토글, 표정 버튼까지 VRChat과 같은 설정으로 움직입니다.

얼굴부터 전신까지

웹캠 하나로 표정과 시선, 손가락 관절, 전신까지. iPhone과 VMC(전신 트래커 · 장갑)도 부위별로 섞어 씁니다.

키보드 · 마우스 손 동작

손이 화면에 없을 때도 타이핑과 마우스에 맞춰 손이 움직입니다. 입력한 글자는 기록하지 않습니다.

방송과 화면 공유

OBS에는 투명 배경으로, Discord에는 게임과 아바타를 한 화면으로 보냅니다.

사용 방법

VRChat 아바타는 세 단계, VRM은 바로.

  1. 1

    Unity 프로젝트 열기

    VRChat에 업로드하던 아바타의 Unity 프로젝트(2022.3.22f1)를 엽니다.

  2. 2

    Exporter로 내보내기

    Curious Bobby - Avatar Exporter에서 버튼 한 번으로 .vavatar 파일을 만듭니다.

  3. 3

    AVATAR LIVE에서 시작

    파일을 열고 웹캠을 켜면 바로 움직입니다. 그 뒤로는 Unity가 필요하지 않습니다.

VRM 0.x·1.0 파일은 Unity 없이 바로 불러올 수 있습니다. VRChat 아바타를 .vavatar로 내보내려면 Unity 프로젝트가 필요하지만, .vrca 파일은 직접 열 수 없습니다. 내보내기 가이드 보기

FAQ

자주 묻는 질문

VRChat 아바타를 그대로 사용할 수 있나요?

네. VRChat에 업로드하던 아바타의 Unity 프로젝트에서 Exporter로 내보내면, 옷 · 액세서리 토글까지 Expression 메뉴가 VRChat과 똑같이 동작합니다. 셰이더와 PhysBone도 그대로입니다.

Unity 프로젝트가 필요한가요?

VRM 0.x·1.0 파일은 Unity 없이 바로 불러올 수 있습니다. VRChat 아바타를 .vavatar로 내보낼 때는 Unity 프로젝트(2022.3.22f1)가 필요하지만, 내보낸 뒤에는 Unity 없이 사용합니다.

VRM 파일만으로 사용할 수 있나요?

네. VRM 0.x와 1.0 파일을 Avatar Live에서 직접 불러올 수 있습니다. 다만 일부 VRM 0.x 모델은 특수 셰이더 호환성 문제로 불러오지 못할 수 있습니다.

어떤 셰이더를 지원하나요?

아바타에 쓴 셰이더를 그대로 보여 줍니다. Poiyomi, lilToon 등 200개가 넘는 셰이더에서 테스트했습니다.

OBS 없이 Discord 화면 공유가 가능한가요?

네. 화면 공유를 켜고 Discord에서 'Avatar Live Share Output'을 고르면 게임과 아바타가 함께 공유됩니다.

Basic과 Pro의 차이는 무엇인가요?

Basic은 개인 사용(친구와의 비공개 Discord 공유 포함), Pro는 방송 · 영상 공개 · 상업적 이용을 위한 에디션입니다. Pro는 4K 출력, 워터마크 없음, 포징, 포즈 라이브러리, 오브젝트, 방송 연동과 노드 편집기를 지원합니다.

시청자 이벤트에 아바타가 반응하게 할 수 있나요?

네. Pro에서 Twitch · 치지직 · SOOP을 연결하면 팔로우 · 후원 · 채널 포인트 같은 이벤트에 맞춰 물건 던지기, 액체 뿌리기, 조명 바꾸기 등을 실행합니다. 방송 연동은 지금 베타라 문제가 있으면 앱의 오류 보고로 알려 주세요.

디스코드 친구도 아바타를 움직일 수 있나요?

네. 디스코드 서버나 그룹 DM에 Avatar Live 앱을 추가하고 연결 코드로 채널을 이으면, 친구가 버튼이나 /반응 명령으로 반응을 보냅니다. 내 Avatar Live가 켜져 있을 때만 동작합니다.

DLC 방은 Basic에서도 쓸 수 있나요?

네. BOOTH에서 산 DLC 방은 Basic에서도 쓸 수 있습니다. 주문번호를 설정 → 라이선스 → 다른 코드 입력에 넣으면 방 목록에 나타납니다. 기본 내장 방과 방 조각 편집은 Pro 기능입니다.

Windows 이외의 운영체제를 지원하나요?

Windows 10 / 11(64비트)만 지원합니다.
