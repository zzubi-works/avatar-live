Windows용 VTuber 소프트웨어

VRChat 아바타를
그대로 VTuber로#

VRM으로 바꾸지 않습니다. 셰이더·흔들리는 본·표정 메뉴·옷 토글을 다시 세팅하지 않습니다.
VRChat에서 보던 내 아바타가 웹캠과 마이크로 움직이고, OBS·Discord·Zoom으로 바로 나갑니다.

BOOTH에서 구매 가이드 시작하기 →

지금까지는 이랬습니다#

무료 VTuber 프로그램은 대부분 VRM 형식을 기준으로 합니다. VRChat 아바타를 쓰려면 VRM으로 변환하고, 셰이더를 다시 만들고, 흔들리는 본과 표정·옷 토글을 다시 설정해야 했습니다. 결국 VRChat에서 보던 내 아바타와 방송에 나오는 아바타가 달라집니다. 아바타를 고칠 때마다 이 과정을 반복해야 했고요.

Avatar Live는 이렇게 다릅니다#

🎨

원래 셰이더 그대로#

Poiyomi·lilToon 등 아바타에 쓴 셰이더를 바꾸지 않고 그대로 씁니다.

💇

PhysBone 그대로#

머리카락·치마·꼬리의 흔들림을 VRChat과 같은 설정으로. 마우스로 잡아당기고 포즈 고정도 됩니다.

📋

표정 메뉴 그대로#

VRChat Expression 메뉴의 토글·버튼·Radial·Puppet, 손 제스처 표정, Contact·Parameter Driver까지 동작합니다.

🙂

얼굴 트래킹 자동 연결#

아바타가 가진 얼굴 트래킹 설정을 그대로 씁니다. 안내를 따라 하는 자동 얼굴 설정.

⌨️

책상 손 동작#

손이 카메라에 안 보여도 실제 키보드·마우스에 맞춰 아바타가 타이핑합니다. 입력한 내용은 기록하지 않습니다.

🎮

Discord에 게임 + 아바타#

OBS 없이 Discord 화면 공유에 게임과 아바타를 합성해서 보냅니다. 나는 게임만 봅니다.

한눈에 비교#

VRM 기반 프로그램 (일반적인 경우) Avatar Live
아바타 준비 VRM 변환 + 셰이더·흔들림·표정 재설정 Exporter 버튼 한 번
셰이더 VRM용 셰이더로 바꿔야 하는 경우가 많음 원래 셰이더 그대로
흔들리는 본 SpringBone으로 다시 설정 PhysBone 그대로
옷·헤어 토글, 표정 메뉴 대부분 다시 만들어야 함 VRChat 메뉴 그대로
FX 애니메이터·Contact 기믹 동작하지 않음 동작
아바타 수정 반영 변환부터 다시 다시 내보내기만

이것도 됩니다#

  • Spout2(OBS, 투명 배경) · 가상 카메라(Zoom·Discord·Teams) · Discord 화면 공유 · PNG 사진
  • 조명 프리셋 10종과 라이트 직접 편집, 블룸·색 보정·피사계 심도 등 효과
  • 게임 중에도 쓰는 전역 단축키와 퀵 액션 버튼
  • 창을 닫아도 트레이에서 계속 송출

이런 분께는 맞지 않을 수 있어요#

  • VRChat 아바타의 Unity 프로젝트가 없는 경우 (VRM·.vrca 파일만으로는 쓸 수 없습니다)
  • Live2D(2D) 아바타, macOS·Linux 사용자

방송·영상 공개·상업적 이용에는 Pro 에디션이 필요합니다. Basic은 개인적인 사용을 위한 기본 에디션입니다. (에디션 비교)
