포징#

뼈를 직접 움직여 아바타 자세를 만들고 저장합니다.

시작: 씬 › 포징 › 포징 모드, 또는 왼쪽 씬 도구의 사람 아이콘

조작 하는 일
뼈 클릭 (Ctrl: 여러 개) 뼈 선택
뼈 끌기 움직이기 (손·발을 끌면 팔·다리 전체)
링 끌기 회전 (Ctrl: 15° 단위)
Ctrl + Z / Ctrl + Y 되돌리기 / 다시 하기
원래대로 선택한 뼈를 원래 동작으로
좌우 좌우 반전 · 왼쪽을 오른쪽에 복사 · 오른쪽을 왼쪽에 복사
전체 초기화 처음 자세로
손가락 뼈 표시 손가락 뼈 보이기

포징 모드를 끄면 자세가 풀립니다. 먼저 저장하세요.

자세#

항목 하는 일
+ 자세 추가 현재 자세 저장 · .anim 파일 불러오기… · 이 자세를 책상 자세로 저장 (팔·손)
자세 클릭 적용 / 해제
자세 수정 저장한 자세 고치기
이름 변경 / 현재 자세로 덮어쓰기 / 삭제 자세 관리
휴식 자세로 지정 (전신) 얼굴이 안 보이면 이 자세로
책상 자세로 쓰기 (팔·손) 책상 손 자세로 쓰기

아바타 메뉴의 자세 카드에서도 버튼 하나로 자세를 켜고 끕니다.

오브젝트#

텍스트·이미지·도형·3D 모델을 씬이나 아바타에 붙입니다 (모자, 머리 위 글씨, 의자, 책상 등).

항목 하는 일
기본 환경 (바닥 격자) 바닥 표시
+ 오브젝트 추가 텍스트 · 이미지 파일… · 3D 모델 (.vprop)… · 도형 (큐브·구·원기둥·캡슐·판)
보이기 스위치 · ⋯ 숨기기, 이름 변경 · 복제 · 처음 위치로 · 삭제
색상 색 바꾸기
붙일 곳 씬에 고정 / 머리 / 가슴 / 몸통 / 왼손 / 오른손
부드럽게 따라오기 뼈를 살짝 늦게 따라가기
비율 고정 / 크기 크기 조절
항상 맨 앞에 보이기 / 항상 카메라를 향하기 보이는 방식
텍스트: 폰트 · 굵게 · 기울임 · 외곽선 · 배경 판 글자 꾸미기

뷰에서는 씬 도구(이동·회전·크기)로 옮깁니다. 텍스트는 더블클릭하면 바로 고칠 수 있습니다.

3D 모델 만들기#

Unity에서 Curious Bobby → Prop Exporter로 GameObject나 프리팹을 .vprop으로 내보냅니다. 모델의 흔들리는 본과 애니메이션도 함께 동작합니다.

화면 공유 추가 소스#

출력 › 화면 공유 › 추가 소스에서 창이나 모니터를 더 겹칩니다 (채팅 창, 음악 플레이어 등).

항목 하는 일
소스 추가 창 또는 디스플레이 추가
👁 보이기 / 숨기기
⋯ 앞으로 · 뒤로 · 처음 위치로 · 삭제

내 표정#

아바타의 쉐이프키로 표정을 직접 만듭니다.

  1. 새 표정 만들기
  2. 쉐이프키 검색 → + 로 추가 → 세기 조절
  3. 이 표정이 보이는 동안: 눈 깜빡임 끄기 · 눈 추적 끄기 · 입 추적 끄기
  4. 저장
  • .anim 불러오기로 Unity에서 만든 표정 애니메이션도 쓸 수 있습니다.
  • 아바타 메뉴·씬의 내 표정 카드에서 눌러서 켜고 끕니다.

자동 표정#

웃거나 놀라면 아바타가 정해 둔 표정을 자동으로 냅니다.

항목 하는 일
자동 표정 켜기 / 끄기
감지 표정 미소 · 놀람 · 화남 · 슬픔 · 윙크(왼쪽/오른쪽) · 삐죽 · 졸림
보여 줄 표정 내 표정 · 제스처 · 아바타 메뉴 항목 · 표정 클립 중에서 연결
기준값 얼마나 확실하게 지어야 켜질지
타이밍 부드럽게 · 시작 지연 · 최소 유지

표정 클립은 Exporter에서 내보낼 때 넣은 추가 표정입니다 (2장).
