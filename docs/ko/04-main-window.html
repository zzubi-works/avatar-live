4. 메인 화면#

v2.0.0의 창은 항상 작업용 씬 뷰입니다. 카메라가 방송으로 나가더라도 내 창은 아바타·조명·소품을 편집하는 용도로 쓸 수 있습니다.

왼쪽 메뉴에서 기능 찾기#

메뉴 실제로 바뀌는 대상
메뉴 현재 선택한 아바타의 VRChat Expression 메뉴, 표정, 제스처·토글. 5장
장치 어느 카메라·마이크·트래커의 신호를 읽는지, 부위별 입력 소스와 연결. 6장
동작 얼굴·머리·팔·손가락·몸의 움직임, AFK·립싱크·추적 복귀. 7장
스튜디오 장면, 아바타 배치, 조명, 방, 카메라, 효과. 8장
출력 Spout2/NDI·가상 카메라·화면 공유·녹화·원격 세션. 9장
설정 성능, 창, 화면 크기, 단축키, 파일, 업데이트·진단. 10장

왼쪽 메뉴를 누르면 설정 패널이 나타나며, 패널의 핀을 켜면 다른 곳을 눌러도 자동으로 접히지 않습니다. 패널 바깥 영역에서 마우스 휠은 기본적으로 카메라 거리/줌을 바꾸지만, 패널 위의 휠은 설정 스크롤에 사용됩니다. 잘못 스크롤로 줌이 변한다면 마우스가 패널 바깥에 있었는지 확인하세요.

작업용 씬 뷰와 방송 화면을 구별하기#

  • 하단 도구막대나 마우스로 씬 뷰를 돌리는 것은 내가 편집할 때 보이는 카메라를 바꾸는 동작입니다.
  • 스튜디오 카메라를 송출하면 외부 OBS·NDI는 저장된 방송 카메라의 구도를 받습니다. 따라서 내 작업용 시점이 바뀌어도 시청자 화면이 반드시 따라 바뀌는 것은 아닙니다.
  • 씬 뷰를 송출 중이라면 앱에서 보는 시점과 외부 화면이 같아집니다. 방송 중 캐릭터 뒤쪽을 보려고 마우스를 돌릴 때 시청자에게도 뒷모습이 나갈 수 있습니다.
  • 출력 → 송출과 스튜디오 카메라에서 어떤 화면이 실제로 송출 중인지 확인하고, OBS 프로그램 화면을 기준으로 점검하세요.

하단 카메라·퀵액션 도구막대#

  • 얼굴 / 상반신 / 전신은 카메라가 현재 선택한 아바타에서 얼마나 멀리 있는지 빠르게 조정합니다. 얼굴은 표정 확인, 상반신은 일반 방송, 전신은 동작 확인에 좋습니다.
  • + 저장된 뷰는 지금의 위치·방향·렌즈를 카메라 프리셋으로 기록합니다. 다시 누르면 그 구도로 돌아갑니다. 아바타별로 저장된 뷰를 구분할 수 있습니다.
  • 카메라 잠금은 편집 중 실수로 마우스를 움직여 시점이 바뀌지 않도록 합니다. 캐릭터의 트래킹을 고정하는 것이 아니며, 잠겨도 방송 대상 아바타는 정상적으로 움직입니다.
  • 카메라 모드의 고정 / 자유 / 궤도는 마우스로 조작할 수 있는 방식입니다. 자유는 내가 보는 방향을 바꾸고, 궤도는 캐릭터를 중심으로 돕니다. 저장된 스튜디오 카메라의 추적 방식과는 별도입니다.
  • **FOV(화각)**를 줄이면 캐릭터가 크게 보이고 배경이 좁아지며, 늘리면 주변을 넓게 담습니다. 마우스 회전/이동 속도를 높이면 같은 손 움직임으로 시점이 더 멀리 또는 빠르게 이동하므로 멀미가 난다면 낮추세요.
  • 도구막대의 불투명도는 꺼진 것처럼 보이는 문제가 아닙니다. 평소 60% 정도로 표시하다 마우스를 올리면 진하게 보이도록 할 수 있습니다. 우클릭해 위치와 표시 방식을 변경할 수 있습니다.
  • 퀵액션은 즐겨 쓰는 표정·토글·저장 포즈를 도구막대에 올린 것입니다. 눌렀을 때 어떤 표정 또는 파라미터가 변경되는지는 아바타 메뉴를 참고하세요.

화면 표시·편집·종료#

  • F1은 아바타만 깨끗하게 보여주도록 앱 UI를 숨기거나 다시 표시합니다. 앱 창이 활성화된 상태에서 사용합니다. 방송 출력의 배경 투명도와는 별개입니다.
  • 전체 초기화/물리 초기화는 끼이거나 엉킨 머리카락 등 물리 움직임을 기본 상태로 복구할 때 씁니다. 저장한 아바타 원본 파일을 새로 만드는 기능은 아닙니다.
  • 창의 X 버튼은 설정의 동작에 따라 종료 또는 트레이 이동이 됩니다. 방송·가상 카메라 출력 중에는 트레이에서 계속 실행될 수 있으므로, 완전히 멈추고 싶다면 하단 전원 메뉴의 종료 기능을 사용하세요.
  • 설정 검색은 오른쪽 상단에서 AFK, 얼굴, 단축키, Spout2 등을 입력해 관련 페이지와 해당 카드로 이동합니다. 직접 모든 메뉴를 펼칠 필요가 없습니다.
