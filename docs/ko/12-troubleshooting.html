문제 해결#

증상에 맞는 항목부터 확인하세요. 설정을 찾기 어렵다면 상단 돋보기에서 이름을 검색할 수 있습니다.

시작과 아바타#

증상 먼저 해 볼 일
시작이 잘 안 됩니다 Shift를 누른 채 실행해 웹캠·마이크 없는 안전 시작을 사용합니다.
파일이 변경되었다고 합니다 구매처에서 받은 원본 ZIP을 새 폴더에 풀어 실행합니다.
아바타가 보이지 않습니다 얼굴·상반신·전신 구도로 다시 맞춥니다.
일부가 분홍색입니다 원본 Unity 프로젝트의 재질·셰이더를 확인한 뒤 다시 내보냅니다.
머리카락이 엉켰습니다 상단 초기화를 누릅니다.

얼굴과 손#

증상 먼저 해 볼 일
웹캠이 켜지지 않습니다 다른 앱이 카메라를 사용 중인지 확인합니다.
아바타가 움직이지 않습니다 장치 → 트래킹 소스에서 각 부위가 실제 연결한 장치를 쓰는지 확인합니다.
얼굴 방향이 틀어집니다 정면을 보고 정면 보정을 누릅니다.
윙크가 안 됩니다 깜빡임 방식을 따로로 바꿉니다.
표정이 너무 크거나 작습니다 자동 얼굴 설정을 하거나 얼굴 조정의 민감도를 맞춥니다.
손가락이 떨립니다 손 떨림 보정을 조금 높입니다.
손을 뻗으면 팔이 뒤틀립니다 실험적 손 깊이 추정을 끄고 이전 팔 방식과 비교합니다.
대기 자세로 바뀌지 않습니다 대기 자세를 지정하고 메뉴 → 기본·AFK 자세의 기다리는 시간을 확인합니다.
iPhone 연결 후 반응이 없습니다 휴대폰 앱이 PC 주소로 보내는지 확인하고 정면에서 시작 보정을 기다립니다.
VMC 자세가 어긋납니다 입력 상태를 확인하고 T자세·정렬로 맞춥니다.

OBS와 영상 출력#

증상 먼저 해 볼 일
Spout2 Capture가 없습니다 OBS용 Spout2 플러그인을 설치한 뒤 OBS를 다시 실행합니다.
NDI Source가 없습니다 DistroAV와 해당 버전이 요구하는 NDI Runtime을 설치합니다.
배경이 검게 나옵니다 Avatar Live 배경을 투명으로, OBS 소스는 알파 합성으로 맞춥니다.
송신 이름을 바꾼 뒤 안 나옵니다 OBS 소스에서 새 이름을 다시 선택합니다.
가상 카메라가 목록에 없습니다 장치를 등록한 뒤 받는 앱을 완전히 다시 실행합니다.
내 화면과 방송 구도가 다릅니다 송출 대상이 씬 뷰인지 스튜디오 카메라인지 확인합니다.

자세한 설치 순서는 출력을 확인하세요.

화면 공유#

  • Discord 목록에 없음: 화면 공유를 켜고 애플리케이션 탭에서 Avatar Live Share Output을 찾습니다.
  • 게임 화면이 검음: 게임을 테두리 없는 창 모드로 바꿔 봅니다.
  • 공유 소리 없음: 오디오 대상과 앱 볼륨을 확인합니다. 가상 오디오 장치 안내가 있으면 VB-CABLE 안내를 확인합니다.
  • 통화 소리가 다시 들림: 공유할 앱에 Discord가 포함되어 있는지 확인합니다.

원격 합방#

합방 세션은 방송 → 연결 맨 아래에 있습니다. 방장이 서버를 켰는지, 참가 주소·포트·비밀번호가 맞는지부터 확인합니다. 외부 친구가 접속되지 않으면 연결이 안 될 때의 포트포워딩·방화벽 안내를 펼쳐 보세요.

상대가 대체 아바타로 보이면 아바타 보기와 데이터 전송 동의를 확인합니다. 전송이 허용되지 않는 모델은 대체 아바타로 사용하세요.

방송 연동이 안 될 때#

방송 연동은 베타입니다. 이벤트가 와도 아바타가 반응하지 않으면 차례로 확인합니다.

  1. 방송 → 연결에서 그 플랫폼의 카드가 연결됨인지 봅니다. 로그인이 풀렸으면 스위치를 껐다 켜서 다시 로그인합니다.
  2. 방송 → 인터랙션에서 그 항목의 스위치가 켜져 있는지, 트리거의 최소 금액·보상 제목이 맞는지 봅니다.
  3. 항목의 ▶ 테스트로 반응이 나오는지 봅니다. 테스트도 안 되면 동작 설정(물건·그림이 비었는지)을 확인합니다.
  4. 쿨다운 안에 같은 이벤트가 다시 오면 실행되지 않습니다.
  5. 디스코드는 앱이 켜져 있고 채널이 연결된 채널 목록에 있어야 합니다. 친구에게 "꺼져 있어요"가 보이면 앱이나 디스코드 스위치가 꺼진 상태입니다.

그래도 안 되면 문제가 생긴 직후 설정 → 진단 → 오류 리포트 보내기로 알려 주세요. 보고서에 다음이 들어가 원인을 따라갈 수 있습니다.

  • 플랫폼·디스코드 연결별 상태 기록(끊긴 이유와 코드), 로그인 권한, 구독 응답, 실패한 요청
  • 최근 이벤트 16개와, 간편 설정 항목·그래프가 각 이벤트에 무엇을 했는지 또는 왜 하지 않았는지

진단 자료에서는 토큰·인증 헤더·쿠키·코드·세션 키·주문번호·이메일·파일 경로가 가려집니다. 보고서는 사용자가 보내기를 고를 때만 전송됩니다.

화면이 느리거나 흐릴 때#

  1. 출력 해상도와 FPS를 낮춰 봅니다.
  2. 멀티뷰의 갱신률과 칸 수를 줄입니다.
  3. 사용하지 않는 카메라별 Spout2 출력을 끕니다.
  4. 환경 광 차폐·피사계 심도·볼류메트릭 조명 등 효과를 하나씩 꺼 봅니다.
  5. 전체가 뿌옇다면 블룸 세기·임계값과 블러를 확인합니다.

해결되지 않으면#

설정 → 진단 → 오류 리포트 보내기에서 다음 내용을 적습니다.

  • 어떤 버튼을 누르거나 설정을 바꿨는지
  • 무엇이 이상하게 보였는지
  • 사용하는 장치와 아바타 종류
  • 다시 같은 문제가 생기는 순서

실제 전송은 사용자가 선택할 때 진행됩니다.

지원 범위#

  • .vavatar와 VRM 0.x·1.0 아바타
  • 아바타의 표정 메뉴·애니메이터·PhysBone 등 지원된 기능
  • 아바타에 포함된 얼굴 추적 설정과 표정
  • 웹캠·마이크·iPhone·VMC 입력

일부 VRM 0.x의 특수 셰이더는 지원되지 않을 수 있습니다. 앱에서 실험적으로 표시한 기능은 장치와 환경에 따라 결과가 다를 수 있습니다.
