12. 문제 해결#

해결되지 않는 버그나 문제는 설정 › 진단 › 오류 리포트 보내기로, 필요한 기능이나 개선 사항은 설정 › 정보 › 개선 사항 보내기로 알려 주세요.

시작 · 설치#

증상 해결 방법
"Windows의 PC 보호" 창 추가 정보 → 실행
"Avatar Live 파일이 변경되었습니다" BOOTH에서 받은 원본으로 다시 설치해 주세요. 아바타와 설정은 그대로입니다.
시작이 잘 안 됨 Shift를 누른 채 실행해서 안전 시작

아바타#

증상 해결 방법
일부가 분홍색으로 보임 VRChat 업로드가 정상인지 확인한 뒤 다시 내보내기
아바타가 보이지 않음 뷰의 빈 곳을 더블클릭
자세가 굳거나 머리카락이 엉킴 위쪽 ⟲
아바타 효과음이 들리지 않음 아바타 효과음은 재생되지 않습니다.

웹캠 · 얼굴#

증상 해결 방법
카메라가 켜지지 않음 다른 앱이 카메라를 쓰고 있는지 확인
표정이 작거나 크게 나옴 자동 얼굴 설정을 다시 하거나 얼굴 조정
아바타가 옆을 봄 정면 보정
윙크가 안 됨 깜빡임 방식을 따로로
PC가 무거움 트래킹 품질을 균형이나 절약으로
손 · 손가락이 떨림 장치 › 트래킹 소스 › 손 떨림 보정을 높이기
아바타가 움직이지 않음 장치 › 트래킹 소스에서 부위의 소스가 쓰지 않는 장치(VMC 등)로 되어 있지 않은지 확인
VMC로 받은 자세가 어긋남 VMC 설정에서 T자세 또는 정렬

마이크#

증상 해결 방법
"신호 없음" Windows 설정 › 개인정보 › 마이크에서 데스크톱 앱 허용
잡음에 입이 움직임 배경 소음 측정
입이 덜 움직임 음성 보정

출력 · 화면 공유#

증상 해결 방법
OBS에 Spout2 소스가 없음 OBS에 Spout2 플러그인 설치
OBS에서 배경이 검게 보임 배경을 투명으로, OBS에서 Composite with alpha 선택
Discord 목록에 없음 화면 공유를 켠 뒤 애플리케이션 탭 확인
게임이 검게 보임 게임을 창 모드로
"Avatar Live Basic" 글씨 Basic 워터마크입니다. Pro에서는 표시되지 않습니다.

지원 범위#

내용
✅ VRChat 아바타 Expression 메뉴, 애니메이터, PhysBone, Contact, Constraint, Eye Look, LipSync
✅ 제작 도구 NDMF · Modular Avatar · VRCFury를 쓴 아바타
✅ 셰이더 Poiyomi, lilToon 등
✅ 얼굴 아바타 설정을 따름: VRCFaceTracking, ARKit 52개 쉐이프키(Perfect Sync), MMD 눈 모프
✅ 트래킹 웹캠(얼굴 · 팔 · 손 · 손가락), iPhone(iFacialMocap · FaceMotion3D), VMC(부위별: 팔 · 손 · 손가락 · 몸 · 머리 · 눈)
🧪 실험적 기능 Ultraleap, OSC, VMC 출력, 혀 · 볼 카메라 감지
⚠️ 지원하지 않음 아바타 효과음, AudioLink, 미러 감지, VRM 파일, Live2D, macOS · Linux

웹캠(전신 · 손가락 관절 포함), iPhone, VMC 입력은 실제 장비로 확인했습니다. 실험적 기능은 정상적으로 동작할 것으로 예상하지만, 아직 개발자 환경에서 모든 장치와 앱으로 테스트하지는 못해 앱에 실험적으로 표시해 두었습니다. 써 보시고 문제가 있으면 오류 리포트 보내기로 알려 주세요.

추가 지원 예정#

  • VRM 모델(.vrm, VRM 0.x / 1.0) 불러오기와 .vrma 애니메이션 재생
  • 퍼펙트 싱크 강화: 쉐이프키를 직접 연결하는 매핑, 웹캠 · iPhone별 얼굴 보정, 52개 표정을 하나씩 확인하는 도구
  • 휴대폰 얼굴 앱 추가: VTube Studio(iPhone), MeowFace(Android)
  • 편의 기능: 아바타를 다시 내보내면 자동 새로고침, 할 일이 없을 때 FPS 절약

※ 예정 기능과 시기는 변경될 수 있습니다.

자주 묻는 질문#

VRChat 계정이 필요한가요? 필요하지 않습니다. Avatar Live는 VRChat과 통신하지 않습니다.

방송에 써도 되나요? 방송, 영상 공개, 상업적 이용에는 Pro를 이용해 주세요. 친구와의 비공개 Discord 공유는 Basic으로도 할 수 있습니다.

키보드 입력이 기록되나요? 기록되지 않습니다. 책상 손 동작은 입력한 글자를 저장하거나 전송하지 않습니다.

아바타 파일을 다른 사람에게 줘도 되나요? 아바타와 의상 제작자의 이용 약관을 따라 주세요.
