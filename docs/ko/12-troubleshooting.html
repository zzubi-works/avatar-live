12. 문제 해결#

먼저 설정 › 진단을 확인하고, 해결되지 않으면 오류 리포트 보내기로 알려 주세요. 장치 문제로 시작이 안 되면 Shift를 누른 채 실행(안전 시작)해 보세요.

시작·설치#

증상 해결
"Windows의 PC 보호" 창 추가 정보 → 실행
"Avatar Live 파일이 변경되었습니다" BOOTH에서 받은 원본으로 다시 설치 (아바타·설정은 그대로)
활성화가 안 됨 인터넷 연결 확인 후 다시 시도
실행하면 창만 앞으로 옴 이미 실행 중입니다 (트레이 확인)

아바타#

증상 해결
일부가 분홍색 업로드가 정상인지 확인 후 다시 내보내기
"더 새로운 익스포터로 만든 파일입니다" Avatar Live 업데이트
머리·손이 안 움직임 휴머노이드 아바타인지 확인
아바타 효과음이 안 남 아바타 효과음은 재생되지 않습니다
아바타가 안 보임 뷰 빈 곳 더블클릭, 또는 씬 도구 ⌂
자세가 굳음, 머리카락이 엉킴 위쪽 ⟲ 초기화

웹캠·얼굴#

증상 해결
카메라 "실패" 다른 앱이 카메라를 쓰는지 확인
카메라 화면이 검음 렌즈 덮개, Windows 카메라 개인정보 설정 확인
표정이 작게/크게 나옴 자동 얼굴 설정 다시 하기, 얼굴 조정
아바타가 옆을 봄 정면 보정
윙크가 안 됨 깜빡임 방식 따로 또는 스마트
좌우가 반대 미러
CPU를 많이 씀 트래킹 품질 균형 또는 절약

마이크#

증상 해결
"신호 없음" Windows 설정 › 개인정보 › 마이크에서 데스크톱 앱 허용
"거의 무음" 믹서 앱을 쓴다면 그 앱의 가상 마이크 선택
소음에 입이 움직임 배경 소음 측정
입이 덜 움직임 음성 보정, 감도

출력#

증상 해결
OBS에 Spout2 소스가 없음 OBS에 Spout2 플러그인 설치
OBS에서 배경이 검음 배경 투명 + OBS Composite with alpha
가상 카메라가 Discord에 없음 가상 카메라 설치 후 Discord 완전히 껐다 켜기
4K가 1080p로 나감 Basic 에디션입니다 (Pro는 4K)
"Avatar Live Basic" 글씨 Basic 워터마크 (Pro는 없음)

Discord 화면 공유#

증상 해결
Discord 목록에 없음 화면 공유를 켜고 Discord 애플리케이션 탭 확인
검은 화면 Avatar Live를 관리자 권한 없이 실행, 게임을 창 모드로
소리가 안 감 Discord에서 소리 켜기, 가상 재생 장치 설치
소리가 두 번 들림 Discord 오디오 장치를 듣지 않는 장치로
영상이 검음 보호된 영상(DRM)은 캡처되지 않습니다

지원 범위#

내용
✅ VRChat 아바타 기능 Expression 메뉴·파라미터, FX 등 애니메이터, PhysBone, Contact, Constraint, Eye Look, LipSync
✅ 제작 도구 NDMF · Modular Avatar · VRCFury 등을 쓴 아바타
✅ 셰이더 Poiyomi, lilToon 등
✅ 얼굴 VRCFaceTracking, ARKit(Perfect Sync), MMD 눈 모프
⚠️ 동작 안 함 아바타 효과음, AudioLink, 미러·카메라 감지, Light Volumes, 사용자 스크립트
🧪 실험적 기능 Ultraleap, OSC·VMC, 혀·볼 카메라 감지 — 정상 동작을 예상하지만 해당 장치·앱이 개발자 환경에서 아직 테스트되지 않았습니다
❌ 미지원 VRM 파일, Live2D, macOS·Linux

추가 지원 예정#

  • VRM 모델(.vrm, VRM 0.x / 1.0) 불러오기와 .vrma 애니메이션 재생
  • 퍼펙트 싱크 강화: 쉐이프키를 직접 연결하는 매핑, 웹캠·iPhone별 얼굴 보정
  • 휴대폰 얼굴 앱 추가: VTube Studio(iPhone), MeowFace(Android)
  • 전신 트래킹 앱 연동 강화(VMC): 얼굴 앱과 몸 앱 동시 수신, 앉기·숙이기 반영 — TDPT, XR Animator 등
  • 데스크톱 마스코트 모드(투명 창), 마우스 커서 시선
  • 편의 기능: 아바타를 다시 내보내면 자동 새로고침, 할 일이 없을 때 FPS 절약

※ 예정 기능과 시기는 변경될 수 있습니다.

자주 묻는 질문#

Q. VRChat 계정이 필요한가요? 아니요. Avatar Live는 VRChat과 통신하지 않습니다.

Q. 방송에 써도 되나요? 방송·영상 공개·상업적 이용에는 Pro가 필요합니다.

Q. 키보드 입력이 기록되나요? 아니요. 책상 손 동작은 입력한 글자를 저장·기록·전송하지 않습니다.

Q. 아바타 파일을 다른 사람에게 줘도 되나요? 아바타·의상 제작자의 이용 약관을 따르세요.

Q. 아바타를 여러 개 동시에 띄울 수 있나요? 한 번에 하나입니다. 왼쪽 위 아바타 이름에서 바꿉니다.
