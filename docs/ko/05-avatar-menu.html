5. 아바타 메뉴#

메뉴 페이지에서 VRChat에서 쓰던 아바타 자체의 Expression 메뉴를 그대로 씁니다. 옷·헤어 토글, 표정 버튼, Radial, Puppet이 VRChat과 같이 동작합니다.

Expression 메뉴#

종류 하는 일
Toggle 켜기 / 끄기
Button 누르고 있는 동안 켜기
Sub Menu 하위 메뉴 열기 (뒤로로 돌아가기)
Radial Puppet 슬라이더로 값 정하기
Two Axis / Four Axis Puppet 패드로 방향 정하기

항목 우클릭#

항목 하는 일
퀵 액션에 추가 이 항목을 툴바 버튼으로
단축키 지정… 이 항목에 단축키 지정
즐겨찾기 메뉴 위 즐겨찾기에 추가
Parameter 정보 이 항목의 파라미터 보기

즐겨찾기#

즐겨찾기한 항목을 메뉴 맨 위에서 바로 씁니다. 하위 메뉴 안의 항목도 바로 조작할 수 있습니다.

손 제스처#

왼손 / 오른손 제스처(기본 · 주먹 · 펴기 · 가리키기 · 브이 · 락앤롤 · 총 · 엄지)를 골라 아바타의 제스처 표정을 냅니다.

  • 웹캠 손 모양으로 제스처 — 켜면 웹캠으로 추적한 손 모양이 제스처가 됩니다.

아바타 파라미터#

  • 기본값으로 되돌리기 — 모든 메뉴 값을 아바타 기본값으로 되돌립니다 (VRChat의 Reset Avatar와 같음).

옷 상태처럼 VRChat에서 저장되는 값은 다음 실행에도 그대로 유지됩니다.

퀵 액션#

자주 쓰는 동작을 버튼이나 키로 만듭니다.

추가하는 곳 - 메뉴 항목 우클릭 → 퀵 액션에 추가 - 설정 › 단축키 · 퀵 액션 › 퀵 액션 추가

넣을 수 있는 동작: 아바타 메뉴 항목 · 제스처 · 카메라 뷰 · 저장된 뷰 · 트래킹 리셋 · 조명 프리셋 · PhysBone 리셋 · 전체 초기화

버튼 우클릭: 이름 변경 · 표시 위치 (상단 HUD / 하단 툴바 / 단축키만) · 단축키 지정… · 제거

초기화와 모두 초기화#

초기화 모두 초기화
실행 위쪽 ⟲ 클릭, 설정 › 일반 ⟲ 우클릭, 설정 › 일반
되돌리는 것 트래킹, 손 자세, 눌린 버튼, PhysBone, Contact 위 + 모든 파라미터(옷 포함), 아바타 위치·크기, 자세, 카메라
그대로 두는 것 옷·토글, 조명, 카메라 오브젝트, 저장한 자세·표정, 설정
