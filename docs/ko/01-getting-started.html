1. 시작하기#

준비물#

항목 필요 사항
운영체제 Windows 10 / 11 (64비트)
그래픽 DirectX 11 지원 GPU
웹캠 일반 컬러 웹캠
마이크 립싱크용 (선택)
인터넷 활성화와 라이선스 확인에 필요
아바타 VRChat 아바타의 Unity 프로젝트 (Unity 2022.3.22f1)

에디션#

Basic Pro
이용 범위 개인 사용 (친구와의 비공개 Discord 공유 포함) 방송 · 영상 공개 · 상업적 이용
출력 최대 1080p · 워터마크 최대 4K · 워터마크 없음
포징 · 오브젝트 · 화면 공유 추가 소스 — ✅

방송이나 영상 공개처럼 다른 사람에게 보여 주는 용도라면 Pro를 선택해 주세요. 자세한 내용은 13장에 있습니다.

설치#

  1. BOOTH 구매 내역에서 ZIP 파일을 내려받습니다.
  2. 원하는 폴더에 압축을 풉니다.
  3. AvatarLive.exe를 실행합니다.

"Windows의 PC 보호" 창이 보이면 추가 정보 → 실행을 눌러 주세요.

💡 설치 폴더의 파일은 그대로 두는 것을 권장합니다. 파일이 바뀌면 Avatar Live가 시작되지 않을 수 있는데, 이때는 원본으로 다시 설치하면 됩니다. 아바타와 설정은 그대로 남습니다.

활성화#

처음 실행하면 제품 활성화 화면이 나옵니다. 구매할 때 안내받은 정보를 입력하고 활성화를 누르면 끝입니다.

라이선스는 1인 1기기입니다. 다른 PC로 옮기는 것은 본인이 직접 1회 할 수 있고, 그 뒤에는 부득이한 경우 문의를 통해 도와드리고 있지만 쉽지 않을 수 있습니다. 처음 활성화할 PC를 신중하게 정해 주세요.

첫 방송까지#

  1. 아바타 내보내기 — Unity에서 .vavatar 파일을 만듭니다. → 2장
  2. 아바타 열기 — 시작 화면에서 파일을 열고 ▶ Avatar Live 시작을 누릅니다. → 3장
  3. 웹캠 · 마이크 켜기 — 장치 페이지의 스위치를 켭니다. → 6장
  4. 얼굴 맞추기 — 동작 › 자동 얼굴 설정을 눌러 안내를 따라 합니다. → 7장
  5. 배경 · 조명 고르기 — 씬 페이지에서 고릅니다. → 8장
  6. 내보내기 — 출력 페이지에서 Spout2, 가상 카메라, 화면 공유 중 하나를 켭니다. → 9장

F1을 누르면 메뉴가 사라지고 아바타만 보입니다.

종료#

창의 X를 누르면 트레이로 들어가고, 아바타와 출력은 계속 동작합니다. 완전히 끄려면 트레이 아이콘을 우클릭해서 종료를 누릅니다.
