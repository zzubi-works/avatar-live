4. メイン画面#

左のメニュー#

メニュー 内容 ガイド
ロゴ 再起動（スタート画面へ） 3 章
メニュー アバターの Expression メニュー、ジェスチャー、クイックアクション 5 章

アップデートがあると、設定 に緑の点が表示されます。

パネル右上の ピン を押すとパネルが固定され、ビューをクリック・ドラッグしても開いたままになります。閉じるときは左のメニューボタンか F1 を押します。

FPS（右） 現在のフレームレート。押すとフレームレートを変更

ボタン 内容

+ 今のカメラをビューとして保存

カメラの設定#

項目 内容
PNG を保存 / フォルダー UI なしで画面を写真として保存
カメラをロック カメラを固定
レンズ 透視 / 平行投影、画角、向き
保存したビュー ビュー一覧の管理、今のカメラを保存、開始ビュー

左ボタンで PhysBone をつかむ マウスで髪・しっぽなどをつかむ（下記）

マウスとキーボード#

操作 内容
右ドラッグ カメラを回転
ホイールドラッグ / Shift + 右ドラッグ カメラを移動
ホイール ズーム
何もない所をダブルクリック アバターの全身が映るように合わせ直す

Avatar Live のウィンドウが前面にあるときに使うキーです。ゲーム中にも使うキーはグローバルショートカットで別に設定します。

キー 内容
F1 クリーンビュー（UI を隠す / 表示）
Ctrl + 1 / 2 / 3 顔 / 上半身 / 全身
Ctrl + 4 … 9 保存したビュー
F 回転の中心をアバターに
Ctrl + = / − UI のサイズ
Alt + Enter 全画面 / ウィンドウ
Esc メニューを閉じる、全画面を解除
Ctrl + Z / Ctrl + Y アバター・オブジェクトの配置を元に戻す / やり直す

クリーンビュー#

F1 を押すと UI がすべて消え、背景とアバターだけが残ります。トラッキングと出力は続きます。もう一度 F1 を押すと元に戻ります。

シーンツール（左のアイコン）#

ツール 内容
カメラ 基本モード
移動 / 回転 / サイズ ビュー上でアバターの位置・向き・サイズを変更（右クリック：その値だけリセット）
ポージング（Pro） ボーンを選んでポーズを作る（11 章）
⌂ アバターを中央に

PhysBone をつかむ#

ビュー上で、髪・耳・しっぽのような揺れる部分をマウスでつかめます。

操作 内容
左ドラッグ 引っ張る
つかんだままホイール 近づける / 遠ざける
つかんだまま右クリック その場で ポーズを固定
ポーズを解除 固定したものを解除

固定した部分は、その部分をもう一度つかむまでそのまま保たれます。

アバターの PhysBone 設定でつかむことが許可されている部分だけをつかめます。

ウィンドウとトレイ#

操作 結果
ウィンドウの X トレイに隠す（アバター・出力は継続）
トレイアイコンをダブルクリック 再び開く
トレイを右クリック Avatar Live を開く / クリーンビューで開く / 終了

画面サイズとテーマ#

UI のサイズ、ライト・ダークのテーマ、パネルの位置は設定 › UIで変更します。
