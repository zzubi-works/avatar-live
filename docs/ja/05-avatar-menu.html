5. アバターメニュー#

メニュー ページでは、VRChat で使っていた アバター自体の Expression メニュー をそのまま使います。衣装・ヘアのトグル、表情ボタン、Radial、Puppet が VRChat と同じように動作します。

Expression メニュー#

種類 内容
Toggle オン / オフ
Button 押している間だけオン
Sub Menu サブメニューを開く（戻る で戻る）
Radial Puppet スライダーで値を決める
Two Axis / Four Axis Puppet パッドで方向を決める

項目を右クリック#

項目 内容
クイックアクションに追加 この項目をツールバーのボタンにする
ショートカットを設定… この項目にショートカットを設定
お気に入り メニュー上部のお気に入りに追加
パラメーター情報 この項目のパラメーターを表示

お気に入り#

お気に入りにした項目を、メニューの一番上からすぐに使えます。サブメニュー内の項目もそのまま操作できます。

ハンドジェスチャー#

左手 / 右手のジェスチャー（ニュートラル · グー · パー · 指差し · ピース · ロック · ガン · サムズアップ）を選んで、アバターのジェスチャー表情を出します。

  • Web カメラの手の形でジェスチャー — オンにすると、Web カメラでトラッキングした手の形がジェスチャーになります。

アバターのパラメーター#

  • デフォルトに戻す — すべてのメニューの値をアバターの初期値に戻します（VRChat の Reset Avatar と同じ）。

衣装の状態など、VRChat で保存される値は次回の起動時もそのまま保持されます。

クイックアクション#

よく使う操作を ボタン や キー にします。

追加する場所 - メニュー項目を右クリック → クイックアクションに追加 - 設定 › ショートカット・クイックアクション › クイックアクションを追加

設定できる操作：アバターメニューの項目 · ジェスチャー · カメラビュー · 保存したビュー · トラッキングリセット · ライティングプリセット · PhysBone リセット · すべてリセット

ボタンを右クリック：名前を変更 · 表示場所（上部 HUD / 下部ツールバー / ショートカットのみ）· ショートカットを設定… · 削除

リセットとすべてリセット#

リセット すべてリセット
実行 上部の ⟲ をクリック、設定 › 一般 ⟲ を右クリック、設定 › 一般
元に戻るもの トラッキング、手のポーズ、押されたボタン、PhysBone、Contact 上記 + すべてのパラメーター（衣装を含む）、アバターの位置・サイズ、ポーズ、カメラ
そのまま残るもの 衣装・トグル、ライティング、カメラ オブジェクト、保存したポーズ・表情、設定

配信中にアバターが固まったり、髪が絡まったりしたときは ⟲ リセット を押してください。
