エディションとライセンス#

Avatar Liveの使用権、外部プログラムの使用権、アバター・小道具の使用権はそれぞれ異なります。

OBS・カメラ出力にはSpout2・NDI・仮想カメラが含まれます。基本画面効果はポストプロセッシング、追加画面効果は後処理効果と環境光遮蔽です。

有効化とアップグレード#

  • ライセンス1つは1人が1台のPCで使用します。
  • 有効化とライセンス確認にはインターネット接続が必要です。
  • 他のPCへ直接移動は1回可能です。その後の移行はお問い合わせにより検討します。
  • Basic → Pro: アップグレードを購入した後、設定 → ライセンス → 別のコードを入力に入力します。
  • 体験中の購入: 設定 → ライセンス → 別のコードを入力にライセンスを入力します。
  • DLC部屋パック: BOOTHの注文番号を、同じ別のコードを入力に入力します。ライセンスはそのままで、そのPCで部屋パックをダウンロードできるようになります。他のPCへの移動は1回可能です。

プログラム・ライセンスコードの再配布・貸与・共有・改変や保護手段の回避は許可されていません。詳細については利用規約に従ってください。

NDI#

NDI®はVizrt NDI ABの登録商標です。 NDI公式サイト

ネットワーク映像の伝送に使用する外部技術です。

  • Avatar Liveに含まれるNDI RuntimeはNDI SDKライセンスに従います。
  • ライセンス全文は、プログラムの AvatarLive_Data/Plugins/x86_64/Processing.NDI.Lib.Licenses.txt にあります。
  • NDI Tools は別途ダウンロードするプログラムです。Avatar Liveには含まれていません。
  • OBSで受け取る DistroAV は別のプロジェクトであり、当該プロジェクトのライセンスに従います。

NDI SDK 利用条件 · NDI 接続方法

Spout2#

同じ Windows PC 上でプログラム間で映像を送信する外部技術です。

  • Avatar Live の Spout2 連携に使用した KlakSpout は Unlicense に従います。配布版のサードパーティ告知で全文を確認できます。
  • OBS Spout2 Capture プラグイン は別途インストーラーで提供されており、該当プロジェクトの GPL v2 条件に従います。
  • Avatar Live の購入は、OBS プラグインの著作権や別の権利を移転するものではありません。

Spout2 接続方法

VB-CABLE#

VB-Audio Software が制作した別の仮想オーディオドライバーです。

  • VB-CABLE は Donationware であり、使用・配布・ライセンス条件は VB-Audio が定めます。
  • インストールボタンはVB-Audioの元のドライバーをインストールするための経路です。Avatar Liveが開発したドライバーではありません。
  • 必要なライセンスとサポートは、VB-Audio公式ライセンス案内をご確認ください。
  • Avatar Liveの購入・Proアップグレードは、VB-CABLEの別ライセンスを付与するものではありません。

アバターと小道具#

アバター・衣装・テクスチャ・シェーダー・ポーズ・3D小物などのコンテンツの権利は、各原制作者にあります。

放送で使用する場合には、以下の事項と各原作者の利用規約を確認して使用してください。

考慮すべき事項 確認すべき規約
放送・映像公開 原作者が放送・商業的使用を許可しているか確認します。
ファイルの修正・変換 原作者の改造・変換条件を確認します。
リモートセッション送信 他のPCへのデータ送信および一時保存が許可されているか確認します。
他の人に提供 再配布または第三者への提供の許可を確認します。

アバターや小道具を使用する前に、各原作者の権利と利用規約を確認してください。必要な利用許可を取得し、規約を守る責任は利用者にあります。

Avatar Liveの購入や機能の使用は、コンテンツの利用許可を代替するものではありません。Avatar Liveおよび開発者は、利用者のコンテンツ使用・修正・送信・配布によって生じる権利侵害や紛争に対して責任を負いません。

オープンソースと独立性#

含まれるオープンソースの構成要素は、それぞれのライセンスに従います。プログラムおよびExporterに同梱された通知を確認してください。

Avatar LiveおよびAvatar ExporterはCurious Bobby Co.の独立した製品です。VRChat SDK・NDMF・Modular Avatar・VRCFuryを配布しておらず、各開発社の公式製品や承認製品ではありません。VRChatアカウントやサーバーには接続しません。

実験的機能#

アプリで実験的に表示される機能は、デバイスや環境によって動作が異なる場合があります。購入前に必要なデバイスおよびサポート範囲を確認してください。
