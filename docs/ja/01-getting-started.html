はじめに#

アバターを呼び出して、私の動きを接続し、放送画面を出力する順序で始めます。

インストールして実行する#

  1. BOOTHの購入履歴からAvatar LiveのZIPファイルを受け取ります。
  2. 希望するフォルダにすべての圧縮を解凍します。
  3. フォルダ内の AvatarLive.exe を実行します。
  4. 製品の有効化画面で、購入時に案内された情報を入力し、有効化を押します。

Windows 10 / 11 64ビットとDirectX 11対応のグラフィックカードが必要です。顔と手を追従させるにはウェブカメラを、声で口を動かすにはマイクを用意してください。

1. アバターを開く#

  1. アバターを開くを押すか、ファイルをウィンドウにドラッグします。
  2. アバターの一覧から使用するキャラクターを選びます。
  3. アバターライブの開始を押します。シーン一覧が表示されたら、使用するシーンを選びます。
所有ファイル やること
.vavatar そのまま呼び出します。
.vrm そのまま読み込みます。VRM 0.xと1.0をサポートしています。
Unity アバタープロジェクト アバターのエクスポートで .vavatar を作成した後、読み込みます。

2. 自分の動きを接続する#

  1. 左側のデバイスを押します。
  2. ウェブカメラのリストから使用するカメラを選び、タイトルの右のスイッチをオンにします。
  3. 画面を正面に向けて正面補正を押します。
  4. 声で口を動かしたい場合は、マイクも選んでスイッチをオンにします。

iPhoneや外部トラッカーを使用する場合は、デバイスで接続方法を確認してください。

3. 背景と構図を決める#

  • 衣装・表情: 左のメニューで選びます。
  • 顔・手の動き: 動作で調整します。
  • 背景・照明: スタジオで選びます。
  • 構図: 下のカメラツールバーで顔・上半身・全身を選びます。

F1を押すとメニューを隠してアバターだけを表示します。再度押すとメニューが戻ります。

4. 放送プログラムに接続する#

使用目的 開く場所
このPCのOBSにアバターを入れる Spout2接続
他のPCのOBSに映像を送る NDI接続
Discord・Zoomのカメラとして使用 仮想カメラ
ゲームとアバターを一緒に共有 画面共有
友だちのアバターと合同配信 リモート合同配信
視聴者のイベントにアバターが反応 配信

配信を始める前に、OBSや共有される側の実際の映像を確認してください。自分の作業画面と配信カメラの構図が異なる場合があります。

アバターをエクスポート#

UnityプロジェクトにあるアバターをAvatar Liveで開くための.vavatarファイルにします。すでに.vavatarや.vrmファイルがある場合は、アバターを開くに進んでください。

Exporter のインストール#

  1. 下のボタンを押して、VCC または ALCOM にリポジトリを追加します。開いた画面で追加を確定します。
  2. アバタープロジェクトに Curious Bobby - Avatar Exporter を追加します。
  3. Unityで該当のプロジェクトを開きます。

VCC・ALCOM に追加

ボタンで開かない場合は、下のアドレスをコピーして Settings → Packages → Add Repository に貼り付けます。

https://raw.githubusercontent.com/zzubi-works/avatar-exporter/main/index.json

.unitypackageで受け取った場合は、UnityのAssets → Import Package → Custom Package…から取り込みます。

アバターファイルを作成する#

  1. Unity 上部の Curious Bobby → Avatar Exporter を開きます。
  2. アバター欄にHierarchyのアバターをドラッグします。
  3. 表示名と保存フォルダを決めます。
  4. .vavatar をエクスポートを押します。
  5. 完了したら、ファイルを表示して結果ファイルを確認します。
  6. Avatar Liveのアバターを開くでそのファイルを読み込みます。
項目 変えるとどうなりますか？
アバター エクスポートするキャラクターを選択します。
表示する名前 Avatar Live のリストに表示される名前になります。
表情クリップ 選択した表情アニメーションを一緒に入れます。なくても書き出すことができます。
保存フォルダー 完成した .vavatar ファイルを置くフォルダーです。
.vavatar をエクスポート 選択したアバターでファイルを作成します。
ファイルを見る 完成したファイルがあるフォルダを開きます。

アバターを修正したとき#

Unityで衣装や髪などを修正した後、同じアバターを再度エクスポートします。Avatar Liveで新しいファイルを読み込むと、変更した外見が反映されます。

エクスポートできないとき#

  • Unityでアバター自体にエラーがないか確認します。
  • 使用中の制作ツールとエクスポーターを確認して、再度エクスポートします。
  • ファイルは作成されたが、一部がピンク色になったり消えてしまった場合は、元のプロジェクトのマテリアル・シェーダーと該当パーツのオン状態を確認します。

アバター・衣装・小道具の放送および共有の許可範囲は、各制作者の利用規約に従います。コンテンツ利用条件を確認してください。

アバターライブラリ#

アバターファイルを登録し、使用するキャラクターと開始シーンを選びます。

開始画面#

ボタン・項目 押すとどうなりますか？
Avatarを開く リストに「.vavatar」または「.vrm」ファイルを追加してください。また、そのファイルをウィンドウにドラッグすることもできます。
最近 最近使用したアバターを表示します。
フォルダー 指定したアバターフォルダーのファイルを表示します。
インポートした ライブラリからインポートしたアバターを表示します。
アバターのサムネイル 開始するキャラクターを選択します。
デフォルトに指定 デフォルトのアバターで開始する際に使用するキャラクターを設定します。
プレビュー 選択したキャラクターの姿を確認します。
シーンリスト 開始するステージの構成を選びます。
Avatar Live 開始 選択したアバターとシーンでメイン画面を開きます。

開始するデバイスを選ぶ#

  • カメラ: 右側のスイッチをオンにすると、起動時に選択したウェブカメラを使用します。
  • マイク：オンにすると、開始時に選択したマイクでリップシンクを使用します。
  • 顔・手：各部位を追跡する方法を選びます。実行した後でも、デバイスで変更できます。

次回実行に使用するアバター#

開始設定 次回実行時
毎回尋ねる 開始画面でアバターを直接選びます。
最後のアバター 直前に使用したアバターで開始します。
基本アバター 基本として指定したアバターで開始します。

実行中に変更する#

  1. 左上のアバター名を押します。
  2. リストから変更するアバターを選びます。
  3. 新しいファイルは「アバターファイル追加」で取り込みます。

既存のアバターを置き換える場合はこのリストを使用してください。一つのシーンにキャラクターを増やす「アバター追加」はスタジオの別機能です。

起動がうまくいかないとき#

Shiftキーを押したままプログラムを実行すると、ウェブカメラとマイクを起動しないセーフ起動を使用できます。デバイスの問題を確認した後、デバイスを一つずつオンにして試してください。

メイン画面#

左側で設定を選び、中央でアバターを見ながら調整します。

左側メニュー#

メニュー ここでできること
アバターメニュー 衣装・表情・手のジェスチャーと保存したポーズを適用します。
デバイス ウェブカメラ・マイク・iPhone・トラッカーを接続します。
動き 顔・体・手の動きの大きさと滑らかさを調整します。
スタジオ 背景・照明・部屋・小道具・アバター・撮影カメラを配置し、写真と録画を撮ります。
出力 OBS・仮想カメラ・画面共有に接続します。
配信 Twitch・CHZZK・SOOP・Discordのイベントにアバターが反応するようにし、リモート合同配信のセッションを開きます。詳しくは配信を確認してください。
設定 ウィンドウ・パフォーマンス・言語・ショートカット・アップデートを変更します。

設定パネルの使い方#

  • カードタイトル: クリックして詳細設定を開閉します。
  • スイッチ: 該当機能をオンまたはオフにします。タイトルの開閉とは別です。
  • ピン: パネル外をクリックしても設定パネルが閉じないようにします。
  • 数字: 直接入力するか、横のスライダーで変更します。
  • カードタイトルをドラッグ: よく使うカードを上に移動します。
  • 上部虫眼鏡: 設定名を検索し、結果をクリックしてすぐに移動します。

カメラツールバー#

項目 変わること
顔・上半身・全身 選択したアバターをそのサイズで画面に収めます。
保存されたビュー 保存しておいた位置と方向に戻ります。
ビュー保存 今見ている構図を保存します。
カメラロック マウスで構図が変わらないようにロックします。アバターは引き続き動きます。
視野角 下げるとアバターが大きく見え、高くすると周囲が広く見えます。
固定・自由・軌道 作業画面をマウスで動かす方式を変更します。

設定パネル上でホイールを回すと設定がスクロールされます。アバターが見える範囲で回すとカメラの距離が変わります。

作業画面と配信画面#

画面 見る人 動かすと
シーンビュー 自分が編集している作業画面 自分の作業視点が変わります。シーンビューを配信中の場合、放送も同様に変わります。
スタジオカメラ 選択した撮影カメラの視聴者画面 該当カメラの設定に従って構図が変わります。

放送構図を維持しながら照明や小道具を編集したい場合は、スタジオカメラを配信対象として選びます。

よく使う操作#

操作 結果
F1 メニューを隠します。再度押すと表示します。
Ctrl+Z サポートされている編集作業を1段階戻します。
上部リセット トラッキング・手の姿勢・物理的な動きを回復します。
左下の電源 プログラムを終了します。

服や位置まで変更するすべてのリセットは適用範囲がより広いです。髪が少し絡まった程度であれば、まずは通常のリセットを使用してください。

エディションと終了#

Basicは個人的・非公開利用、Proは配信・動画公開・商用利用に使用します。 エディション別機能で必要な機能を確認してください。

左下の電源ボタンでプログラムを終了します。ウィンドウのXボタンがトレイに隠れるように設定されている場合は、配信は続行されます。Xボタンの動作は設定 → ウィンドウで変更できます。
