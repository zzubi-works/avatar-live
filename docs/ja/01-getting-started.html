はじめに#

アバターを呼び出して、私の動きを接続し、放送画面を出力する順序で始めます。

インストールして実行する#

  1. BOOTHの購入履歴からAvatar LiveのZIPファイルを受け取ります。
  2. 希望するフォルダにすべての圧縮を解凍します。
  3. フォルダ内の AvatarLive.exe を実行します。
  4. 製品の有効化画面で、購入時に案内された情報を入力し、有効化を押します。

Windows 10 / 11 64ビットとDirectX 11対応のグラフィックカードが必要です。顔と手を追従させるにはウェブカメラを、声で口を動かすにはマイクを用意してください。

1. アバターを開く#

  1. アバターを開くを押すか、ファイルをウィンドウにドラッグします。
  2. アバターの一覧から使用するキャラクターを選びます。
  3. アバターライブの開始を押します。シーン一覧が表示されたら、使用するシーンを選びます。
所有ファイル やること
.vavatar そのまま呼び出します。
.vrm そのまま読み込みます。VRM 0.xと1.0をサポートしています。
Unity アバタープロジェクト アバターのエクスポートで .vavatar を作成した後、読み込みます。

2. 自分の動きを接続する#

  1. 左側のデバイスを押します。
  2. ウェブカメラのリストから使用するカメラを選び、タイトルの右のスイッチをオンにします。
  3. 画面を正面に向けて正面補正を押します。
  4. 声で口を動かしたい場合は、マイクも選んでスイッチをオンにします。

iPhoneや外部トラッカーを使用する場合は、デバイスで接続方法を確認してください。

3. 背景と構図を決める#

  • 衣装・表情: 左のメニューで選びます。
  • 顔・手の動き: 動作で調整します。
  • 背景・照明: スタジオで選びます。
  • 構図: 下のカメラツールバーで顔・上半身・全身を選びます。

F1を押すとメニューを隠してアバターだけを表示します。再度押すとメニューが戻ります。

4. 放送プログラムに接続する#

使用目的 開く場所
このPCのOBSにアバターを入れる Spout2接続
他のPCのOBSに映像を送る NDI接続
Discord・Zoomのカメラとして使用 仮想カメラ
ゲームとアバターを一緒に共有 画面共有
友だちのアバターと合同配信 リモート合同配信
視聴者のイベントにアバターが反応 配信連携

配信を始める前に、OBSや共有される側の実際の映像を確認してください。自分の作業画面と配信カメラの構図が異なる場合があります。

エディションと終了#

Basicは個人的・非公開利用、Proは配信・動画公開・商用利用に使用します。 エディション別機能で必要な機能を確認してください。

左下の電源ボタンでプログラムを終了します。ウィンドウのXボタンがトレイに隠れるように設定されている場合は、配信は続行されます。Xボタンの動作は設定 → ウィンドウで変更できます。
