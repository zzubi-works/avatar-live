1. はじめに#

必要なもの#

項目 要件
OS Windows 10 / 11（64ビット）
グラフィック DirectX 11 対応 GPU
Web カメラ 一般的なカラー Web カメラ
マイク リップシンク用（任意）
インターネット アクティベーションとライセンス確認に必要
アバター VRChat アバターの Unity プロジェクト（Unity 2022.3.22f1）

エディション#

Basic Pro
利用範囲 個人での利用（フレンドとの非公開の Discord 共有を含む） 配信・動画の公開・商用利用
出力 最大 1080p・ウォーターマークあり 最大 4K・ウォーターマークなし
ポージング・オブジェクト・画面共有のほかのソース — ✅

配信や動画の公開など、ほかの人に見せる用途には Pro を選んでください。詳しくは13章をご覧ください。

インストール#

  1. BOOTH の購入履歴から ZIP ファイルをダウンロードします。
  2. 好きなフォルダーに展開します。
  3. AvatarLive.exe を実行します。

「Windows によって PC が保護されました」という画面が表示されたら、詳細情報 → 実行 を押してください。

💡 インストールフォルダーのファイルは、そのままにしておくことをおすすめします。ファイルが変わると Avatar Live が起動しないことがありますが、その場合は元のファイルで再インストールすれば大丈夫です。アバターと設定はそのまま残ります。

アクティベーション#

初めて起動すると、製品のアクティベーション 画面が表示されます。購入時に案内された情報を入力して アクティベート を押せば完了です。

ライセンスは1人1台です。別の PC への移行は、ご自身で1回行えます。それ以降は、やむを得ない場合にお問い合わせを通じてお手伝いしていますが、難しい場合もあります。最初にアクティベートする PC は、慎重に決めてください。

初めての配信まで#

  1. アバターを書き出す — Unity で .vavatar ファイルを作ります。→ 2章
  2. アバターを開く — スタート画面でファイルを開き、▶ Avatar Live を開始 を押します。→ 3章
  3. Web カメラ・マイクをオンにする — デバイス ページのスイッチをオンにします。→ 6章
  4. 自分の顔に合わせる — 動き › 自動フェイスセットアップ を押して、案内に従います。→ 7章
  5. 背景・ライティングを選ぶ — シーン ページで選びます。→ 8章
  6. 出力する — 出力 ページで、Spout2、仮想カメラ、画面共有のどれかをオンにします。→ 9章

F1 を押すと、メニューが消えてアバターだけが表示されます。

終了#

ウィンドウの X を押すとトレイに最小化され、アバターと出力は動き続けます。完全に終了するには、トレイアイコンを右クリックして 終了 を押します。
