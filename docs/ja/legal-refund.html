返金の基準#

  • Avatar Live の決済と返金は、BOOTH の返金ポリシー に従います。
  • Avatar Live はダウンロード型のデジタル商品のため、商品の性質上、購入後の申込みの撤回や返金は原則として難しくなっております。
  • ご購入前に、以下の項目をご確認いただけますと幸いです。

ご購入前の確認#

  • [ ] Windows 10 / 11（64ビット）の PC ですか？（macOS・Linux には対応していません）
  • [ ] DirectX 11 に対応したグラフィックカードがありますか？
  • [ ] 使いたいアバターの Unity プロジェクト（Unity 2022.3.22f1、VRChat に正常にアップロードできる状態）がありますか？ VRM・.vrca ファイルだけではご利用いただけません。
  • [ ] 一般的なカラー Web カメラがありますか？
  • [ ] アクティベーションとライセンス確認のために、インターネットに接続できますか？
  • [ ] 対応範囲を確認しましたか？
  • [ ] 配信や商用利用の場合、Pro を選びましたか？（エディション）

決済・返金に関するお問い合わせ#

決済と返金に関するお問い合わせは、販売者ではなく BOOTH に直接 お願いいたします。

動作に問題がある場合#

まずトラブルシューティングをご確認いただき、解決しない場合は販売者情報のお問い合わせ窓口までお知らせください。可能な範囲でお手伝いいたします。
