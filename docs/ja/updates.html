更新履歴#

Avatar Liveのバージョンごとの変更内容です。最新の更新から確認できます。

2026/10/30 — v2.4.4#

  • Web カメラ 60fps トラッキング: デバイス › Web カメラ › トラッキング品質の「トラッキング FPS」で 30・60・120・自動を選べます。60fps のカメラで 60 を選ぶと顔を毎秒約 59 回解析し、カメラから結果までの時間が約半分になります。既定はこれまでどおり 30 です。
  • トラッキング品質の詳細設定: カメラ解像度、手・体の更新頻度、顔を優先を設定できます。速度の行で、カメラ・解析・画面のうち遅いところがわかります。
  • 手の検出: 画面に手がないときは手を毎秒 20 回だけ探し、CPU を節約します。
  • 動きの反応: 動き › 頭の動きの「動きの反応」で低遅延・バランス・なめらかを選べます。使われていなかった「反応速度」スライダーの代わりで、バランスはこれまでと同じです。
  • 仮想カメラ: 30fps を均一に送ります(以前は 15–22fps)。NDI の fps 表示も直しました。
  • X3D CPU: CCD が 2 つある CPU で、コアの「自動」がゲームとは別の CCD を使い、Avatar Live とトラッカーが Windows の電力調整で遅くなりません(エコを除く)。
  • エコで高い FPS: エコでトラッキング FPS や手・体の更新頻度を既定より上げると、トラッカーが Windows の効率モードに縛られず、選んだ頻度が出ます。

  • 画面共有ソースのロック: ソース一覧の鍵アイコンや右クリックメニューでアバターやソースをロックすると、プレビューでのドラッグやホイールで動かなくなります。数値入力と配置ボタンでは動かせ、ロックはレイアウトプリセットにも保存されます。
  • 画面共有の一覧: アバターを右クリックすると空の白いウィンドウが出ていたのを直しました。レイアウトプリセットがないときの案内と「+ 新規プリセット」ボタンの間隔を整えました。
  • ライトのエフェクト: エフェクトごとの ⋯・右クリックメニューに「エフェクトをリセット」が加わりました。ライトのカードで変えたものは Ctrl+Z で元に戻し、Ctrl+Y でやり直せます。
  • 投げる・ステッカーの軌跡: 「軌跡の量」の下の「軌跡の大きさ」で軌跡を 0.25–3 倍に変えられます。
  • ドロワーの端: ドロワーとノードエディターのウィンドウの端で Windows 標準のサイズ変更カーソルが出て、灰色のバーの代わりに細い強調線が表示されます。

  • 録画: ゲーム画面がまだ届いていないときは「待機中」と表示し、画面が届いたらすぐに録画を始めます。録画の音声やファイルの仕上げに問題があればお知らせし、音声が途切れたあとに録画がずれる問題を修正しました。
  • 配信プレビュー: プレビューのスイッチ一つで表示・非表示を切り替えます。スタジオカメラを掴んでいるときも同じです。
  • 画面共有パネル: ソースの選択が押したボタンの位置で開き、ソース・音声・プリセットが一つのカードにまとまります。解像度と FPS は共有状態の下に戻りました。
  • モーション画面: 表情キーがメッシュ一覧の横に専用の一覧で表示され、文字が重ならず、長いヘルプは短いヒントになりました。案内やエラーが 4 言語で表示されます。
  • 実行中のノードグラフの編集: 実行中のグラフを編集しても(別ウィンドウのエディターを含む)、進行中の待機・クールダウン・ポーズと変数の値が続きます。二つのウィンドウで同じグラフを同時に変えた場合は上書きせずにお知らせします。
  • 全体のコードレビュー: アプリ全体を見直し、録画、画面共有、モーション、写真、照明などで見つかった問題を修正しました。

2026/10/28 — v2.3.0#

  • 長時間配信の最適化: 長く起動したままでも CPU・GPU・メモリ・VRAM の使用量がたまらないよう、全体を見直しました。流体と物理、アバター、レンダリング、出力、録画を整理し、起動時に使うメモリも減らしました。使っていない出力やウェブカメラ、隠したウィンドウはリソースを手放します。
  • 画面共有の HDR の色: HDR モニターの画面やウィンドウを共有しても、SDR の画面と同じ明るさの色で映ります。セッションの再開時に終了してしまう問題も修正しました。
  • 画面共有の編集ワークスペース: 大きな編集画面がソースパネル中心のワークスペースになりました。画像とテキストのソースを追加し、レイヤーとプリセットを一か所で扱えます。フレームレートは配信出力も画面共有も「フレームレート(FPS)」の一つで選びます。
  • モーションシーケンサーの .anim 保存: モーションシーケンサーで保存すると、再生中のアバターごとにヒューマノイドの .anim も作られます。アニメーションノードでこのモーションを選び、再生・停止・速度変更・ループができ、表情のシェイプキーも一緒に再生されます。アバター 1 体を .anim または .vmd として書き出すこともできます。
  • モーションプレイヤーとシーケンサー: スタジオ › ポーズにモーションプレイヤーを追加しました。保存したシーケンスをシーンのアバターが一つの時計で再生し、ライト・小物・ルーム・カメラのトラックも一緒に動き、逆再生もできます。シーケンサーにはカメラトラック(任意)、メッシュ階層ごとの表情スライダー、Alt+矢印でキーを1フレームずつ動かす操作、ループ端・マーカーのドラッグが加わりました。.vmd 書き出しは VRM の表情を MMD 標準モーフとして、最初のディレクショナルライトを照明モーションとして書きます。
  • サウンド再生ノードと変数: ノードエディターに、グラフからサウンドを再生するノードが加わりました。変数、カメラ演出のオン・オフノード、入力値のコピー&ペースト、数値ラベルのドラッグでの値変更、リストの並べ替えも使えます。
  • かんたん設定のルールスイッチ: かんたん設定の各ルールにオン・オフのスイッチが付きました。ノードエディターで編集したルールでもスイッチはそのまま使えます。ルールの行は 1 行で読めるように整えました。
  • 数値欄とラベル: 数値入力欄の数字が中央に表示されます。色チャンネル、桁入力、カスタムサイズ、モーションの数値欄も同じです。ラベルは行に収まる長さに短くし、はみ出して切れる表示を直しました。
  • 液体を注ぐ: 液体を初めて注ぐときに一瞬止まる現象を修正しました。
