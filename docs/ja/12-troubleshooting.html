12. トラブルシューティング#

まず 設定 › 診断 を確認し、解決しない場合は エラーレポートを送る でお知らせください。 デバイスの問題で起動できない場合は、Shift を押したまま起動（セーフスタート）してみてください。

起動・インストール#

症状 対処
「Windows によって PC が保護されました」画面 詳細情報 → 実行
「Avatar Liveのファイルが変更されています」 BOOTH からダウンロードした元のファイルで再インストール（アバター・設定はそのまま）
アクティベートできない インターネット接続を確認してから再試行
起動するとウィンドウが前面に出るだけ すでに起動しています（トレイを確認）

アバター#

症状 対処
一部がピンク色になる アップロードが正常にできるか確認してから書き出し直す
「新しいエクスポーターで作られています」 Avatar Live をアップデート
頭・手が動かない ヒューマノイドのアバターか確認
アバターの効果音が鳴らない アバターの効果音は再生されません
アバターが見えない ビューの何もない所をダブルクリック、またはシーンツールの ⌂
ポーズが固まる、髪が絡まる 上部の ⟲ リセット

Web カメラ・顔#

症状 対処
カメラが「失敗」 ほかのアプリがカメラを使っていないか確認
カメラの映像が黒い レンズカバー、Windows のカメラのプライバシー設定を確認
表情が小さい / 大きい 自動フェイスセットアップ をやり直す、顔の調整
アバターが横を向く 正面補正
ウインクできない まばたきの方式を 独立 または スマート に
左右が逆 ミラー
CPU 使用率が高い トラッキング品質を バランス または エコ に

マイク#

症状 対処
「信号なし」 Windows の設定 › プライバシー › マイクでデスクトップアプリを許可
「ほぼ無音」 ミキサーアプリを使っている場合は、そのアプリの仮想マイクを選ぶ
ノイズで口が動く 背景ノイズを測定
口の動きが小さい 音声キャリブレーション、感度

出力#

症状 対処
OBS に Spout2 ソースがない OBS に Spout2 プラグインをインストール
OBS で背景が黒い 背景を 透明 + OBS で Composite with alpha
仮想カメラが Discord に出ない 仮想カメラをインストールしてから Discord を完全に終了して起動し直す
4K が 1080p で出力される Basic エディションです（Pro は 4K）
「Avatar Live Basic」の文字 Basic のウォーターマーク（Pro はなし）

Discord の画面共有#

症状 対処
Discord の一覧にない 画面共有 をオンにして、Discord の アプリケーション タブを確認
黒い画面 Avatar Live を管理者権限なしで実行、ゲームをウィンドウモードに
音が届かない Discord でサウンドをオン、仮想再生デバイスをインストール
音が二重に聞こえる Discord オーディオデバイス を自分では聞かないデバイスに
動画が黒い 保護された動画（DRM）はキャプチャされません

対応範囲#

内容
✅ VRChat アバターの機能 Expression メニュー・パラメーター、FX などのアニメーター、PhysBone、Contact、Constraint、Eye Look、LipSync
✅ 制作ツール NDMF · Modular Avatar · VRCFury などを使ったアバター
✅ シェーダー Poiyomi、lilToon など
✅ 顔 VRCFaceTracking、ARKit（Perfect Sync）、MMD の目のモーフ
⚠️ 動作しない アバターの効果音、AudioLink、ミラー・カメラの検出、Light Volumes、ユーザースクリプト
🧪 実験的機能 Ultraleap、iFacialMocap、OSC・VMC、舌・頬のカメラ検出 — 正常に動作する見込みですが、該当するデバイス・アプリが開発者の環境でまだテストされていません
❌ 非対応 VRM ファイル、Live2D、macOS・Linux

よくある質問#

Q. VRChat のアカウントは必要ですか？ いいえ。Avatar Live は VRChat と通信しません。

Q. 配信に使ってもいいですか？ 配信・動画の公開・商用利用には Pro が必要です。

Q. キーボード入力は記録されますか？ いいえ。デスクの手の動きは、入力した文字を保存・記録・送信しません。

Q. アバターファイルをほかの人に渡してもいいですか？ アバター・衣装の制作者の利用規約に従ってください。

Q. アバターを複数同時に表示できますか？ 一度にひとつです。左上のアバター名から切り替えます。
