## Hotkeys · Quick Actions

### Everywhere (global hotkeys)

Keys that work even in games or while Avatar Live is in the background. They do not block key input to other programs.

1. **+ Add a hotkey**
2. Choose an action: avatar menu · gesture · camera view · saved view · tracking reset · lighting preset · PhysBone reset · reset all
3. Click **Set the key…** and press the key combination you want

- For menu buttons and gestures you can choose **While held** / **Press to switch**.
- **F1** alone cannot be used (it is reserved for clean view).

### Quick Actions

Puts the same actions as global hotkeys on buttons. See [Chapter 5](05-avatar-menu.md#quick-actions).

## Updates

| Item | What it does |
|---|---|
| **Check now** | Check for a new version |
| **Download** | Download the new version |
| **Restart to install** | Install right away |
| **Check and download automatically** | Download new versions automatically in advance |
| **Install when quitting** | Install when you quit |

If installation fails, Avatar Live automatically returns to the previous version. Your avatars and settings are kept.
