## ポージング

ボーンを直接動かしてアバターのポーズを作り、保存します。

**開始**：シーン › **ポージング** › **ポージングモード**、または左のシーンツールの人型アイコン

| 操作 | 内容 |
|---|---|
| ボーンをクリック（Ctrl：複数） | ボーンを選択 |
| ボーンをドラッグ | 動かす（手・足をドラッグすると腕・脚全体） |
| リングをドラッグ | 回転（Ctrl：15° 単位） |
| **Ctrl + Z / Ctrl + Y** | 元に戻す / やり直す |
| **元に戻す** | 選択したボーンを元の動きに |
| **左右** | 左右反転 · 左側を右側にコピー · 右側を左側にコピー |
| **すべてリセット** | 最初のポーズに |
| **指のボーンを表示** | 指のボーンを表示 |

> ポージングモードをオフにするとポーズが解除されます。先に保存してください。

### ポーズ

| 項目 | 内容 |
|---|---|
| **+ ポーズを追加** | **このポーズを保存** · **.anim ファイルを読み込む…** · **このポーズを机のポーズとして保存（腕・手）** |
| ポーズをクリック | 適用 / 解除 |
| **ポーズを編集** | 保存したポーズを修正 |
| **名前を変更 / 今のポーズで上書き / 削除** | ポーズの管理 |
| **休憩ポーズにする（全身）** | 顔が見えないときにこのポーズにする |
| **机のポーズにする（腕・手）** | 机での手のポーズとして使う |

アバターメニューの **ポーズ** カードからも、ボタンひとつでポーズをオン / オフできます。

## オブジェクト

テキスト・画像・図形・3D モデルを、シーンやアバターに付けます（帽子、頭上の文字、椅子、机など）。

| 項目 | 内容 |
|---|---|
| **基本環境（床のグリッド）** | 床を表示 |
| **+ オブジェクトを追加** | **テキスト** · **画像ファイル…** · **3D モデル（.vprop）…** · **図形**（キューブ・球・円柱・カプセル・板） |
| 表示スイッチ · ⋯ | 非表示、名前を変更 · 複製 · 最初の位置へ · 削除 |
| **色** | 色を変える |
| **付ける場所** | シーンに固定 / 頭 / 胸 / 胴体 / 左手 / 右手 |
| **ゆっくり追従** | ボーンに少し遅れてついていく |
| **比率を固定 / サイズ** | サイズの調整 |
| **常に最前面に表示 / 常にカメラを向く** | 見え方 |
| テキスト：**フォント · 太字 · 斜体 · 縁取り · 背景プレート** | 文字の装飾 |

ビュー上では、シーンツール（移動・回転・サイズ）で動かします。テキストはダブルクリックするとその場で編集できます。

### 3D モデルを作る

Unity で **Curious Bobby → Prop Exporter** を使い、GameObject やプレハブを **.vprop** に書き出します。モデルの揺れるボーンやアニメーションも一緒に動作します。

## 画面共有のほかのソース

出力 › 画面共有 › **ほかのソース** で、ウィンドウやモニターをさらに重ねます（チャットウィンドウ、音楽プレーヤーなど）。

| 項目 | 内容 |
|---|---|
| **ソースを追加** | ウィンドウまたはディスプレイを追加 |
| 👁 | 表示 / 非表示 |
| ⋯ | 前へ · 後ろへ · 最初の位置へ · 削除 |

## マイ表情

アバターのシェイプキーで表情を直接作ります。

1. **新しい表情**
2. **シェイプキーを検索** → **+** で追加 → 強さを調整
3. **この表情を表示している間**：まばたきしない · 目のトラッキングを止める · 口のトラッキングを止める
4. **保存**

- **.anim を読み込む** で、Unity で作った表情アニメーションも使えます。
- アバターメニュー・シーンの **マイ表情** カードで押してオン / オフします。

## 自動表情

笑ったり驚いたりすると、アバターが決めておいた表情を自動で出します。

| 項目 | 内容 |
|---|---|
| **自動表情** | オン / オフ |
| 検出する表情 | 笑顔 · 驚き · 怒り · 悲しみ · ウインク（左/右）· 口をとがらせる · 眠そう |
| **表示する表情** | マイ表情 · ジェスチャー · アバターメニューの項目 · 表情クリップから割り当て |
| **しきい値** | どのくらいはっきり表情を作ったらオンになるか |
| **タイミング** | なめらかさ · 開始まで · 最低表示 |

**表情クリップ** は、Exporter で書き出すときに入れた追加の表情です（[2 章](02-avatar-exporter.md#書き出し)）。
