# 1. はじめに

## v2.0.0：初回起動から配信まで

1. **アバターを読み込む**：Exporter 1.0.6 の **.vavatar**か、対応する **VRM 0.x／1.0** を選びます。一部の特殊な VRM 0.x シェーダーは非対応です。
2. **入力を選ぶ**：[デバイス](06-devices.md)で Web カメラ、iPhone、マイク、VMC、SteamVR を顔・腕・指・体ごとに割り当てられます。
3. **正面補正**：顔を正面に向けます。iPhone は初回の有効な顔フレームから約 **3秒後**に初期補正されます。
4. **動作を調整**：[メニュー](05-avatar-menu.md)で衣装・表情を、[動作](07-motion.md)でスムージング・口・AFK を設定します。
5. **構図を準備**：[スタジオ](08-scene.md)で背景・ライトを整えます。**Pro** では複数アバター・複数配信カメラが使えます。
6. **OBS の設定**：同じ PC は **OBS Spout2 受信プラグイン**、別 PC は **DistroAV/NDI** が必要です。**NDI は Basic でも使用可**。[出力ガイド](09-output.md)の公式リンクから導入します。
7. **確認**：自分の編集用シーンビューと視聴者向けカメラは別の場合があります。OBS の最終映像を見てください。

技術的に NDI が利用できることと商用配信の利用権は別です。個人利用の Basic、公開・商用配信の Pro の条件は[ライセンス](13-license.md)を確認してください。

## 必要なもの

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11（64ビット） |
| グラフィック | DirectX 11 対応 GPU |
| Web カメラ | 一般的なカラー Web カメラ |
| マイク | リップシンク用（任意） |
| インターネット | アクティベーションとライセンス確認に必要 |
| アバター | VRChat アバターの Unity プロジェクト（Unity 2022.3.22f1） |

## エディション

| | Basic | Pro |
|---|---|---|
| 利用範囲 | 個人での利用（フレンドとの非公開の Discord 共有を含む） | 配信・動画の公開・商用利用 |
| 出力 | 最大 1080p・ウォーターマークあり | 最大 4K・ウォーターマークなし |
| ポージング・オブジェクト・画面共有のほかのソース | — | ✅ |

配信や動画の公開など、ほかの人に見せる用途には **Pro** を選んでください。詳しくは[13章](13-license.md)をご覧ください。

## インストール

1. BOOTH の購入履歴から ZIP ファイルをダウンロードします。
2. 好きなフォルダーに展開します。
3. `AvatarLive.exe` を実行します。

> 💡 「Windows によって PC が保護されました」という画面が表示されたら、**詳細情報 → 実行** を押してください。

> 💡 インストールフォルダーのファイルは、そのままにしておくことをおすすめします。ファイルが変わると Avatar Live が起動しないことがありますが、その場合は元のファイルで再インストールすれば大丈夫です。アバターと設定はそのまま残ります。

## アクティベーション

初めて起動すると、**製品のアクティベーション** 画面が表示されます。購入時に案内された情報を入力して **アクティベート** を押せば完了です。

ライセンスは1人1台です。別の PC への移行は、ご自身で1回行えます。それ以降は、やむを得ない場合にお問い合わせを通じてお手伝いしていますが、難しい場合もあります。**最初にアクティベートする PC は、慎重に決めてください。**

## v1.1.5 で変更された主な場所

- 右上の虫眼鏡からAFK、ミラー、Spout2などを検索できます。
- 通常の基本ポーズと追跡喪失時の待機ポーズを別々に設定します。AFKの時間は設定ではなく動作 › 体にあります。
- カードの見出しで開閉・ドラッグで並び替えできます。ポーズのフェイシャル、頭、腕、指、胴体の追跡は独立して切り替えられます。

## 終了

通常、ウィンドウの **X** はプログラムを終了します。**設定 › ウィンドウ** で **トレイに最小化** に変更できます。配信出力中は出力を維持するためトレイに入る場合があります。左下の **電源** ボタンで完全に終了できます。
