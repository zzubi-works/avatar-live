# 1. はじめに

## 必要なもの

| 項目 | 要件 |
|---|---|
| OS | **Windows 10 / 11（64 ビット）** |
| グラフィック | **DirectX 11** 対応 GPU |
| Web カメラ | 一般的なカラー Web カメラ（顔・腕・手のトラッキング用） |
| マイク | リップシンク用（任意） |
| インターネット | アクティベートとライセンス確認に必要 |
| アバター | VRChat アバターの **Unity プロジェクト**（Unity 2022.3）— [2 章](02-avatar-exporter.md)で `.vavatar` に書き出します |
| 任意のデバイス | Leap Motion / Ultraleap ハンドトラッカー、iPhone（iFacialMocap） |

## エディションを選ぶ

| | Basic | Pro |
|---|---|---|
| 用途 | 個人での利用 | **配信・動画の公開・商用利用** |
| 出力 | 最大 1080p、ウォーターマークあり | 最大 4K、ウォーターマークなし |
| ポージング · オブジェクト · 画面共有のほかのソース | — | ✅ |

> 配信（ライブストリーミング）や動画のアップロードなど、**公開・商用目的で使うには Pro** が必要です。詳しくは [13 章](13-license.md)をご覧ください。

## インストール

1. BOOTH の購入履歴から Avatar Live の ZIP ファイルをダウンロードします。
2. 好きなフォルダーに **展開します。** 展開したフォルダーがインストールフォルダーになります。
3. `AvatarLive.exe` を実行します。

> **「Windows によって PC が保護されました」画面が出たら** **詳細情報 → 実行** を押してください。

> ⚠️ **インストールフォルダーのファイルを変更したり、ほかのプログラムを入れたりしないでください。** 元のファイルと異なると Avatar Live は起動しません。その場合は BOOTH からダウンロードした元のファイルで再インストールしてください（アバターと設定はそのまま残ります）。

## 製品のアクティベーション

初めて起動すると **製品のアクティベーション** 画面が表示されます。

1. 右上で言語を選びます。
2. 購入時に案内された情報を入力し、**アクティベート** を押します。
3. 「アクティベートしました。」と表示されれば完了です。

### 別の PC に移す

- ライセンスは **1 人 1 台** です。
- 別の PC への移行は **1 回だけ** できます。移行すると以前の PC では使えなくなり、**その後はいかなる場合も再び移行することはできません。**
- 移行先の PC を慎重に決めてから行ってください。

## 初めての配信まで

1. **アバターを作る** — アバターの Unity プロジェクトで `.vavatar` を書き出す（[2 章](02-avatar-exporter.md)）
2. **アバターを開く** — スタート画面で **アバターを開く…** → **▶ Avatar Live を開始**（[3 章](03-launcher-and-library.md)）
3. **Web カメラをオン** — **デバイス** → **Web カメラ** スイッチ（[6 章](06-devices.md)）
4. **マイクをオン** — **デバイス** → **マイク** スイッチ
5. **顔を合わせる** — **動き** → **自動フェイスセットアップ**（[7 章](07-motion.md)）
6. **背景を選ぶ** — **シーン** → **背景**（[8 章](08-scene.md)）
7. **出力する** — **出力** → Spout2 / 仮想カメラ / 画面共有（[9 章](09-output.md)）
8. **F1** — UI をすべて隠したクリーンな画面

## 終了する

- ウィンドウの **X** は、標準では **トレイに隠す** 動作です。アバターと出力は動作し続けます。
- 完全に終了するには **トレイアイコンを右クリック → 終了**。
- X ですぐに終了したい場合は、設定 › ウィンドウ › **閉じるボタン（×）** → **終了**。
