# 13. エディション · ライセンス · 告知

## エディション

Avatar Live は **有料ソフトウェア** で、[BOOTH](https://curiousbobby.booth.pm/) で販売しています。

| | **Basic** | **Pro** |
|---|---|---|
| 利用範囲 | **個人的・非公開の利用** | **配信（ライブストリーミング）・動画の公開・商用利用** |
| アバター・トラッキング・メニュー・ライティング・エフェクト | ✅ | ✅ |
| マイ表情 · 自動表情 | ✅ | ✅ |
| Spout2 · 仮想カメラ · 画面共有 | ✅ | ✅ |
| 最大出力 | 1080p | 4K |
| ウォーターマーク | あり | なし |
| ポージング · オブジェクト · 画面共有のほかのソース | — | ✅ |

> **配信、動画のアップロード、依頼制作など、公開・商用目的で使うには Pro が必要です。** Basic は個人での利用のための基本エディションです。

## ライセンスの利用条件（要約）

- **1 人 1 台** です。
- 別の PC への移行は **1 回だけ** できます。移行後は以前の PC では使えず、**その後はいかなる場合も再び移行することはできません**（お問い合わせいただいても移行はできません）。
- アクティベートとライセンス確認にはインターネット接続が必要です。
- 再配布、販売、貸与、共有、リバースエンジニアリング、改変、ライセンス確認の回避は禁止されています。

すべての条件は[利用規約](legal-terms.md)に従います。

## 実験的機能

「実験的」と表示された機能（Ultraleap、iFacialMocap、OSC・VMC、舌・頬のカメラ検出）は正常に動作する見込みですが、該当するデバイス・アプリが開発者の環境でまだテストされていない機能です。

## ユーザーが作成したファイル

- Exporter で作成した `.vavatar` / `.vprop` ファイルはユーザーのものです。その中のアバター・衣装・シェーダーの権利は各制作者にあるため、共有するときは元の制作者の規約に従ってください。
- 配信・動画に映るアバターの利用条件も、各制作者の規約に従ってください。

## 独立性に関する告知

Avatar Live と Avatar Exporter は **Curious Bobby Co. が独自に開発したソフトウェア** です。

- **VRChat SDK のコードを使用・同梱しておらず、VRChat SDK を配布していません。**
- **NDMF、Modular Avatar、VRCFury などのアバター制作ツールを同梱・配布していません。** これらのツールは、ユーザーが自分のプロジェクトに直接インストールしたものが、ユーザーの環境で動作します。
- **VRChat のサーバーやアカウントと通信せず**、ほかの人のアバターを取得する機能はありません。
