# 更新履歴

Avatar Liveのバージョンごとの変更内容です。最新の更新から確認できます。

## 2026/10/26 — v2.2.3

アップデートが完了せずアプリが再起動しない場合は、Discord・Webブラウザー・OBSなど、カメラを使用するアプリをすべて閉じてから、もう一度アップデートしてください。

- **配信オーバーレイ・プレビュー：** 縮小プレビューが真っ黒になる問題と、オーバーレイを回転すると黒くなったり色が暗くなったりする問題を修正しました。色と上下の向きが正しく表示されます。
- **配信画面：** 画面のキャプチャ・合成・出力の仕組みを刷新しました。ゲーム画面とアバターを重ねて出力する処理と、出力が中断された後の復帰処理を改善しました。
- **ゲームウィンドウの移動：** 別のモニターへ移動した後も、以前のモニターを基準にキャプチャ状態を判定していた問題を修正しました。
- **配信解像度：** アプリのウィンドウサイズを変えても、配信用のアバター画面は設定した出力解像度を保ちます。
- **配信ルール：** ルールを無効化・編集する途中でエラーが起きた際に、以前のルールが動作したりテストボタンに反応したりする問題を修正しました。1つのルールのエラーが、ほかのルールやアプリの動作を止めないよう改善しました。
- **ライトのエフェクト：** ライト設定の「エフェクトを追加」ボタンを押してもメニューが開かない問題を修正しました。
- **動作・メモリ：** 使用していない配信出力や共有テクスチャの解放、GPU優先度設定の適用・復元処理を改善しました。
- **液体エフェクト：** 濡れた表面の重複計算を減らし、液体が映らないカメラでは不要な描画を省きます。使用していない液体エフェクトのリソース解放も反映しました。
- **口の動き・リップシンク：** 口の入力元を1か所で選べるようにし、顔トラッキングとマイクの混合設定をアバターごとに保存します。リップシンクの感度はパーセントで調整します。
- **ルームの照明：** 明るいルームでアバターの肌が透けて見える問題を修正しました。

## 2026/10/26 — v2.2.2

- **かんたん設定・配信連携:** 2.2.0・2.2.1 でかんたん設定のルールが動かずエラーが出続け、その間 CHZZK などの配信接続やアプリのほかの動作まで止まっていた問題を直しました。
- **ノードエディター:** 2.2.0・2.2.1 で作ったグラフのつながりはそのまま残ります。
- ルールを1つ作れなくても、ほかのルールとアプリは動き続け、エラーは1回だけ記録されます。

## 2026/10/25 — v2.2.1

- **iPhone の顔トラッキング:** ポーズが頭を固定しているとき、iPhone の頭の動きにつられて体だけが横に動いたり回ったりする問題を直しました。頭を固定したポーズでは、体も頭の動きを追わなくなりました。
- **パネルの色:** 設定 › UI › テーマで、ライト・ダーク・ホワイト・ブラック・カスタムから選べます。カスタムは背景色とアクセントカラーを選ぶだけで残りの色が合わせられ、どの色でも文字が読みやすく調整されます。サイドメニューだけ別のテーマにもできます（例: メニューはホワイト、パネルはブラック）。
- **パネルの見た目:** ライトテーマがやわらかなバニラとラベンダーの色になりました。サイドメニューはウィンドウの端に付き、開くパネルはその下に重なって影が落ちます。背景はより透けて、上に浮かぶカードはよりはっきり見えます。
- **スタジオのオブジェクトを投げる (Pro):** かんたん設定の投げるルールで、スタジオに置いた自分の3Dモデル（Prop Exporter で作ったもの）も選んで投げられます。
- **カード:** ドラッグで並べ替えられるカードは、また1枚ずつ分かれて表示されます。
- **顔のカード:** 「正面補正」と「顔を自動設定…」のボタンを1行に並べました。
- **ゲーム照明:** アバターごとの受ける量は、アバターメニューではなくスタジオ › ライティング › ゲーム照明の同期の「アバターごと」で設定します。
- **アニメーションレイヤー:** 配信イベントが切り替えるアニメーションのため、アバターメニューから配信 › インタラクションへ移しました。設定しなければ普段のトラッキングには影響しません。
- **エラーレポート:** 何が頭を固定しているかと、iPhone の頭のデータがどれだけ跳んだかが含まれ、原因をより正確に追えます。

## 2026/10/25 — v2.2.0

**新機能**

- **配信連携(ベータ・PRO):** 新しい「配信」ページで Twitch・CHZZK・SOOP・Discord をつなぐと、視聴者のチャンネルポイント・チャット・投げ銭・サブスク・風船などのイベントにアバターが反応します。ベータ版のため、実際の配信で問題があればエラーレポートでお知らせください(レポートに配信接続の記録が含まれます。トークン・コード・注文番号・メールアドレスは伏せられます)。
- **Discord で一緒に遊ぶ(ベータ・PRO):** Bot をサーバーに招待してチャンネルをアプリとつなぐと、フレンドが Discord のボタンや `/react` コマンドでアバターを反応させられます。ポイントを使うミニゲーム(出席・ルーレット・スロット・ブラックジャック・クイズ・ボス戦など)もあります。アプリの起動中のみ動作します。
- **かんたん設定(ベータ・PRO):** 「+」からプラットフォーム → イベント → 反応を選ぶだけで、すぐに動くルールができます。金額の範囲、視聴者ごとのクールダウン、投げ銭額に応じて投げる数を増やす設定にも対応しています。
- **ノードエディター(ベータ・PRO):** イベントと反応をノードでつないで、自由な演出を作れます。大きな専用ウィンドウ、ミニマップ、イベントノードごとの TEST ボタン付きです。
- **投げる・液体・ステッカー・転倒(PRO):** 小物をアバターに投げたり、水やミルクなどの液体をかけると体を伝って流れ、やがて乾きます。画像・GIF・視聴者のプロフィール画像をステッカーとして貼ることもできます。強く当たると倒れ、ゆっくり起き上がります。倒れている間の表情や起き上がる速さも選べます。
- **テストカード:** 配信 › インタラクションのいちばん下で、投げる・倒す・当てる・液体・ステッカーを配信なしですぐに試せます。
- **投げ銭表示ボックス(PRO):** 投げ銭した人の名前とメッセージをシーン内のボックスに表示します。初期設定はオフです。
- **WebSocket(PRO):** 自分の PC 内だけで開く WebSocket で、ほかのプログラムと連携できます。初期設定はオフです。
- **DLC ルームパック:** BOOTH の追加コンテンツを購入し、注文番号をいつものコード入力欄に入れると、部屋一覧に新しい部屋13室が表示され、選ぶとダウンロードされます。日本の路地(昼・夜)、日本のアパート、学校のプール、ショールームギャラリー、教室(昼・夕方・夜)、コワーキングオフィスが、元のシーンの照明と雰囲気のまま入っています。部屋の明かりはオン/オフと明るさを変えられ(部屋と一緒に保存)、カメラをさえぎる壁は映像からだけ外れます。Basic でも使えます。
- **スクリーンオブジェクト:** スタジオ › オブジェクトに「スクリーン」を追加すると、画像・GIF、モニターやウィンドウ、Spout・NDI の映像をシーン内に表示できます。

**変更点**

- **パネルのデザインを一新しました。** まとまったカード、セグメントタブ、右端のボタン、背景がほんのり透ける半透明のレールと浮かぶツールバーになりました。縦の配置と左のメニューはそのままです。半透明のぼかしは配信・録画・仮想カメラには映りません。Windows の透明効果をオフにすると不透明になります。
- **メニューの場所:** Twitch・CHZZK の接続とリモートセッションは新しい「配信」ページへ、写真と撮影フレームはスタジオ › 「写真と録画」タブへ、転倒の設定は配信 › インタラクションへ移しました。長いページは小見出しでまとめました。自分で変えたカードの順番と折りたたみはそのまま残ります。
- **名前の変更:** 「待機・重ねアニメーション」→「アニメーションレイヤー」、「目の設定」→「目の動き」、「視線の制御」→「見る対象」。
- **口の動き:** 口のソースを「顔(iPhone)」または「オフ」にしている場合、マイクで口が動かなくなりました。声で口を動かすには「顔 + マイク」または「マイク」を選んでください。
- **アプリ録画の音:** マイクに加えて、画面共有中は共有しているゲームの音も録音されます。
- **右クリックメニュー:** アバター・カメラ・シーン・オブジェクト・プリセットなど、すべての一覧で右クリック(または ⋯)から名前の変更・複製・削除ができ、Delete・F2 キーも使えます。
- **セッションの同意:** リモートセッションへの参加は、チェック1つと「データのやりとり」スイッチ1つになりました。これまでの設定はそのまま残ります。
- **コード入力:** アップグレードや DLC のコードも「ほかのコードを入力」ウィンドウひとつで入力します。
- **ローポリインテリア:** 「建物全体」の選択をなくしました(分かれた部屋はそのまま)。建物全体で保存したシーンは部屋なしで開きます。
- **DLC の部屋を選ぶと**、スタジオの環境光・反射の強さ・フォグがその部屋に合わせて一度だけ変わります。その後は自由に変えられ、シーンに保存されます。内蔵の部屋や部屋なしに切り替えると既定値に戻り、部屋の明かりでアバターが明るくなりすぎることはありません。
- **エラーレポート**に配信接続の状態と最近のイベントが含まれるようになり、連携がうまくいかないときの原因をより正確に追えます。
- 既存の .vavatar をそのまま使用でき、再エクスポートは不要です。

## 2026/10/22 — v2.1.0

**新機能**

- **ライティングの拡張:** 写真用ライト配置とソフトボックスなどの近似ライト、ビーム品質・ゴボ(クッキー)・ボリュームライト・局所フォグ、ネオン・RGB・LEDテープ・キャンドル・モニター・太陽・月などの装飾・環境ライト、ムービングヘッドとレーザーを追加しました。パルス・点滅・カラーサイクル・パン/チルトなどのライトアニメーションや、音に反応するライトも使えます。

- **ゲームライト同期:** 共有中のゲーム画面の色と明るさを、アバターのライティングにリアルタイムで反映します。初期設定はオフです。
- **アンビエントプロジェクション:** ゲーム画面をぼかした光をアバターにほんのり映し、画面の雰囲気にアバターが自然になじむようにします。アバターにだけ映り、透明背景はそのままです。初期設定はオフです。
- **空・フォグ・光:** 空の背景4種、フォグ、壁に跳ね返る光、よりやわらかい影を追加しました。
- **部屋の編集:** 部屋の壁・床・ドア・窓・家具をひとつずつ隠したり動かしたり、元に戻したりできます。種類ごとの一括オン/オフ、隠したパーツの再表示、部屋の照明のスイッチと明るさ、アバターの立ち位置の選択に対応しています。変更した部分だけがシーンに保存されます。 配信カメラを遮る壁とその壁に掛かった小物、視界をふさぐ小物は映像からだけ外れ、影と明かりはそのまま残ります。
- **新しい室内空間:** 部屋4つと家一軒を追加しました。窓の外の景色まで入っており、部屋を選ぶとその部屋に合った雰囲気(跳ね返る光・隅の陰影・反射)も適用されます。既存の室内空間も建物全体を選べるようになりました。
- **シーケンサー:** キー・ドープシート・グラフ・ポーズコピー・ピン・クリップのミックス・ベイクなど、Blenderに近い編集に対応しました。.vrma・.bvh・.vmdのモーションを読み込め、ファイルごとに腕の角度と移動の大きさを記憶します。
- **フリーポーズ:** 手・足・腰をドラッグすると体全体が自然についてきます。腰を下げても足は床に残ります。
- **固定ポーズの呼吸:** ポーズを固定しても呼吸が続き、アバターが固まって見えません。
- **スタート画面:** アバター・デバイス・リストがひと目でわかるよう配置を整理しました。

- 座る・寝るなど姿勢を変えたとき、体から出るパーティクル効果が立っていた位置から出る問題を修正しました。
- 半透明の髪が画面効果と重なって透けて見える問題を修正しました。
- リモートセッションでやわらかい影の設定も共有されます。
