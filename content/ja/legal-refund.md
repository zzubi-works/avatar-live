# 返金ポリシー

**施行日：2026年10月9日**

## 返金はできません

Avatar Live は **ダウンロード型のデジタル商品** です。

- **購入後の返金はできません。**
- デジタル商品の性質上、**購入後一定期間（例：14 日）内の申込みの撤回・返金も適用されません。**
- 単なる気変わり、利用環境の未確認、アバタープロジェクトがない場合、ほかのソフト・アバター・シェーダーとの互換性の問題、エディションの選択違いの場合も返金はできません。

## 購入前に必ずご確認ください

- [ ] Windows 10 / 11 64 ビットの PC ですか？（macOS・Linux 非対応）
- [ ] DirectX 11 に対応したグラフィックカードがありますか？
- [ ] 使いたいアバターの **Unity プロジェクト**（Unity 2022.3、VRChat に正常にアップロードできる状態）がありますか？ VRM・.vrca ファイルだけでは使えません。
- [ ] 一般的なカラー Web カメラがありますか？
- [ ] アクティベートとライセンス確認のためにインターネットに接続できますか？
- [ ] [対応範囲](12-troubleshooting.md#対応範囲)を確認しましたか？
- [ ] 配信・商用利用の場合、**Pro** を選びましたか？（[エディション](13-license.md#エディション)）

## 決済・返金に関するお問い合わせ

決済は **BOOTH（pixiv Inc.）** を通じて行われます。決済・返金に関するお問い合わせは、販売者ではなく **BOOTH に直接** お願いします。販売者には返金を処理する機能がありません。
