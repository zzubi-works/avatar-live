# 配信連携

> 💡 2.2.0 で追加された機能です。2.1.2 以前にはありません。

Twitch・CHZZK・SOOPの視聴者イベントや、Discordの友達のリアクションを受け取って、アバターが反応するようにします。配信連携はPro機能で、現在はベータです。実際の配信で問題が起きたら、[エラーレポート](12-troubleshooting.md#配信連携がうまくいかないとき)でお知らせください。

配信ページには2つのタブがあります。

| タブ | できること |
|---|---|
| インタラクション | イベントが届いたときに何をするかを決めます。[かんたん設定](09-interactions.md)、[ノードエディター](09-node-editor.md)、[倒れる・寄付表示・テスト](09-reactions.md)があります。 |
| 接続 | プラットフォームのアカウントとDiscordのチャンネルを接続し、WebSocketと[リモート合同配信](09-session.md)のセッションを開きます。 |

![配信 › 接続タブのプラットフォーム一覧](img/guide-broadcast-connect.png)

## Twitch・CHZZK・SOOPの接続

1. 配信 → 接続を開きます。
2. 接続するプラットフォームのスイッチをオンにします。
3. ブラウザーに開いたプラットフォームのログイン画面で、自分の配信アカウントにログインし、権限を許可します。
4. カードに接続済みと表示されれば、イベントを受け取る準備は完了です。

![Twitchカードのウィスパー・デバッグログ設定](img/guide-twitch.png)

| プラットフォーム | 受け取れるイベント |
|---|---|
| Twitch | チャンネルポイント使用、チャット、フォロー、サブスク（ギフト・サブスクメッセージを含む）、ビッツ、レイド、ハイプトレイン、ウィスパー |
| CHZZK | チャット、ドネーション（チャット・動画）、サブスク |
| SOOP | チャット、スターバルーン、アドバルーン、動画バルーン、ステッカー、サブスク、ギフト |

スイッチをオフにすると、それ以上イベントを受け取りません。保存されたログインとルールは削除されません。デバッグログをオンにすると、受け取ったイベントが診断ログに詳しく残ります。

> 🔒 Twitch・CHZZK・SOOPのログインは、Avatar Liveのサーバーを経由して接続します。ログイン情報はご自身のPCにだけ保存され、サーバーには残りません。

## Discordの接続

配信を見ていない友達も、Discordのチャンネルでボタンや`/リアクション`コマンドを使ってアバターを動かせます。Avatar Liveのアプリが起動しているときだけ動作します。

![Discordカードのリアクション一覧](img/guide-discord.png)

### 1. Discordアプリを追加する

[Avatar Live Discordアプリを追加する](https://discord.com/oauth2/authorize?client_id=1563157504995754014)を開き、追加先を選びます。アプリが求めるのはコマンド（`applications.commands`）の権限だけです。メッセージを読んだり、サーバーを管理したりはしません。

| 追加先 | 使う場合 |
|---|---|
| サーバーに追加 | 自分のDiscordサーバーのチャンネルで使います。サーバーの管理権限が必要です。友達は何もインストールしません。 |
| 自分のアカウントに追加 | サーバーがない場合や、グループDMで使います。グループDMでコマンドを直接入力するには、その友達もアプリを自分のアカウントに追加する必要があります。インストールしていない友達は、自分が投稿したボタンを押します。 |

### 2. チャンネルを接続する

1. アプリで配信 → 接続 → Discordのスイッチをオンにします。
2. 接続コードを作るを押します。8桁のコードが10分間表示されます。
3. 接続するDiscordのチャンネルで`/接続`コマンドを選び、コード欄にそのコードを入力して送信します。
4. アプリに「接続しますか？」というウィンドウが表示されたら、サーバーとチャンネルの名前を確認して接続を押します。
5. 接続済みチャンネルの一覧に、そのチャンネルが表示されます。

コードは1回だけ使えます。他の人がすでに接続したチャンネルは接続できません。

### 3. リアクションボタンを投稿する

1. 接続したチャンネルで`/パネル`を送信します。リアクション一覧のリアクションがボタンとして投稿されます。
2. 友達がボタンを押すか、`/リアクション`でリアクションを選ぶと、そのリアクションを処理するルールが実行されます。
3. Discordのメッセージに、誰が何をしたかが表示されます。

リアクション一覧では、ボタンごとに名前・絵文字・値・ルールを決めます。値は、ルールの最小・最大個数の条件が見る数です。ルールを押すとルールが順に切り替わり、選んだルールのDiscordリアクショントリガーがオンになります。

### Discordのコマンド

| コマンド | 誰が | できること |
|---|---|---|
| `/接続 コード:` | 自分 | このチャンネルを自分のAvatar Liveに接続します。 |
| `/接続解除` | 自分・サーバー管理者 | このチャンネルの接続を解除します。 |
| `/パネル` | 自分・サーバー管理者 | リアクションボタンを投稿します。グループDMでも使えます。 |
| `/リアクション` | 友達 | リアクションを1つ選びます。選ばなければ最初のリアクションです。 |
| `/ポイント` `/出席` `/ギフト` `/ランキング` | 友達 | ポイントゲームのポイントを確認し、貯め、分け合います。 |
| `/ルーレット` `/スロット` `/ハイアンドロー` `/ブラックジャック` `/対決` `/予想` `/宝くじ` `/レース` `/クイズ` `/ボス戦` | 友達 | ポイントゲームのミニゲームです。 |

Discordの言語が英語の場合、コマンドも`/link`、`/unlink`、`/panel`、`/react`のように英語の名前で表示されます。

ポイントゲームのルールとポイントの値は、Discordカードのポイントゲームで決めます。ポイントはこのPCにチャンネルごとに保存されます。

> 🔒 Discordとアプリの間は、開発者のサーバーが中継します。友達のDiscordの名前とプロフィール画像が自分のアプリに届き、表示とステッカーに使われます。アプリがDiscordに自分から投稿することはなく、友達のコマンドにだけ応答します。

## WebSocket

![WebSocketカードのポート設定](img/guide-websocket.png)

他のプログラムが、このPCの中でAvatar Liveとイベントをやり取りできるようにします。初期設定はオフで、ポートは19190です。同じPCのプログラムだけが`ws://127.0.0.1:ポート`で接続できます。やり取りする内容は、[ノードエディター](09-node-editor.md)のWebSocketノードで扱います。

## BasicとPro

| 機能 | Basic | Pro |
|---|---|---|
| 配信ページの表示 | 可能 | 可能 |
| プラットフォーム・Discord・WebSocketの接続 | ロック | 可能 |
| かんたん設定・寄付表示・テスト | ロック | 可能 |
| ノードエディター | 表示・移動・拡大のみ | 編集・実行 |

Basicでも、保存されたログイン・ルール・グラフは削除されず、ロックされたまま残ります。
