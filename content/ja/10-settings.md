# 10. 設定

## 性能と設定が変えるもの

![設定](img/v45-settings.png)

| 設定 | 実際の効果 |
|---|---|
| アプリ FPS | 上げると動きが滑らかですが CPU/GPU 負荷が増え、下げると省電力になります。送出 FPS は別に確認します。 |
| 描画品質・解像度 | 高いほど髪や輪郭が鮮明ですが GPU 負荷が増えます。アプリの窓と OBS 出力解像度は別です。 |
| 影・ポストエフェクト | オフで軽くなりますが立体感や光学効果が減ります。スタジオごとのエフェクトも確認してください。 |
| ウィンドウサイズ・常に手前 | Windows の表示方法だけを変え、Spout2/NDI への送信解像度は変えません。 |
| X ボタン | 終了またはトレイ移動。配信中はトレイから送出が続く場合があります。 |
| UI 拡大率 | 文字とボタンの大きさが変わり、小さい画面ではスクロールが増えます。 |
| クイックツールバーの不透明度 | 高いほどボタンが目立ち、低いほどキャラクターを隠しません。 |
| アップデート自動ダウンロード | 有効で新バージョンを事前取得。オフでも起動時の確認と通知は行われます。 |
| 診断レポート送信 | ユーザーが送信を選んだときにログや再現状況を送ります。 |

ショートカットは背面でも動作することがあるためゲームとの競合を避けます。表情は押している間だけか切り替え式を選べます。F13–F24 と組み合わせキーが使え、Stream Deck の通常ホットキーからも起動可能です。

保存先に注意：アバター別設定は表情・ポーズ・保存ビュー、スタジオ別設定は部屋・舞台ライト・配信カメラ、Windows の機器はカメラ・マイクの選択です。環境を変えるとデバイスを選び直す場合があります。

## 一般・ウィンドウ・パフォーマンス

<div class="shot" markdown="1">

![設定ページ](img/settings.png)

- 起動時にメニューを開く — オフにすると、メニューなしで起動します。

- パフォーマンス — フレームレートと画質を決めます。下げると PC の負担が軽くなります。
- 影 — 髪やあごが、首や胸に落とす影です。オフにすると GPU の負担が軽くなります。
- 言語 — 한국어・English・日本語・简体中文
- UI — テーマ、パネルの位置、文字の大きさを変えます。

## ライセンス

現在のエディションを確認できます。

| ボタン | 内容 |
|---|---|
| 別のコードを入力 | 別のライセンスに切り替えます。 |
| Proにアップグレード | BOOTH で購入したアップグレードを入力して、Pro にします。 |
| 今すぐ確認 | ライセンスを再確認します。 |

## 診断・情報・アップデート

| 項目 | 内容 |
|---|---|
| 診断 › エラーレポートを送る | 問題が起きたときに、説明とログを送ります。押したときだけ送信されます。 |
| 情報 › 改善の提案を送る | 欲しい機能や、直してほしい点を送ります。 |
| お知らせ | 新しいお知らせは起動時に一度だけ表示し、過去のお知らせは設定からもう一度見られます。 |
| ログフォルダーを開く | ログファイルを確認します。 |
| 今すぐ確認・ダウンロード | 新しいバージョンを確認して、ダウンロードします。 |
| 再起動してインストール | すぐにアップデートします。アバターと設定はそのままです。 |

> Avatar Liveは起動するたびに更新を一度確認し、新しいバージョンがあれば緑色の通知を表示します。設定 › アップデート › アップデートを自動ダウンロード をオンにすると自動でダウンロードします。インストールは別の 終了時にインストール 設定または 再起動してインストール ボタンに従います。BOOTHから再ダウンロードしてもアバターと設定は維持されます。

## 起動時の更新確認とダウンロード

![アップデートの設定](img/settings-updates.png)

Avatar Liveは起動するたびに新しいバージョンを一度確認します。自動ダウンロードをOFFにしても更新確認と通知は続きます。アップデート設定から手動で確認・ダウンロードし、再起動後または終了時にインストールできます。アバターと設定は保持されます。

## エラーレポートの送信

![診断とエラーレポート](img/settings-diagnostics.png)

不具合があったら設定 › 診断 › エラーレポートを送るから、発生した操作を添えて送信してください。状況の説明だけより診断データと再現手順が原因調査に役立ちます。

## 問題・要望を送る

- 使っていて バグや問題 があれば、設定 › 診断 › エラーレポートを送る からお知らせください。どんな状況だったかを一、二行書いていただけると、原因を探す大きな手がかりになります。
- 欲しい機能や改善点 があれば、設定 › 情報 › 改善の提案を送る から送ってください。いただいたご意見は、アップデートの計画に反映します。
