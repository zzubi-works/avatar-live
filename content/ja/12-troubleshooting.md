# 問題解決

症状に合った項目から確認してください。設定を見つけにくい場合は、上部の虫眼鏡で名前を検索できます。

## 起動とアバター

| 症状 | まず試すこと |
|---|---|
| 起動がうまくいきません | Shiftキーを押しながら実行して、Webカメラ・マイクなしのセーフ起動を使用します。 |
| ファイルが変更されたと言われます | 購入先から受け取った元のZIPを新しいフォルダーに解凍して実行します。 |
| アバターが見えません | 顔・上半身・全身の構図で再設定します。 |
| 一部がピンク色です | 元のUnityプロジェクトのマテリアル・シェーダーを確認した後、再出力します。 |
| 髪がもつれています | 上部の初期化を押します。 |

## 顔と手

| 症状 | まず試すこと |
|---|---|
| Webカメラが起動しません | 他のアプリがカメラを使用していないか確認します。 |
| アバターが動きません | デバイス → トラッキングソースで各部位が実際に接続したデバイスを使用しているか確認します。 |
| 顔の向きがずれます | 正面を見て、正面補正を押します。 |
| ウィンクができません | まばたき方式を別に変更します。 |
| 表情が大きすぎたり小さすぎます | 自動顔設定を行うか、顔調整の感度を合わせます。 |
| 指が震えます | 手の震え補正を少し高くします。 |
| 手を伸ばすと腕がねじれます | 実験的な手の深さ推定をオフにして、以前の腕の方式と比較します。 |
| 待機姿勢に変わりません | 待機姿勢を指定し、メニュー → 基本・AFK姿勢の待機時間を確認します。 |
| iPhone接続後に反応がありません | 携帯アプリがPCアドレスに送信しているか確認し、正面で初期補正を待ちます。 |
| VMC姿勢がずれます | 入力状態を確認し、Tポーズ・整列で合わせます。 |

## OBSと映像出力

| 症状 | まず試すこと |
|---|---|
| Spout2 Captureがありません | OBS用Spout2プラグインをインストールした後、OBSを再起動します。 |
| NDI Sourceがありません | DistroAVと対応バージョンが要求するNDI Runtimeをインストールします。 |
| 背景が黒くなります | Avatar Liveの背景を透明にし、OBSソースはアルファ合成に設定します。 |
| 送信名を変更した後に表示されません | OBSソースで新しい名前を再度選択します。 |
| 仮想カメラがリストにありません | デバイスを登録した後、受信アプリを完全に再起動します。 |
| 自分の画面と配信の構図が異なります | 配信対象がシーンビューかスタジオカメラか確認します。 |

詳しいインストール手順は[出力](09-output.md)を確認してください。

## 画面共有

- Discordリストにない場合: 画面共有をオンにして、アプリケーションタブでAvatar Live Share Outputを探します。
- ゲーム画面が黒い：ゲームを枠なしウィンドウモードに切り替えてみます。
- 共有音なし: オーディオの対象とアプリの音量を確認します。仮想オーディオデバイスの案内がある場合は、[VB-CABLEの案内](13-license.md#vb-cable)を確認してください。
- 通話の音が再び聞こえる: 共有するアプリにDiscordが含まれているか確認します。

## リモートコラボ配信

合同配信のセッションは、配信 → 接続のいちばん下にあります。ホストがサーバーを起動したか、参加アドレス・ポート・パスワードが正しいかをまず確認します。外部の友達が接続できない場合は、[接続できないとき](09-session.md#接続できない場合)のポートフォワーディング・ファイアウォールの案内を開いて確認してください。

相手が代替アバターに見える場合、アバターの表示とデータ送信の同意を確認してください。送信が許可されていないモデルは代替アバターとして使用してください。

## 配信連携がうまくいかないとき

配信連携はベータです。イベントが届いてもアバターが反応しない場合は、順に確認してください。

1. 配信 → 接続で、そのプラットフォームのカードが接続済みになっているか確認します。ログインが切れていたら、スイッチをオフにしてからオンにし、もう一度ログインします。
2. 配信 → インタラクションで、その項目のスイッチがオンか、トリガーの最小金額・報酬のタイトルが合っているか確認します。
3. 項目の▶テストで反応が出るか確認します。テストでも反応しない場合は、アクションの設定（物や画像が空になっていないか）を確認します。
4. クールダウン中に同じイベントが届いても実行されません。
5. Discordは、アプリが起動していて、チャンネルが接続済みチャンネルの一覧にある必要があります。友達に「オフになっています」と表示される場合は、アプリかDiscordのスイッチがオフです。

それでも解決しない場合は、問題が起きた直後に設定 → 診断 → エラーレポートを送るでお知らせください。レポートには次の内容が入り、原因を追跡できます。

- プラットフォーム・Discord接続ごとの状態の記録（切断の理由とコード）、ログインの権限、購読の応答、失敗したリクエスト
- 最近のイベント16件と、かんたん設定の項目・グラフが各イベントに対して何をしたか、またはしなかった理由

> 🔒 診断資料では、トークン・認証ヘッダー・Cookie・コード・セッションキー・注文番号・メールアドレス・ファイルパスが伏せられます。レポートは、ユーザーが送信を選んだときだけ送られます。

## 画面が遅いまたはぼやけているとき

1. 出力解像度とFPSを下げてみます。
2. マルチビューの更新率と枠の数を減らします。
3. 使用していないカメラごとのSpout2出力をオフにします。
4. 環境光遮蔽・被写界深度・ボリュメトリック照明などの効果をひとつずつオフにしてみます。
5. 全体がかすんでいる場合は、ブルームの強さ・しきい値とブラーを確認します。

## 解決されない場合

設定 → 診断 → エラー報告を送信 で次の内容を記載します。

- どのボタンを押したか、または設定を変更したか
- 何が異常に見えたか
- 使用しているデバイスとアバターの種類
- 同じ問題が再発する順序

実際の送信は、ユーザーが選択したときに行われます。

## サポート範囲

- `.vavatar` と VRM 0.x・1.0 アバター
- アバターの表情メニュー・アニメーター・PhysBone などサポートされた機能
- アバターに含まれる顔追跡設定と表情
- ウェブカメラ・マイク・iPhone・VMC 入力

一部の VRM 0.x の特殊シェーダーはサポートされない場合があります。アプリで実験的に表示された機能は、デバイスと環境により結果が異なる可能性があります。
