# 5. アバターメニュー

## v2.0.0：アバターメニューの各操作が変えるもの

![v45 アバターメニュー](img/v45-menu.png)

| 操作 | 実際の動作 |
|---|---|
| **Toggle** | 一度押すとオン、もう一度押すとオフ。衣装やアクセサリーなどの変化は元のアバターの Animator 設定によります。 |
| **Button** | 押している間だけ有効で、離すと元に戻ります。切り替え式とは別です。 |
| **Radial** | 0–100% の連続値。表情の強さや衣装の変形など、制作者が設定したパラメータに中間値を送ります。 |
| **2軸／4軸 Puppet** | 複数パラメータをパッドの左右・上下へ同時に変更。中央は初期状態で、方向の意味は元のアバター設定によります。 |
| **Sub Menu** | 同じアバターの下位メニューを開きます。他人のアバターに切り替わるものではありません。 |
| **お気に入り・クイックアクション** | 既存の操作を深いメニューを開かず実行できるショートカットです。 |
| **ショートカット：ホールド／トグル** | ホールドは押す間のみ、トグルは次に押すまで維持。ゲームと競合するキーを避けてください。 |

**手のジェスチャー**は左右別に働きます。Web カメラの指関節、VMC グローブ、SteamVR コントローラーの自動入力が手動のジェスチャーを上書きする場合があります。意図せず戻るときは[指の入力元](06-devices.md)と[自動表情](07-motion.md)を確認します。

**マイ表情とポーズライブラリ**はアバター別です。静止 **.anim** は一定のシェイプキーを使い、複数フレームの **.anim** は時間とともに変化します。ポーズの**顔・頭・腕・指・胴体**の追跡許可を別々に切り替えれば、体を固定したまま顔だけ動かせます。

VRChat で使っていたアバターの **Expression メニュー** を、そのまま使えます。衣装やヘアのトグル、表情ボタン、Radial、Puppet が VRChat と同じように動作します。

## カードの並び順・ポーズ・マイ表情

![アバターメニューの保存ポーズ](img/menu-poses.png)

ポーズ、マイ表情、ハンドジェスチャーの見出しから開閉できます。見出しをドラッグしてカードを、個別のポーズ・表情タイルをドラッグして項目を並べ替えられます。

![アバターメニューのマイ表情](img/menu-myexpr.png)

- ポーズを押して適用・解除します。横のカメラアイコンからそのポーズの追跡設定を開きます。
- フェイシャル、頭、腕、指、胴体の5項目を独立してON/OFFできます。頭を固定して表情だけ動かすことも可能です。
- 標準の座りポーズは骨盤と脚を固定し、5項目の追跡を初期状態で許可します。
- タイルの右クリックでショートカット、複製、クイックアクションなど使用可能な操作を選べます。
- スタジオとメニューのマイ表情には、新しい表情を作成と .anim を読み込むボタンがあります。複数フレームの再生・ループは元のクリップ設定に従います。

## デフォルトに戻す

**アバターのパラメーター › デフォルトに戻す** を押すと、メニューの値がアバターの初期値に戻ります。衣装の状態のように保存される値は、次回の起動時にも引き継がれます。

## クイックアクション

よく使う操作を、ボタンやキーにしておけます。メニュー項目、ジェスチャー、カメラビュー、ライティングプリセットなどを登録でき、ボタンを右クリックすると名前や位置を変更できます。

## ヒエラルキー・メッシュ・シェイプキー

アバターのオブジェクトを、Unity のようにツリーで見て、その場で直せます。

- **ヒエラルキー** — アバターのオブジェクトをツリーで表示します。チェックでオン / オフし、目のアイコンはオブジェクトをオンにしたまま、画面からだけ隠します。
- **メッシュ** — すべてのメッシュを、ひとつの一覧で表示します。検索で、すばやく見つけられます。
- メッシュを押すと、横のパネルで **シェイプキー** をひとつずつ調整できます。自分で決めた値は、フェイストラッキングやアバターのアニメーションより優先されます。
- 一番上の **すべてリセット** ですべてのメッシュをアバターの元の状態に戻し、**すべて折りたたむ** でツリーを閉じます。

## リセット

| | リセット | すべてリセット |
|---|---|---|
| 内容 | トラッキング、手のポーズ、PhysBone を最初の状態に | 上記に加えて、衣装・位置・カメラまで最初の状態に |
| 実行 | 上部の **⟲** | **⟲** を右クリック、または **設定 › 一般** |
