# アバターメニュー

衣装・髪型・表情など、アバター作成者が設定した機能を使用します。モデルによってメニュー名や項目が異なります。

## 衣装と表情を変える

![一般の表情ボタンがあるサブメニュー](img/guide-avatar-menu.png)

| 操作 | 動作方式 |
|---|---|
| オン・オフ | 一度押すとオンになり、もう一度押すとオフになります。衣装や装飾を変更する際に主に使用します。 |
| 押すボタン | 押している間のみ適用されます。離すと解除されます。 |
| 円形スライダー | ハンドルを動かして0〜100％の間で値を設定します。関連する色・サイズ・表情の強さなどが変わります。 |
| 方向パッド | ハンドルを左右・上下に動かして、さまざまな表情や値を一緒に調整します。 |
| フォルダ | サブメニューを開きます。戻るを押すと、上位メニューに戻ります。 |

## よく使う項目をすぐ取り出す

![表情ボタンを右クリックして開くクイックアクション・ショートカット・お気に入りメニュー](img/guide-menu-context.png)

- お気に入り: メニューの上の方で素早く見つけます。
- クイックアクションに追加: 下部ツールバーに実行ボタンを作ります。
- ショートカットキーの指定：キーボードで該当項目を実行します。

ショートカットキーでは押している間はキーを離すと解除され、トグルは再度押すまで維持されます。

## 姿勢と追跡 (Pro)

![保存されたポーズと私の表情](img/guide-menu-poses.png)

1. ポーズタイルをタップして適用します。
2. ポーズ横のカメラアイコンでトラッキング設定を展開します。
3. フェイシャル・頭・腕・指・胴体をそれぞれオンまたはオフにします。

オンになっている部位は自分の動きを追従し、オフになっている部位は保存したポーズを維持します。例えば頭をオフにしてフェイシャルをオンにすると、首は固定したまま表情だけが動きます。

### 体勢別追跡

![ポーズカードの部位別追跡設定](img/guide-pose-tracking.png)

姿勢の横のカメラボタンを押すと、顔・頭・腕・指・胴体をそれぞれオン・オフできます。

- 点灯している部分：私の動きに従います。
- 消えた部分: 保存した姿勢を維持します。
- 例：腕を下ろして頭・フェイシャルをオンにすると、腕のポーズを維持しながら、首と表情が動きます。

## 基本姿勢と待機姿勢

![基本ポーズとAFKポーズの選択](img/guide-default-pose.png)

| 選択 | 使用するとき |
|---|---|
| 基本姿勢 | 普段追跡しない部分の基準姿勢です。 |
| AFK 待機姿勢 | 追跡を失ったときに使用する姿勢です。 |
| 待機表情 | AFK中に自動で適用される表情です。 |
| 机の姿勢 | 手がカメラに映らないときに使う腕・手の姿勢です。 |

待機姿勢に移る時間は、[トラッキングを失った場合](#トラッキングを失った場合)で合わせます。

### トラッキングを失った場合

![トラッキング喪失とAFK切替時間](img/guide-motion-afk.png)

AFKは顔と体のトラッキングを両方失ったときに使用する待機状態です。メニュー → 基本・AFKポーズで時間を設定します。

| 時間 | 長くすると |
|---|---|
| 待機時間 | 少し入力が途切れても姿勢を維持してさらに待ちます。 |
| 切替時間 | 待機ポーズにゆっくり移行します。 |
| 復帰時間 | 入力が戻った後、正常な動作にゆっくり戻ります。 |

待機中に使用するポーズと表情は [基本ポーズと待機ポーズ](#基本姿勢と待機姿勢) で選びます。

## 私の表情

新しい表情を作成して顔の形を調整して保存するか、`.anim` 表情ファイルを読み込みます。作成した表情はタイルで適用し、右クリックでクイックアクションやショートカットに接続します。

![自分で作った表情と表情の追加](img/guide-my-expression.png)

1. 「新しい表情を作成」を押します。
2. 顔のシェイプキーを動かして表情を作ります。
3. プレビューの強さで0%無表情から100%表情まで確認します。
4. 保存します。
5. 自分の表情タイルを押して適用します。

`.anim` の読み込みでUnity表情アニメーションを追加することもできます。動くファイルは時間に応じて表情が変わり、繰り返し有無はファイル設定に従います。

## 手のジェスチャー

![左手と右手のジェスチャー設定](img/guide-gestures.png)

左手と右手のグー・チョキ・パーなどを選びます。アバターに手の形ごとの表情が紐づいている場合、表情も一緒に変わります。ウェブカムの手の形でジェスチャーをオンにすると、実際の手の形を使用します。

## 元に戻す

アバターパラメーター → デフォルトに戻すを押すと、衣装・表情などのメニュー値がアバターのデフォルト値に戻ります。

## 階層構造とシェイプキー

- 階層構造: アバターの部品をツリーで表示します。チェックで部品をオン・オフにします。
- 目のアイコン: 部品の動作は維持しながら画面上だけ非表示にします。
- メッシュ: 見た目を描く部品を検索します。
- シェイプキー: 顔や体の変形量を直接調整します。直接固定した値はトラッキングより優先される場合があります。
