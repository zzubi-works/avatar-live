# 動き

自分の表情や動きがアバターにどれだけ大きく、どれだけ滑らかに反映されるかを決めます。設定はアバターごとに保存されます。

## 顔

![顔の追跡と表情の調整](img/guide-motion-face.png)

| 項目 | 調整すると |
|---|---|
| 顔追跡 | オンにすると自分の表情が反映されます。オフにすると顔入力は使用されません。 |
| ミラー | 鏡のように左右の動きを反映します。 |
| ジェスチャー → 表情 | 手の形に関連するアバターの表情を使用します。 |
| 表情感度 | 高くすると小さな表情でも大きく、低くすると落ち着いて表示されます。 |
| 柔らかさ | 上げると揺れが減り、下げると素早く反応します。 |

### 自動顔設定

![自動顔設定ガイド](img/guide-face-calibration.png)

1. 自動顔設定を押します。
2. 案内に従って正面を向くか、表情を作ります。
3. 測定を押して、次のステップに進みます。
4. 最後に「適用」を押します。

### 顔の調整

![目・眉・口を別々に調整する顔の調整](img/guide-face-adjust.png)

- 目・眉・口・頬：それぞれの表情が動く大きさを個別に調整します。
- 左右両方を同時に編集: オンにすると両側を同じ値にします。
- スムージング: 小さな表情の揺れを減らします。高すぎると反応が遅くなります。

### 表情が出ないとき

アバターにある表情だけが動かせます。VRCFaceTracking設定があればその設定を、ARKitシェイプキーがあればその顔の形を使用します。ない表情は感度を上げても新たに出現しません。

## 目 · 視線

![まばたきと視線の設定](img/guide-motion-eyes.png)

| 項目 | 結果 |
|---|---|
| 点滅別 | 左目と右目を別々に閉じます。ウィンクに使います。 |
| 点滅同期 | 両目を一緒に閉じます。 |
| 自動まばたき | 入力がなくても一定間隔でまばたきをします。 |
| 目の視線追跡 | 私の瞳の方向を反映します。 |
| カメラビュー | アバターの瞳をカメラの方に向けます。 |
| 見る対象 | カメラ・特定のアバターなど、見る対象を選びます。 |

頭の追跡と顔の追跡、カメラの視点はそれぞれ別々に設定します。頭を固定した姿勢でも、瞳だけをカメラに向けさせることができます。

## 口 · 表情

![マイクリップシンクと口の設定](img/guide-motion-mouth.png)

- リップシンクの強さ：上げると口をより大きく開きます。
- 自動レベル: 声の大きさに合わせて口の動きを調整します。
- 感度: 自動レベルをオフにすると表示されます。高いほど小さな声でも口が開きます。100% はささやきにも、0% は大きな声にだけ反応し、口が開き始める音の大きさ（dB）も一緒に表示します。
- 音声補正: 指示された母音を発音して自分の声に合わせます。
- 舌・頬の膨らみ: ボタンやショートカットキーでその表情を適用します。モデルに必要な表情がある場合に表示されます。

### 口を動かすソース

口のカードのソースで、アバターの口を何で動かすかを選びます。[デバイス](06-devices.md)のトラッキングソースにある口と同じ設定です。

| 選択 | 口の動き方 |
|---|---|
| 顔 | ウェブカムや iPhone が読んだ口の形に合わせます。 |
| 顔 + マイク | 顔と声の両方を使います。混ぜ方をすぐ下で選びます。 |
| マイク | 声だけを使います（リップシンク）。声を出さなければ、口を開けても閉じたままです。 |
| オフ | トラッキングで口を動かさず、アバターのアニメーションの口のままにします。 |

顔 + マイクの混ぜ方はアバターごとに保存されます。

- 話す間は声: 話している間は声が、黙っているときは顔が口を動かします。
- 大きく開いた方: 口の形ごとに、顔と声のうち大きく開いた方を使います。話している間も、大きく開けた口は開いたままです。

混ぜ方の違いは、顔トラッキングが口を動かすアバター（顔トラッキング用または Perfect Sync の口のシェイプがあるアバター）でだけ見えます。通常の VRChat ビセームだけのアバターは、どちらでも声がビセームを動かすので同じに見えます。iPhone から受けた口は声と混ぜません。

マイク → 顔は、声を顔トラッキングの口のシェイプにも送るかを決めます。自動は、アバターの口を顔トラッキングが動かすときだけ送ります。マイクが口を動かすソースのときだけ表示されます。

### 自動表情

![自動表情の接続設定](img/guide-auto-expression.png)

動作 → 自動表情でオンにします。笑顔・驚き・ウィンクなど検知する表情ごとに、自分の表情で保存した表情を接続します。そうすると、実際に笑ったり驚いたりした時に接続した表情が自動で出ます。

## 頭

![頭と体の動きの設定](img/guide-motion-body.png)

| 項目 | 調整すると |
|---|---|
| 頭の動き | 小さく・自然に・大きく の中で動きの大きさを選びます。 |

## 体

| 項目 | 調整すると |
|---|---|
| 体の追従 | 頭を回すと体も一緒に回ります。 |
| 自然な動き | じっとしていても小さな待機動作を加えます。 |
| 呼吸 | 呼吸しているような小さな体の動きを加えます。 |
| 上半身・全身 | デバイスから受け取った体の動きを反映します。 |

## 手

![腕・手のトラッキングと机上動作](img/guide-motion-hands.png)

| 項目 | 調整すると |
|---|---|
| 腕・手の滑らかさ | 上げると手の震えが減り、速い手振りは遅れて追従します。 |
| 動的方式 | 手を伸ばす距離の変化を反映する腕の方式を使用します。 |
| 以前の方式 | 既存の腕の動き方式と比較できます。 |
| 手の深さ推定 | ウェブカメラで前後の距離を推定します。実験的で、腕がねじれる場合はオフにしてください。 |
| 手を見失った時の復帰 | 手が見えないときに基本姿勢に戻る速さを変えます。 |

## デスク

手がカメラに映らないとき、キーボードやマウスの使用に合わせてアバターの手を動かします。

- 手の基本姿勢: デスクの高さ・手の間隔・手首の角度を合わせます。
- キーボード反応: タイピング時に指と手が動く大きさです。
- マウス反応: マウスを動かすときに手が追従する大きさです。
- 手を再びカメラに戻すとトラッキングに戻ります。

キーボード入力は手の動作を作るためだけに使用し、入力した文字は保存や送信を行いません。
