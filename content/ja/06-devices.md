# デバイス

ウェブカメラ・マイク・トラッカーを接続し、顔・体・手で使用する入力を選びます。

## カメラ · マイク

![ウェブカメラとマイクの設定](img/guide-devices.png)

| ボタン・項目 | 動作 |
|---|---|
| ウェブカメラスイッチ | 選択したカメラでトラッキングを開始または停止します。 |
| カメラリスト | 使用するウェブカメラを選びます。 |
| 正面補正 | 今向いている方向をアバターの正面に合わせます。 |
| トラッキング品質 | スムーズは動きを頻繁に計算します。バランス・節約はPC負荷を減らします。 |
| マイクスイッチ | 選択したマイクで口の動きを開始または停止します。 |
| 入力バー | 声の大きさを表示します。話すときに動くか確認してください。 |
| ノイズゲート | 小さな音では口が開かないようにします。 |
| 背景雑音測定 | 話していない間の音を測定して雑音基準を設定します。 |

ノイズゲートの基準を上げるとキーボード音に反応しにくくなりますが、小さな声も無視されることがあります。口がうまく動かない場合は基準を下げてみてください。

## トラッキング

### トラッキングソース

![体の部位ごとに入力を選ぶトラッキングソース](img/guide-tracking-sources.png)

顔・口・頭・目・腕・手・指・体をそれぞれ何で動かすかを選びます。

| 選択 | 使用する時 |
|---|---|
| ウェブカム | カメラに映る自分の顔・体・手の動きに合わせて動きます。 |
| iPhone | iPhone 顔アプリで表情と頭の動きを動かします。 |
| VMC | 他のモーションキャプチャアプリやトラッカーアプリの動作を受け取ります。 |
| Ultraleap | 専用の手トラッカーで手を動かします。 |
| SteamVR | HMD・コントローラー・トラッカーを体の部位に接続します。 |
| オフ | その部位には該当するトラッキング入力を使いません。 |

例: 顔は iPhone、腕と手はウェブカムに設定できます。 デバイスが接続されていても、部位のソースが別の入力を指していると動きません。

#### 口

口を何で動かすかは、この一覧の「口」の一か所で選びます。動作 › 口のカードには、いま選んでいるソースだけが表示されます。

| 選択 | 口の動き方 |
|---|---|
| 顔 | ウェブカムや iPhone が読んだ口の形に従います。 |
| 顔 + マイク | 顔と声を一緒に使います。混ぜ方はすぐ下で選びます。 |
| マイク | 声だけを使います（リップシンク）。声を出さなければ、口を開けても閉じたままです。 |
| オフ | トラッキングでは口を動かさず、アバターのアニメーションのままにします。 |

iPhone や VMC で顔を受け取っている間は、「顔」の代わりに「iPhone」「VMC」と表示されます。

顔 + マイクを選ぶと混ぜ方が表示され、アバターごとに保存されます。

- 話す間はマイク：話している間は声が、黙っているときは顔が口を動かします。
- 最大値：口の形ごとに、顔と声のうち大きく開いた方を使います。話している間も、大きく開けた口は開いたままです。

混ぜ方の違いは、顔トラッキングが口を動かすアバター（顔トラッキング用または Perfect Sync の口のシェイプがあるアバター）でだけ見えます。通常の VRChat ビセームだけのアバターは、どちらでも声がビセームを動かすので同じに見えます。

iPhone は口を自分で測るため、同じ場所の「iPhone の口にマイクを混ぜる」をオンにしたときだけ声と混ぜます。初期設定はオフで、以前のバージョンで作ったアバター設定ではオンになっている場合があります。

#### ウェブカム 全身と指

- 全身: カメラに映る胴体と脚を追跡します。机に隠れた脚は実際に見える通りには追跡されません。
- 指関節の追跡: 指の関節の曲げ伸ばしに合わせて動きます。
- 手の震え補正: 高くすると微細な震えが減り、速い動きは少し遅れてついてきます。

### SteamVR 接続

![SteamVR デバイス設定](img/guide-steamvr.png)

1. SteamVRでHMD・コントローラー・トラッカーが認識されるか確認します。
2. デバイス → SteamVRを起動します。
3. 装置を頭・手・体などの該当部位に接続します。
4. 補正を実行して、アバターと自分のデバイスの位置を合わせます。

### iPhone 接続

![外部顔追跡接続設定](img/guide-phone.png)

1. iPhoneとPCを同じWi-Fiに接続します。
2. 顔エンジンで iFacialMocap または FaceMotion3D を選びます。
3. このPCのアドレスをコピーし、携帯アプリの送信先アドレスに入力します。
4. 入力スイッチを入れて、正面をしばらく見ます。最初の顔入力の後、約3秒で開始補正が行われます。
5. 接続テストでデータが入ってくるか確認します。

| 項目 | オンにするか変更すると |
|---|---|
| ミラー | 左右の動きを鏡のように反映します。 |
| 接続が切れたらウェブカメラに切り替え | 携帯電話の接続が切れている間、ウェブカメラに切り替えます。 |
| iPhone アドレス | 携帯アプリにPCアドレスを入れない方式で使用します。通常の接続では空白のままにできます。 |

### VMC 接続

![VMCの入力と接続状態](img/guide-vmc.png)

1. 送信するアプリでVMC送信をオンにし、このPCの受信アドレス・ポートに送ります。
2. トラッキングソースで受け取る部位をVMCで選びます。
3. VMC 設定で受け取った本数と入力状態が表示されるか確認します。
4. 体の向きや腕がずれていたら、T字姿勢や整列で合わせます。

**VMCトラッキング動作確認済み機器：** ReboCap、HTC VIVE Tracker、Tundra Tracker。

装置の接続は正常なのに動きがおかしい場合は、[動き](07-motion.md)で滑らかさ・補正・追跡復帰の設定を確認してください。
