# 6. デバイス

## Web カメラとマイク

<div class="shot" markdown="1">

![デバイスページ](img/devices.png)

- **Web カメラ** のスイッチをオンにすると、顔と手のトラッキングが始まります。
- カメラの一覧から、使う Web カメラを選びます。
- **正面補正** — 今の顔の向きを正面に合わせます。
- **トラッキング品質** — ゲームと一緒に使うときは、**バランス** か **エコ** をおすすめします。
- **マイク** のスイッチをオンにすると、話すときに口が動きます。
- **ノイズゲート** — キーボードの音などの雑音では、口が動かないようにします。
- **背景ノイズを測定** — 静かにしている間にボタンを押すと、雑音の基準を自動で合わせます。

</div>

## トラッキングソース

<div class="shot" markdown="1">

![トラッキングソース](img/sources.png)

- 顔、口、頭、目、腕、手、指、体を何で動かすか、部位ごとに選びます。
- 部位ごとに、**Web カメラ**、**iPhone**、**VMC**、**Ultraleap**（手）を組み合わせて使えます。たとえば、顔は iPhone、体は全身トラッカー、手は Web カメラ、という使い方ができます。
- **顔エンジン** — Web カメラのエンジンか、顔アプリ（iPhone・VMC）を選びます。各デバイスの設定は、そのデバイスを使う部位の下に表示されます。
- **口** を **顔 + マイク** にすると、話しているときは声に、話していないときは口の形に合わせて動きます。
- **手ぶれ補正** — じっとしているときに、手や指が震えないようにします。

</div>

## 全身・指の関節（Web カメラ）

- **体** を Web カメラにすると、**全身** スイッチが表示されます。オンにすると、カメラに映っている胴体と脚に合わせて動き、横に **座り・立ち・脚トラッキング・脚は推定** が表示されます。
- デスクの前のように脚が映らないときは、肩の動きだけで上半身が傾いたり回ったりします。映っていない脚は、アバターのポーズのままにします。
- **指** を Web カメラにすると、**指の関節トラッキング** スイッチが表示されます。オンにすると、指の関節ごとの曲げ、開き、親指の動きをカメラで追います。

## VMC で受け取る（全身トラッカー・グローブ・ほかのアプリ）

<div class="steps" markdown="1">

1. 送信側のアプリ（全身トラッカーのアプリ、グローブのアプリ、モーションキャプチャーのアプリなど）で VMC 送信をオンにして、この PC に送ります。
2. **トラッキングソース** で、VMC で受け取る部位のソースを **VMC** にします。ほかの部位は、Web カメラ・iPhone のままにできます。
3. **VMC 設定** で、受け取っているボーンの数と、データが届いているかを確認します。
4. ポーズがずれるときは、**Tポーズ** または **合わせる** を押します。**リセット** で元に戻します。

</div>

- 指は、関節ごとの回転、開き、親指まで、そのまま反映します。
- 腕を VMC で受け取っている間に入力が途切れると、腕はデスク（キーボード・マウス）のポーズに戻ります。

> 💡 Web カメラ（全身・指の関節を含む）、iPhone、VMC の入力は、実際の機器で確認済みです。**試験的** と表示されている機能（Ultraleap、OSC など）は正常に動作する見込みですが、まだ開発者の環境ですべてのデバイスとアプリでテストできてはいません。問題があれば、**設定 › 診断 › エラーレポートを送る** からお知らせください。

## iPhone でフェイストラッキング（iFacialMocap・FaceMotion3D）

<div class="steps" markdown="1">

1. iPhone と PC を、同じ Wi-Fi に接続します。
2. **顔エンジン** で、顔アプリとして **iFacialMocap** または **FaceMotion3D** を選び、**このPCのアドレス** を **コピー** します。
3. iPhone の iFacialMocap アプリでは、歯車 › **Destination IP address（送信先IPアドレス）** にそのアドレスを入力します。FaceMotion3D では、アプリの接続設定で、この PC のアドレスに送るようにします。
4. スイッチをオンにすると、iPhone の表情がアバターに反映されます。表情の出方はアバターの設定に従います（[表情が動くしくみ](07-motion.md#表情が動くしくみ) を参照）。
5. つながらないときは、**接続テスト** を押して、データが届いているか確認します。

</div>

> 💡 **iPhoneのアドレス（任意）** 欄は、空欄のままで大丈夫です。iFacialMocap アプリで Destination IP address を使わない場合だけ入力してください。

> 💡 **途切れたらウェブカメラで代替** をオンにしておくと、iPhone との接続が途切れたとき、Web カメラが一時的に代わりにトラッキングします。
