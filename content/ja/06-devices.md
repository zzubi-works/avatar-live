# 6. デバイス

**デバイス** ページでは、何でアバターを動かすかを決めます。ここで決めたデバイスはすべてのアバターに共通です。

![デバイスページ](img/devices.png)

## Web カメラ

| 項目 | 内容 |
|---|---|
| **Web カメラ** スイッチ | Web カメラのトラッキングをオン / オフ |
| カメラ一覧 | 使用するカメラを選ぶ |
| **正面補正** | 今の顔の向きを正面に合わせる |
| **トラッキング品質** | **なめらか** / **バランス** / **エコ** — ゲームと一緒に使うときはバランスかエコ |

カメラに問題があると、このカードに理由が表示されます（未接続、映像が暗い、ほかのアプリが使用中など）。

## マイク

| 項目 | 内容 |
|---|---|
| **マイク** スイッチ | マイク（リップシンク）をオン / オフ |
| マイク一覧 | 使用するマイクを選ぶ |
| **入力** メーター | 今入っている音の大きさ |
| **ノイズゲート** | 背景ノイズでは口が動かないようにする |
| **背景ノイズを測定** | 静かにしている間にノイズを測って、ゲートを自動で合わせる |
| **ノイズゲートの詳細設定** | **自動 / 手動**、開く・閉じる基準、反応時間 |

## トラッキングソース

部位ごとに、何で動かすかを選びます。

| 項目 | 選択肢 |
|---|---|
| **顔エンジン** | 自動 / MediaPipe / OpenSeeFace |
| **腕 · 手 · 指** | MediaPipe / Ultraleap / オフ |
| **口** | 顔 + マイク / 顔 / マイク / オフ |
| **詳細** › 顔の表情 · 頭 · 目 | 顔 / オフ |

### OpenSeeFace

顔だけをトラッキングする別のエンジンです。Avatar Live には含まれていないため、ご自身でダウンロードして **インストールフォルダーの外** に置き、**OpenSeeFace フォルダー** で指定します。

### 顔アプリ連携（VMC · iFacialMocap）

Web カメラの代わりに、ほかのアプリや iPhone から顔のデータを受け取ります。

| 項目 | 内容 |
|---|---|
| **ソース** | なし / VMC / iFacialMocap |
| スイッチ | 受信を開始 |
| **ポート** / **iPhoneのアドレス** | 接続情報 |
| **同じネットワークの機器を許可** | 同じネットワークのスマートフォン・PC から受信 |
| **このPCのアドレス** · **コピー** | iFacialMocap アプリに入力するアドレス |
| **正面補正** | 今の頭の向きを正面に |

## Ultraleap ハンドトラッキング

Leap Motion / Ultraleap デバイスで腕・手・指をトラッキングします。Ultraleap のソフトウェアをインストールしてデバイスを接続したあと、トラッキングソースで **Ultraleap** を選んでください。

| 項目 | 内容 |
|---|---|
| スイッチ · 状態 | オン、デバイスと手が見えているか |
| **キャリブレーション（デバイスの位置）** | デバイスの位置・向き、手のサイズ、スムージング |
| **キャリブレート** | 手をキーボードの上に置いて押すと、その位置をキーボードの位置にする |

## 外部トラッキング（OSC · VMC）

この PC のほかのアプリと連携します。標準ではオフです。

| 項目 | 内容 |
|---|---|
| **OSC 入力（アバターパラメーター）** | VRChat 用の OSC ツールでアバターパラメーターを変更 |
| **VMC 入力（ほかのアプリの体・ボーン）** | ほかのモーションアプリから体のデータを受信、受け取る **部位** を選ぶ |
| **送信側のシェイプをアバターにそのまま書き込む** | 受け取った表情をそのまま適用 |

> **Ultraleap、OSC・VMC** は正常に動作する見込みですが、該当するデバイス・アプリが開発者の環境でまだテストされていない **実験的機能** です。

VMC の **出力** は [9 章](09-output.md#外部出力vmc)にあります。
