# 3. スタート画面とアバターライブラリ

## ライブラリの選択が変えること

![アバター読み込み後](img/v45-menu.png)

- .vavatar を読み込む：Exporter 1.0.6 で作ったファイルを登録します。Unity プロジェクトそのものを直接開くわけではありません。.vrm を読み込む：対応する VRM 0.x / 1.0 を読み込みますが、一部の未対応シェーダーは表示できません。
- 最近使った／フォルダー／取り込み済みはライブラリの表示カテゴリだけを変えます。トラッキングやカメラの動作を変えるものではありません。
- 既定／前回／毎回選ぶは起動時にどのアバターを表示するかを決めます。配信ごとにモデルを変えるなら毎回選ぶと取り違えを減らせます。
- 起動時にカメラ・マイクをオンにすると Windows のデバイスをすぐ使用します。他の通話アプリと競合する場合はオフにし、必要な時だけ手動でオンにします。
- アバターを切り替えるとそのアバター自身の表情、ポーズ、保存したビューが戻ります。前のモデルの全設定を次のモデルへ勝手にコピーするものではありません。
- 複数アバター (Pro)はシーンで複数のモデルを同時に使う機能で、完全な置き換えとは別です。編集するモデルを選んでください。

セッションとの違い： ライブラリの原本は自分の PC にあります。[リモートセッション](09-output.md)の自分のアバターデータを送るは別途同意が必要で、受信側ではセッション限定の暗号化一時キャッシュを使用します。相手の原本が自分のライブラリへ恒久的に登録されるわけではありません。

## スタート画面

![スタート画面](img/launcher.png)

| 項目 | 内容 |
|---|---|
| アバターを開く… | `.vavatar` ファイルを開きます。ウィンドウにドラッグ＆ドロップしても開けます。 |
| 最近・フォルダー・読み込み済み | 最近開いたアバター、アバターフォルダーのアバター、読み込んだアバターを表示します。 |
| 既定に設定 | このアバターですぐに開始するようにします。 |
| カメラ・マイク | 開始時に一緒にオンにするデバイスを選びます。 |
| 顔・手 | トラッキングの方式を選びます。 |
| 起動設定 | 毎回確認・前回のアバター・既定のアバターから選びます。 |
| ▶ Avatar Live を開始 | 選んだアバターで開始します。 |

> 💡 Shift を押したまま起動すると、Web カメラ・マイクを使わずに安全に開始します。デバイスの問題でうまく起動できないときに試してみてください。

## 起動中にアバターを切り替える

<div class="shot" markdown="1">

![アバターライブラリ](img/avatar-pop.png)

- 左上の アバター名 を押すと、ライブラリが開きます。
- 一覧のアバターを押すと、そのアバターに切り替わります。
- アバターファイルを追加… で、新しいアバターを読み込みます。
- オンにしていた Web カメラとマイクは、切り替えたあともそのままオンになります。

</div>

## メニューを初めて開くとき

アバターのロード中にメニューのレイアウトも準備するため、各メニューの初回表示が速くなりました。初期ロードは少し長くなる場合があります。左上のロゴから再起動せずにアバター選択へ戻れます。

## スタート画面に戻る

左上の ロゴ を押して、再起動 を選びます。
