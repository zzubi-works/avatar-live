# 2. アバターの書き出し

## v2.0.0：Exporter 1.0.6 と VRM 直接読み込み

**Unity のアバター（.vavatar）**と**VRM（.vrm）**では手順が違います。VRChat 向け Unity アバターは **Curious Bobby - Avatar Exporter 1.0.6**で出力します。対応する **VRM 0.x／1.0** はアプリへ直接読み込めるため、Exporter は不要です。

- **Unity プロジェクト**：Unity **2022.3.22f1** の元プロジェクトと対応する VRChat SDK を使用します。アバターを指定して **.vavatar を出力**します。Exporter 1.0.6 は VRChat SDK 3.10.5 に合わせた PhysBone／Collider と、衣装統合時に髪・アクセサリーの骨が無効になる問題を改善しています。
- **名前・表情クリップ・保存場所**：名前はライブラリに表示されるもの、クリップは追加表情、保存場所は Windows 上のファイルの出力先です。ファイルを作っただけではアプリのライブラリに登録されないので、作成後に開いてください。
- **モデルを変更したとき**：衣装・骨・素材を直した後は再出力します。モデル形状の変更で保存済みポーズやカメラ構図が変わる場合があるので、配信前に確認します。
- **VRM**：一部 VRM 0.x の未対応シェーダーは読み込めません。拡張子を名前変更してもシェーダー互換性は変わりません。
- **権利**：アバターデータを作成または所有していても、他人への送信権が自動的に付くわけではありません。モデル・衣装・テクスチャ・小物の規約を確認してから[セッションのデータ送信](09-output.md)に同意してください。

モデルの一部がピンクになったり消えたりした場合は Unity 側のマテリアル、シェーダー、PhysBone・Collider を確認して再出力し、Avatar Live で新しいファイルを読み込み直してください。

Avatar Live で使うアバターファイル（`.vavatar`）は、アバターの Unity プロジェクトに **Curious Bobby - Avatar Exporter** をインストールして作ります。

## 準備

- Unity **2022.3.22f1** のアバタープロジェクト
- VRChat に正常にアップロードできるアバター
- NDMF・Modular Avatar・VRCFury などを使ったアバターも、そのまま書き出せます。

## インストール

**VCC / ALCOM** にリポジトリを追加してから、アバタープロジェクトに **Curious Bobby - Avatar Exporter** を追加します。

```text
https://raw.githubusercontent.com/zzubi-works/avatar-exporter/main/index.json
```

`.unitypackage` でダウンロードした場合は、Unity の **Assets → Import Package → Custom Package…** からインポートしてください。

## 書き出し

1. Unity のメニューから **Curious Bobby → Avatar Exporter** を開きます。
2. **アバター** 欄に、書き出すアバターを入れます。
3. **.vavatar を書き出す** を押します。
4. 完了したら、**ファイルを表示** で作成されたファイルを確認します。

| 項目 | 内容 |
|---|---|
| **Avatar Live での表示名** | Avatar Live に表示される名前 |
| **表情クリップ（任意）** | 追加の表情アニメーションを入れて、[自動表情](11-pro-features.md#自動表情)で使用 |
| **保存フォルダー** | ファイルの保存先 |

> 💡 書き出しがうまくいかない場合は、まずアバターが VRChat に正常にアップロードできるか確認してください。

## アバターを改変したとき

Unity で改変したあと、書き出し直すだけで大丈夫です。ライティング、カメラ、顔の調整、衣装の状態など、アバターごとの設定はそのまま引き継がれます。

- 元のアバターとシーンは変更されません。
- 作成したファイルは自分の PC にだけ保存され、どこにもアップロードされません。
