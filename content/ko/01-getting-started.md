# 시작하기

아바타를 불러오고, 내 움직임을 연결하고, 방송 화면을 내보내는 순서로 시작합니다.

## 설치하고 실행하기

1. BOOTH 구매 내역에서 Avatar Live ZIP 파일을 받습니다.
2. 원하는 폴더에 압축을 모두 풉니다.
3. 폴더 안의 `AvatarLive.exe`를 실행합니다.
4. 제품 활성화 화면에 구매할 때 안내받은 정보를 입력하고 활성화를 누릅니다.

Windows 10 / 11 64비트와 DirectX 11 지원 그래픽 카드가 필요합니다. 얼굴과 손을 따라 움직이려면 웹캠을, 목소리로 입을 움직이려면 마이크를 준비하세요.

## 1. 아바타 열기

![아바타와 시작할 장치를 고르는 시작 화면](img/guide-launcher.png)

1. 아바타 열기를 누르거나 파일을 창에 끌어 놓습니다.
2. 아바타 목록에서 사용할 캐릭터를 고릅니다.
3. Avatar Live 시작을 누릅니다. 장면 목록이 나오면 사용할 장면을 고릅니다.

| 가진 파일 | 할 일 |
|---|---|
| `.vavatar` | 그대로 불러옵니다. |
| `.vrm` | 그대로 불러옵니다. VRM 0.x와 1.0을 지원합니다. |
| Unity 아바타 프로젝트 | [아바타 내보내기](02-avatar-exporter.md)로 `.vavatar`를 만든 뒤 불러옵니다. |

## 2. 내 움직임 연결하기

![웹캠과 마이크를 켜는 장치 설정](img/guide-devices.png)

1. 왼쪽 장치를 누릅니다.
2. 웹캠 목록에서 사용할 카메라를 고르고 제목 오른쪽 스위치를 켭니다.
3. 화면을 정면으로 보며 정면 보정을 누릅니다.
4. 목소리로 입을 움직이려면 마이크도 고른 뒤 스위치를 켭니다.

iPhone이나 외부 트래커를 쓰면 [장치](06-devices.md)에서 연결 방법을 확인하세요.

## 3. 배경과 구도 정하기

![메뉴와 아바타가 함께 보이는 메인 화면](img/guide-main.png)

- 의상·표정: 왼쪽 메뉴에서 고릅니다.
- 얼굴·손 움직임: 동작에서 조절합니다.
- 배경·조명: 스튜디오에서 고릅니다.
- 구도: 하단 카메라 도구막대에서 얼굴·상반신·전신을 고릅니다.

F1을 누르면 메뉴를 숨기고 아바타만 봅니다. 다시 누르면 메뉴가 돌아옵니다.

## 4. 방송 프로그램에 연결하기

| 사용 목적 | 열 곳 |
|---|---|
| 이 PC의 OBS에 아바타 넣기 | [Spout2 연결](09-output.md#spout2) |
| 다른 PC의 OBS로 영상 보내기 | [NDI 연결](09-output.md#ndi) |
| Discord·Zoom 카메라로 사용 | [가상 카메라](09-output.md#가상-카메라) |
| 게임과 아바타를 함께 공유 | [화면 공유](09-output.md#화면-공유) |
| 친구의 아바타와 합동 방송 | [원격 합방](09-session.md) |
| 시청자 이벤트에 아바타가 반응 | [방송 연동](09-broadcast.md) |

방송을 시작하기 전에는 OBS나 공유받는 쪽의 실제 영상을 확인하세요. 내 작업 화면과 송출 카메라의 구도가 다를 수 있습니다.

## 에디션과 종료

Basic은 개인적·비공개 사용, Pro는 방송·영상 공개·상업적 이용에 사용합니다. [에디션별 기능](13-license.md)에서 필요한 기능을 확인하세요.

왼쪽 아래 전원 버튼으로 프로그램을 종료합니다. 창의 X 버튼이 트레이로 숨기도록 설정되어 있으면 송출은 계속됩니다. X 버튼 동작은 설정 → 창에서 바꿉니다.
