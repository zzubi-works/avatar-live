# 1. 시작하기

## 준비물

| 항목 | 필요 사항 |
|---|---|
| 운영체제 | **Windows 10 / 11 (64비트)** |
| 그래픽 | **DirectX 11** 지원 GPU |
| 웹캠 | 일반 컬러 웹캠 (얼굴·팔·손 트래킹용) |
| 마이크 | 립싱크용 (선택) |
| 인터넷 | 활성화와 라이선스 확인에 필요 |
| 아바타 | VRChat 아바타의 **Unity 프로젝트** (Unity 2022.3) — [2장](02-avatar-exporter.md)에서 `.vavatar`로 내보냅니다 |
| 선택 장치 | Leap Motion / Ultraleap 손 트래커, iPhone (iFacialMocap) |

## 에디션 고르기

| | Basic | Pro |
|---|---|---|

| 포징 · 오브젝트 · 화면 공유 추가 소스 | — | ✅ |

> 방송(라이브 스트리밍), 영상 업로드 등 **공개·상업적 용도로 쓰려면 Pro**가 필요합니다. 자세한 내용은 [13장](13-license.md)을 보세요.

## 설치

1. BOOTH 구매 내역에서 Avatar Live ZIP 파일을 내려받습니다.
2. 원하는 폴더에 **압축을 풉니다.** 압축을 푼 폴더가 설치 폴더입니다.
3. `AvatarLive.exe`를 실행합니다.

> **"Windows의 PC 보호" 창이 뜨면** **추가 정보 → 실행**을 누르세요.

> ⚠️ **설치 폴더의 파일을 바꾸거나 다른 프로그램을 넣지 마세요.** 원본과 다르면 Avatar Live가 시작하지 않습니다. 이때는 BOOTH에서 받은 원본으로 다시 설치하세요 (아바타와 설정은 그대로 남습니다).

## 제품 활성화

처음 실행하면 **제품 활성화** 화면이 뜹니다.

1. 오른쪽 위에서 언어를 고릅니다.
2. 구매 시 안내받은 정보를 입력하고 **활성화**를 누릅니다.
3. "활성화되었습니다."가 뜨면 끝입니다.

### 다른 PC로 옮기기

- 라이선스는 **1인 1기기**입니다.
- 다른 PC로 옮기는 것은 **딱 1회만** 가능합니다. 옮기면 이전 PC에서는 더 이상 쓸 수 없고, **그 뒤에는 어떤 경우에도 다시 옮길 수 없습니다.**
- 옮길 PC를 신중하게 정한 뒤 진행하세요.

## 처음 방송까지

1. **아바타 만들기** — 아바타 Unity 프로젝트에서 `.vavatar` 내보내기 ([2장](02-avatar-exporter.md))
2. **아바타 열기** — 시작 화면에서 **아바타 열기…** → **▶ Avatar Live 시작** ([3장](03-launcher-and-library.md))
3. **웹캠 켜기** — **장치** → **웹캠** 스위치 ([6장](06-devices.md))
4. **마이크 켜기** — **장치** → **마이크** 스위치
5. **얼굴 맞추기** — **동작** → **자동 얼굴 설정** ([7장](07-motion.md))
6. **배경 고르기** — **씬** → **배경** ([8장](08-scene.md))
7. **내보내기** — **출력** → Spout2 / 가상 카메라 / 화면 공유 ([9장](09-output.md))
8. **F1** — UI를 모두 숨긴 깨끗한 화면

## 종료하기

- 창의 **X**는 기본적으로 **트레이로 숨기기**입니다. 아바타와 출력은 계속 동작합니다.
- 완전히 끄려면 **트레이 아이콘 우클릭 → 종료**.
- X로 바로 종료하려면 설정 › 창 › **창 닫기 (X)** → **종료**.
