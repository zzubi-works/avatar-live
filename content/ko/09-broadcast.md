# 방송 연동

> 💡 2.2.0부터 있는 기능입니다. 2.1.2 이하에는 없습니다.

Twitch·치지직·SOOP 시청자 이벤트와 디스코드 친구의 반응을 받아 아바타가 반응하게 합니다. 방송 연동은 Pro 기능이며 지금은 베타입니다. 실제 방송에서 문제가 생기면 [오류 보고](12-troubleshooting.md#방송-연동이-안-될-때)로 알려 주세요.

방송 페이지에는 탭이 두 개 있습니다.

| 탭 | 하는 일 |
|---|---|
| 인터랙션 | 이벤트가 오면 무엇을 할지 정합니다. [간편 설정](09-interactions.md), [노드 편집기](09-node-editor.md), [쓰러짐·후원 표시·테스트](09-reactions.md)가 있습니다. |
| 연결 | 플랫폼 계정과 디스코드 채널을 연결하고, 웹소켓과 [원격 합방](09-session.md) 세션을 엽니다. |

![방송 › 연결 탭의 플랫폼 목록](img/guide-broadcast-connect.png)

## Twitch · 치지직 · SOOP 연결

1. 방송 → 연결을 엽니다.
2. 연결할 플랫폼의 스위치를 켭니다.
3. 브라우저에 열린 플랫폼 로그인 화면에서 내 방송 계정으로 로그인하고 권한을 허용합니다.
4. 카드에 연결됨이 표시되면 이벤트를 받을 준비가 끝났습니다.

![Twitch 카드의 귓속말·디버그 로그 설정](img/guide-twitch.png)

| 플랫폼 | 받을 수 있는 이벤트 |
|---|---|
| Twitch | 채널 포인트 사용, 채팅, 팔로우, 구독(선물·구독 메시지 포함), 비트, 레이드, 하이프 트레인, 귓속말 |
| 치지직 | 채팅, 후원(채팅 후원·영상 후원), 구독 |
| SOOP | 채팅, 별풍선, 애드벌룬, 영상풍선, 스티커, 구독, 선물 |

스위치를 끄면 이벤트를 더 받지 않습니다. 저장된 로그인과 규칙은 지워지지 않습니다. 디버그 로그를 켜면 받은 이벤트가 진단 로그에 자세히 남습니다.

> 🔒 Twitch·치지직·SOOP 로그인 과정의 토큰 교환은 개발자 서버(`stream-auth.erp.pictures`)를 거칩니다. 플랫폼의 비밀 키는 이 서버에만 있고, 받은 로그인 정보는 이 PC에 저장됩니다.

## 디스코드 연결

방송을 보지 않는 친구도 디스코드 채널에서 버튼이나 `/반응` 명령으로 아바타를 움직일 수 있습니다. Avatar Live 앱이 켜져 있을 때만 동작합니다.

![디스코드 카드의 반응 목록](img/guide-discord.png)

### 1. 디스코드 앱 추가하기

[Avatar Live 디스코드 앱 추가하기](https://discord.com/oauth2/authorize?client_id=1563157504995754014)를 열고 추가할 곳을 고릅니다. 앱은 명령(`applications.commands`) 권한만 요청합니다. 메시지를 읽거나 서버를 관리하지 않습니다.

| 추가할 곳 | 쓰는 경우 |
|---|---|
| 서버에 추가 | 내 디스코드 서버의 채널에서 씁니다. 서버 관리 권한이 필요합니다. 친구들은 아무것도 설치하지 않습니다. |
| 내 계정에 추가 | 서버가 없거나 그룹 DM에서 씁니다. 그룹 DM에서 명령을 직접 치려면 그 친구도 앱을 자기 계정에 추가해야 합니다. 설치하지 않은 친구는 내가 올린 버튼을 누릅니다. |

### 2. 채널 연결하기

1. 앱에서 방송 → 연결 → 디스코드 스위치를 켭니다.
2. 연결 코드 만들기를 누릅니다. 8자리 코드가 10분 동안 표시됩니다.
3. 연결할 디스코드 채널에서 `/연결` 명령을 고르고 코드 칸에 그 코드를 넣어 보냅니다.
4. 앱에 "채널을 연결할까요?" 창이 뜨면 서버와 채널 이름을 확인하고 연결을 누릅니다.
5. 연결된 채널 목록에 그 채널이 나타납니다.

코드는 한 번만 쓸 수 있습니다. 다른 사람이 이미 연결한 채널은 연결되지 않습니다.

### 3. 반응 버튼 올리기

1. 연결한 채널에서 `/패널`을 보냅니다. 반응 목록의 반응이 버튼으로 올라갑니다.
2. 친구가 버튼을 누르거나 `/반응`으로 반응을 고르면 그 반응을 처리하는 규칙이 실행됩니다.
3. 디스코드 메시지에 누가 무엇을 했는지 표시됩니다.

반응 목록에서 버튼마다 이름·이모지·값·처리 규칙을 정합니다. 값은 규칙의 최소·최대 개수 조건이 보는 수입니다. 처리 규칙을 누르면 규칙이 차례로 바뀌고, 고른 규칙의 디스코드 반응 트리거가 켜집니다.

### 디스코드 명령

| 명령 | 누가 | 하는 일 |
|---|---|---|
| `/연결 코드:` | 나 | 이 채널을 내 Avatar Live에 연결합니다. |
| `/연결해제` | 나·서버 관리자 | 이 채널의 연결을 풉니다. |
| `/패널` | 나·서버 관리자 | 반응 버튼을 올립니다. 그룹 DM에서도 됩니다. |
| `/반응` | 친구 | 반응을 하나 고릅니다. 고르지 않으면 첫 반응입니다. |
| `/포인트` `/출석` `/선물` `/순위` | 친구 | 포인트 게임의 포인트를 확인하고 모으고 나눕니다. |
| `/룰렛` `/슬롯` `/하이로우` `/블랙잭` `/대결` `/예측` `/복권` `/경주` `/퀴즈` `/보스전` | 친구 | 포인트 게임의 미니게임입니다. |

디스코드 언어가 영어면 명령도 `/link`, `/unlink`, `/panel`, `/react`처럼 영어 이름으로 보입니다.

포인트 게임의 규칙과 포인트 값은 디스코드 카드의 포인트 게임에서 정합니다. 포인트는 이 PC에 채널별로 저장됩니다.

> 🔒 디스코드와 앱 사이는 개발자 서버(`discord-check.erp.pictures`)가 전달합니다. 친구의 디스코드 이름과 프로필 그림이 내 앱에 전달되어 표시와 스티커에 쓰입니다. 앱은 디스코드에 스스로 글을 올리지 않고 친구의 명령에만 답합니다.

## 웹소켓

![웹소켓 카드의 포트 설정](img/guide-websocket.png)

다른 프로그램이 이 PC 안에서 Avatar Live와 이벤트를 주고받게 합니다. 기본은 꺼짐이고 포트는 19190입니다. 같은 PC의 프로그램만 `ws://127.0.0.1:포트`로 접속할 수 있습니다. 주고받는 내용은 [노드 편집기](09-node-editor.md)의 웹소켓 노드로 다룹니다.

## Basic과 Pro

| 기능 | Basic | Pro |
|---|---|---|
| 방송 페이지 보기 | 가능 | 가능 |
| 플랫폼·디스코드·웹소켓 연결 | 잠김 | 가능 |
| 간편 설정·후원 표시·테스트 | 잠김 | 가능 |
| 노드 편집기 | 보기·이동·확대만 | 편집·실행 |

Basic에서도 저장된 로그인·규칙·그래프는 지워지지 않고 잠긴 채 남습니다.
