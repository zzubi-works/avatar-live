# 동작

내 표정과 움직임이 아바타에 얼마나 크게, 얼마나 부드럽게 반영될지 정합니다. 설정은 아바타별로 저장됩니다.

## 얼굴

![얼굴 추적과 표정 조절](img/guide-motion-face.png)

| 항목 | 조절하면 |
|---|---|
| 얼굴 추적 | 켜면 내 표정이 반영됩니다. 끄면 얼굴 입력을 사용하지 않습니다. |
| 미러 | 거울처럼 좌우 움직임을 반영합니다. |
| 제스처 → 표정 | 손 모양에 연결된 아바타 표정을 사용합니다. |
| 표정 민감도 | 높이면 작은 표정도 크게, 낮추면 차분하게 나옵니다. |
| 부드러움 | 높이면 떨림이 줄고, 낮추면 빠르게 반응합니다. |

### 자동 얼굴 설정

![자동 얼굴 설정 안내](img/guide-face-calibration.png)

1. 자동 얼굴 설정을 누릅니다.
2. 안내에 맞춰 정면을 보거나 표정을 짓습니다.
3. 측정을 누르고 다음 단계로 진행합니다.
4. 마지막에 적용을 누릅니다.

### 얼굴 조정

![눈·눈썹·입을 따로 맞추는 얼굴 조정](img/guide-face-adjust.png)

- 눈·눈썹·입·볼: 각 표정이 움직이는 크기를 따로 맞춥니다.
- 왼쪽·오른쪽 함께 편집: 켜면 양쪽을 같은 값으로 바꿉니다.
- 스무딩: 작은 표정 떨림을 줄입니다. 너무 높으면 반응이 늦습니다.

### 표정이 안 나올 때

아바타에 있는 표정만 움직일 수 있습니다. VRCFaceTracking 설정이 있으면 해당 설정을, ARKit 쉐이프키가 있으면 해당 얼굴 모양을 사용합니다. 없는 표정은 민감도를 올려도 새로 생기지 않습니다.

## 눈 · 시선

![깜빡임과 시선 설정](img/guide-motion-eyes.png)

| 항목 | 결과 |
|---|---|
| 깜빡임 따로 | 왼눈과 오른눈을 따로 감습니다. 윙크에 사용합니다. |
| 깜빡임 동기화 | 양쪽 눈을 함께 감습니다. |
| 자동 깜빡임 | 입력이 없어도 일정하게 눈을 깜빡입니다. |
| 눈 시선 추적 | 내 눈동자의 방향을 반영합니다. |
| 카메라 보기 | 아바타 눈동자를 카메라 쪽으로 향하게 합니다. |
| 바라보기 대상 | 카메라·특정 아바타 등 바라볼 대상을 고릅니다. |

머리 추적과 페이셜 추적, 카메라 보기는 각각 따로 설정합니다. 머리를 고정한 자세에서도 눈동자만 카메라를 보게 할 수 있습니다.

## 입 · 표정

![마이크 립싱크와 입 설정](img/guide-motion-mouth.png)

- 립싱크 강도: 높이면 입을 더 크게 벌립니다.
- 자동 레벨: 목소리 크기에 맞춰 입의 움직임을 맞춥니다.
- 감도: 자동 레벨을 끄면 나옵니다. 높일수록 작은 목소리에도 입이 열립니다. 100%는 속삭임에도, 0%는 큰 목소리에만 반응하며, 입이 열리기 시작하는 소리 크기(dB)도 함께 보여 줍니다.
- 음성 보정: 안내된 모음을 발음해 내 목소리에 맞춥니다.
- 혀·볼 부풀림: 버튼이나 단축키로 해당 표정을 적용합니다. 모델에 필요한 표정이 있어야 보입니다.

### 입을 움직이는 소스

입 카드의 소스에서 아바타의 입을 무엇으로 움직일지 고릅니다. [장치](06-devices.md)의 트래킹 소스에 있는 입과 같은 설정입니다.

| 선택 | 입이 움직이는 방식 |
|---|---|
| 얼굴 | 웹캠이나 iPhone이 읽은 내 입 모양을 따릅니다. |
| 얼굴 + 마이크 | 얼굴과 목소리를 함께 씁니다. 섞는 방법을 바로 아래에서 고릅니다. |
| 마이크 | 목소리만 씁니다(립싱크). 소리를 내지 않으면 입을 벌려도 다물어 있습니다. |
| 끔 | 추적으로 입을 움직이지 않고 아바타 애니메이션의 입 그대로 둡니다. |

얼굴 + 마이크의 섞는 방법은 아바타마다 저장됩니다.

- 말할 때 목소리: 말하는 동안은 목소리가, 조용할 때는 얼굴이 입을 움직입니다.
- 더 크게 벌린 쪽: 입 모양마다 얼굴과 목소리 중 더 크게 벌린 쪽을 씁니다. 말하는 중에도 크게 벌린 입은 벌어진 채로 남습니다.

섞는 방법의 차이는 얼굴 추적이 입을 움직이는 아바타(얼굴 추적용 입 셰이프나 Perfect Sync 입 셰이프가 있는 아바타)에서만 보입니다. 일반 VRChat 비셈만 있는 아바타는 어느 쪽이든 목소리가 비셈을 움직여 똑같이 보입니다. iPhone으로 받은 입은 목소리와 섞지 않습니다.

마이크 → 얼굴은 목소리를 얼굴 추적의 입 셰이프에도 보낼지 정합니다. 자동은 아바타의 입을 얼굴 추적이 움직일 때만 보냅니다. 마이크가 입을 움직이는 소스일 때만 나옵니다.

### 자동 표정

![자동 표정 연결 설정](img/guide-auto-expression.png)

동작 → 자동 표정에서 켭니다. 미소·놀람·윙크 등 감지할 표정마다 내 표정에서 저장한 표정을 연결합니다. 그러면 실제로 웃거나 놀랄 때 연결한 표정이 자동으로 나옵니다.

## 손

![팔·손 추적과 책상 동작](img/guide-motion-hands.png)

| 항목 | 조절하면 |
|---|---|
| 팔·손 부드러움 | 높이면 떨림이 줄고, 빠른 손짓은 늦게 따라옵니다. |
| 동적 방식 | 손을 뻗는 거리 변화를 반영하는 팔 방식을 사용합니다. |
| 이전 방식 | 기존 팔 움직임 방식으로 비교할 수 있습니다. |
| 손 깊이 추정 | 웹캠으로 앞뒤 거리를 추정합니다. 실험적이며, 팔이 비틀리면 끄세요. |
| 손 놓침 복귀 | 손이 안 보일 때 기본 자세로 돌아오는 속도를 바꿉니다. |

## 책상

손이 카메라에 보이지 않을 때, 키보드·마우스 사용에 맞춰 아바타 손을 움직입니다.

- 손 기본 자세: 책상 높이·손 간격·손목 각도를 맞춥니다.
- 키보드 반응: 타이핑할 때 손가락과 손이 움직이는 크기입니다.
- 마우스 반응: 마우스를 움직일 때 손이 따라가는 크기입니다.
- 손을 다시 카메라에 올리면 추적으로 돌아옵니다.

키보드 입력은 손 동작을 만드는 데만 사용하며, 입력한 글자는 저장하거나 전송하지 않습니다.
