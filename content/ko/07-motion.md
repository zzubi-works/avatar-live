# 7. 동작

## v2.0.0 동작 세부 조정: 값을 바꾸면 어디에 영향이 있나요?

![v45 동작 화면](img/v45-motion.png)

| 옵션 | 작게/끄면 | 크게/켜면 |
|---|---|---|
| **얼굴 표정 민감도** | 표정이 약하게 나오고 작은 노이즈를 무시함 | 작은 표정도 크게 나오지만 미세한 얼굴 움직임이 과장될 수 있음 |
| **표정 부드러움** | 입·눈·눈썹이 즉각 따라오지만 떨림이 보일 수 있음 | 자연스럽게 연결되지만 빠른 깜빡임·말소리가 늦게 표현될 수 있음 |
| **입술/립싱크 강도** | 입을 벌리는 폭이 줄어들어 차분함 | 말할 때 크게 벌어지지만 모델에 따라 부자연스러울 수 있음 |
| **깜빡임 감도 / 자동 깜빡임** | 작게/끄면 실제 추적 입력 위주 | 높이면 작은 눈 감음에도 반응하거나 대기 중 자동으로 깜빡임 |
| **웹캠 팔: 동적/이전 방식** | **이전 방식**은 1.1.6과 유사한 팔 동작을 보존 | **동적**은 새로운 팔·손 거리 계산을 적용하여 뻗는 동작을 더 표현할 수 있으나 환경별 결과 차이가 있음 |
| **팔·손 부드러움** | 빠른 손짓을 바로 따라가지만 노이즈가 나타날 수 있음 | 미세 떨림이 줄지만 손을 내릴 때 잠깐 늦어짐 |
| **손 거리/깊이 추정 (실험적)** | 기존 2D 기준에 가까운 안정적인 움직임 | 카메라에 손을 앞으로 내밀 때 깊이를 추정하나 팔·손목이 비틀릴 수 있음 |
| **AFK 진입 대기** | 추적이 잠깐 끊겨도 빨리 대기 자세로 전환 | 순간적인 끊김을 견디고 오래 끊길 때만 AFK에 들어감 |
| **AFK 전환/복귀 시간** | 자세·표정이 빠르게 바뀜 | 천천히 섞여 자연스럽지만 복귀가 늦음 |
| **대기 숨쉬기/깜빡임** | 꺼져 있으면 정적인 휴식 모습 | 켜면 입력이 없는 동안에도 작은 생동감 표현 |

![v45 동작 세부 항목](img/v45-motion-expanded.png)

**추적이 끊긴 뒤 복귀하는 기준**은 얼굴·머리·손·몸에서 서로 다를 수 있습니다. iPhone 앱이 연결 중으로 표시돼도 얼굴 값이 반복되거나 실제로 추적되지 않으면 정상 움직임이 아닐 수 있으므로, **추적 상태**, AFK 대기 시간, 정면 보정, 장치 원본 신호를 함께 확인하세요.

**포즈별 페이셜·머리·팔·손가락·몸통 5가지 추적 스위치**는 각각 따로 저장됩니다. 예를 들어 **머리 OFF, 페이셜 ON**이면 머리는 저장된 포즈를 유지하면서 표정만 실시간으로 움직입니다. 수동 포즈와 자동 AFK 포즈가 겹치면 명시적으로 선택한 사용자 포즈가 우선 적용될 수 있습니다.

**아바타별 시선 대상**을 **카메라/특정 인물/없음**으로 바꾸면 렌즈를 보는지, 장면 속 다른 인물을 바라보는지가 달라집니다. 시선 강도를 높이면 눈과 머리가 목표를 더 적극적으로 따라가며, 낮추면 입력 추적을 더 유지합니다. 머리 시선 보정(Look At IK)은 상황에 따라 기본 OFF인 실험 항목이므로 얼굴이 뒤집히면 끄고 확인하세요.

얼굴, 몸, 손이 어떻게 움직일지 정합니다. 설정은 아바타마다 따로 저장됩니다.

## 얼굴 트래킹

<div class="shot" markdown="1">

![동작 페이지](img/motion-face.png)

- **미러** — 거울처럼 같은 쪽으로 움직입니다.
- **팔 · 손 · 손가락** — 웹캠으로 각 부위를 움직입니다.
- **제스처 → 표정** — 손 모양에 맞춰 아바타 표정이 바뀝니다.
- **얼굴 추적** — 얼굴 표정 트래킹을 켜고 끕니다.

</div>

## 표정이 움직이는 방식

얼굴 표정은 **아바타에 들어 있는 설정을 그대로 따라갑니다.** Avatar Live가 아바타의 표정을 새로 만들거나 변환하지는 않습니다.

| 아바타 설정 | 움직이는 방식 |
|---|---|
| **VRCFaceTracking(VRCFT)** 파라미터가 있음 | 아바타의 VRCFT 설정으로 움직입니다. |
| **ARKit 52개 쉐이프키**(퍼펙트 싱크)가 있음 | 그 쉐이프키를 직접 움직입니다. |
| 둘 다 없음 | 깜빡임, 립싱크 등 아바타가 가진 기본 표정 위주로 움직이며, 세밀한 표정은 나오지 않을 수 있습니다. |

- 웹캠이나 iPhone이 표정을 52개 단위로 읽더라도, 아바타에 해당 파라미터나 쉐이프키가 없는 표정은 나오지 않습니다.
- 아바타에 일부 쉐이프키만 있으면 있는 것만 움직입니다.

> 💡 앞으로 52개 표정을 모두 인식해 아바타에 맞게 연결하거나, 해당 설정이 없는 아바타도 얼굴에 직접 연결해 주도록 개선할 예정입니다. 시기는 바뀔 수 있습니다.

## 자동 얼굴 설정

![자동 얼굴 설정](img/facecal.png)

**자동 얼굴 설정** 버튼을 누르면 캘리브레이션이 시작됩니다. 화면 안내에 따라 표정을 짓고 **측정**을 눌러 주세요. 마지막에 **적용**을 누르면 내 얼굴에 맞게 표정이 조정됩니다.

> 💡 첫 단계에서 바라보는 곳이 아바타의 정면 시선이 됩니다. 방송할 때처럼 화면을 바라봐 주세요.

## 눈 시선 · 카메라 보기

![동작의 눈 시선 설정](img/motion-gaze.png)

동작 › 얼굴의 눈 시선 추적을 조절합니다. 눈 카메라 보기를 켜면 아바타의 눈동자가 카메라를 향합니다. 포즈의 페이셜 추적을 OFF로 두어도 이 기능은 별개로 작동하며, 머리 추적도 독립적으로 켜고 끌 수 있습니다. 카메라 응시가 다른 얼굴 표정까지 활성화하는 것은 아닙니다.

## 몸

<div class="shot" markdown="1">

![몸 움직임](img/motion-body.png)

- **머리 움직임** — **작게 · 자연스럽게 · 크게** 중에서 고릅니다.
- **몸 따라오기** — 머리를 돌리면 몸도 자연스럽게 따라옵니다.
- **자연스러운 몸 움직임 · 호흡** — 가만히 있어도 살아 있는 것처럼 움직입니다.
- **상체** — 웹캠 전신을 켜면 어깨 움직임으로 상체가 기울고 돌아갑니다. 다리가 보이지 않는 책상 앞에서도 됩니다.
- **전신** — 몸통, 다리, 앉기 · 서기를 웹캠이나 VMC로 따라갑니다. [장치 › 전신 · 손가락 관절](06-devices.md#전신--손가락-관절-웹캠)을 참고해 주세요.

## AFK 전환 시간과 추적 상실

![동작의 AFK 전환 시간](img/motion-afk.png)

AFK 전환 시간은 더 이상 설정 메뉴가 아닌 동작 › 몸에 있습니다. 아바타별로 아래 세 시간을 슬라이더나 직접 숫자 입력으로 조절합니다.

- 추적 상실 후 대기: 추적이 잠깐 끊겼을 때 AFK로 전환하기 전 기다리는 시간
- AFK 자세로 전환: 대기 자세로 부드럽게 넘어가는 시간
- 추적 복귀: 추적 신호가 돌아온 뒤 정상 동작으로 되돌아가는 시간

기존에 저장한 아바타별 시간은 유지됩니다. 기본 자세와 추적이 끊겼을 때의 자세, 대기 표정은 [포징 가이드](11-pro-features.md)에서 별도로 설정합니다.

## 웹캠 손 깊이 추정(실험적)

![실험적 웹캠 손 뻗기 설정](img/motion-hand-depth.png)

웹캠 화면에서 손을 앞으로 뻗는 거리를 추정하는 기능입니다. 현재 카메라에 따라 팔이나 손목이 비틀리거나 떨릴 수 있어 일반 사용자에게는 OFF 사용을 권장합니다. 문제가 생기면 먼저 이 옵션을 끄고 손 떨림 보정을 확인하세요.

## 손 · 책상

<div class="shot" markdown="1">

![손과 책상](img/motion-desk.png)

- **책상 동작** — 손이 카메라에 보이지 않을 때 키보드와 마우스에 맞춰 아바타 손이 움직입니다.
- **손 기본 자세** — 책상 높이, 손 간격, 손목 각도를 맞춥니다.
- **키보드 · 마우스 입력 반응** — 타이핑과 마우스 움직임의 크기를 정합니다.
- 손을 내리면 바로 책상 자세로 가고, 다시 올리면 부드럽게 트래킹으로 돌아옵니다. 몸이 크게 흔들리거나 앉은 자세여도 팔꿈치가 자연스럽게 따라옵니다.
- 포징에서 만든 팔 · 손 자세를 **책상 자세로 쓰기**로 지정할 수 있습니다 (Pro).

</div>

> 🔒 키보드 입력은 아바타 손을 움직이는 데만 쓰이며, 입력한 글자는 저장하거나 전송하지 않습니다.

> 💡 혀 · 볼 부풀림의 카메라 감지는 실험적 기능입니다.
