# 스튜디오

배경·조명·소품을 배치하고, 촬영할 카메라와 장면을 저장합니다. 화면의 색감과 렌즈 효과는 [카메라 효과](08-camera-effects.md)에서 따로 설명합니다.

## 장면 저장

![장면 목록과 저장 버튼](img/guide-scenes.png)

1. 배경·조명·아바타·카메라를 원하는 상태로 맞춥니다.
2. 씬 카드에서 저장합니다.
3. 다음에 썸네일을 선택하면 그 장면 구성을 불러옵니다.

씬은 아바타의 위치와 포즈도 함께 기억해, 다시 열면 그대로 돌아옵니다. 씬 안에서 아바타를 바꾸면 바꾼 아바타가 그 씬의 아바타가 됩니다. 저장하지 않은 변경이 있는 채로 아바타 목록으로 돌아가면 저장할지 묻습니다.

| 항목 | 하는 일 |
|---|---|
| 새 씬 | 새 장면 구성을 만듭니다. |
| 저장 | 현재 배치와 설정을 기록합니다. |
| 썸네일 | 저장한 장면을 불러옵니다. |
| 검색 | 이름으로 장면을 찾습니다. |
| ⋯ 메뉴 | 이름 변경·복제 등 해당 장면의 명령을 엽니다. |

## 아바타 배치

![아바타의 위치·회전·크기 설정](img/guide-studio-avatar.png)

| 조절 | 바뀌는 것 |
|---|---|
| 위치 X | 좌우로 옮깁니다. |
| 위치 Y | 위아래로 옮깁니다. |
| 위치 Z | 앞뒤로 옮깁니다. |
| 회전 | 아바타가 바라보는 방향을 바꿉니다. |
| 크기 | 장면 속 아바타를 크게 또는 작게 만듭니다. |
| 밝기 | 아바타에 적용되는 밝기를 조절합니다. |
| 가운데로 | 아바타를 기준 위치로 돌려놓습니다. |

### 여러 아바타 (Pro)

아바타 추가로 같은 장면에 캐릭터를 더 놓습니다. 아바타를 선택한 뒤 조종 대상을 바꾸면 내 추적 입력을 받을 캐릭터가 바뀝니다.

- 같은 동작: 여러 아바타가 같은 추적 입력으로 함께 움직입니다.
- 립싱크 모두: 여러 아바타의 입을 함께 움직입니다.
- 립싱크 메인: 주 조종 아바타만 입을 움직입니다.
- 립싱크 끔: 공유 립싱크를 사용하지 않습니다.

## 카메라 (Pro)

![카메라 목록과 선택한 카메라의 설정](img/guide-studio-camera.png)

1. 카메라 → 스튜디오 카메라의 +를 눌러 카메라를 만듭니다.
2. 카메라 이름을 눌러 세부 설정을 펼칩니다.
3. 대상·위치·시선·렌즈를 맞춥니다.
4. 해당 카메라를 송출 대상으로 선택합니다.

직접 잡기를 켜면 씬 화면에 카메라가 나타나 소품처럼 옮기고 돌릴 수 있습니다. 직접 잡기와 현재 화면으로는 카메라 설정의 첫 줄과 카메라의 ⋯ 메뉴에 있습니다. 현재 작업 구도를 그대로 쓰려면 현재 화면으로를 사용합니다.

### 위치 방식

![카메라 위치 방식과 따라갈 대상](img/guide-camera-position.png)

| 선택 | 카메라가 움직이는 방식 |
|---|---|
| 제자리 | 정해 둔 위치에 머뭅니다. 아바타가 이동해도 따라가지 않습니다. |
| 대상 고정 | 선택한 뼈나 지점에 붙습니다. 머리를 고르면 머리 안쪽에 들어갈 수 있습니다. |
| 거리 두고 따라가기 | 대상에서 X·Y·Z만큼 떨어진 자리를 유지하며 따라갑니다. |
| 대상 돌기 | 정한 거리에서 대상 주위를 돕니다. 링 각도로 앞·옆 구도를 바꿉니다. |

- 대상: 따라갈 아바타와 머리·몸 등의 기준 지점을 고릅니다.
- 거리 X·Y·Z: 대상에서 카메라를 좌우·높이·앞뒤로 얼마나 떨어뜨릴지 정합니다.
- 부드러움: 높이면 천천히 따라와 떨림이 줄고, 낮추면 바로 반응합니다.

### 회전 기준

| 선택 | 아바타가 돌아서면 |
|---|---|
| 세계 좌표 | 카메라의 상대 방향은 장면 기준으로 유지됩니다. |
| 단순 추적 | 대상의 뒤를 따라가며 이동합니다. |
| 대상 따라 회전, 위는 세계 | 좌우 회전을 따라가되 화면 위쪽은 세워 둡니다. |
| 회전, 롤 없음 | 좌우·상하 회전을 따라가고 고개 기울기는 따르지 않습니다. |
| 대상에 고정 | 고개 기울기를 포함한 전체 회전에 맞춰 카메라 자리도 돌아갑니다. |

이 설정은 카메라가 놓이는 기준입니다. 얼굴을 계속 화면에 담으려면 아래 시선 방식도 고르세요.

### 시선 방식

![카메라 시선과 렌즈 설정](img/guide-camera-aim.png)

| 선택 | 렌즈가 보는 곳 |
|---|---|
| 제자리 | 지정한 방향을 계속 봅니다. |
| 대상과 함께 | 대상이 돌아보는 방향으로 함께 돌아갑니다. |
| 대상 응시 | 선택한 얼굴이나 지점을 계속 바라봅니다. |
| 1인칭 | 시작 각도를 기준으로 인물 시점처럼 봅니다. |
| 화면 구도 | 대상을 화면에서 정한 위치에 담도록 방향을 맞춥니다. |

- 조준점: 대상에서 초점을 둘 위치를 X·Y·Z로 옮깁니다.
- 화면 위치: 가로·세로 0.5는 가운데입니다. 값을 바꾸면 아바타를 화면의 다른 위치에 담습니다.
- 시선 부드러움: 높이면 렌즈 방향이 느긋하게 바뀌고, 낮추면 바로 따라갑니다.

### 렌즈와 전환

| 항목 | 값을 바꾸면 |
|---|---|
| 시야각 | 낮추면 망원처럼 크게, 높이면 광각처럼 넓게 담습니다. |
| 직교 크기 | 높이면 더 넓게 담아 아바타가 작아집니다. |
| 앞 클리핑 거리 | 이 거리보다 가까운 물체를 그리지 않습니다. 높이면 얼굴·소품이 잘릴 수 있습니다. |
| 뒤 클리핑 거리 | 이 거리보다 먼 물체를 그리지 않습니다. |
| 화면 비율 | 가로 방송·세로 영상 등 화면 모양을 바꿉니다. |
| 흔들림 강도 | 높이면 손으로 들고 찍는 느낌이 강해집니다. 0은 흔들리지 않습니다. |
| 흔들림 속도 | 높이면 더 빠르게 흔들립니다. |
| 컷 | 다른 카메라로 즉시 바뀝니다. |
| 크로스페이드 | 두 카메라 화면이 전환 시간 동안 겹쳐 바뀝니다. |

### 감독과 멀티뷰

![감독 모드와 멀티뷰 설정](img/guide-camera-multiview.png)

- 감독 모드: 카메라를 전환해 방송 화면을 구성합니다.
- 멀티뷰: 여러 카메라 미리보기를 한곳에서 봅니다. 별도 스위치로 켭니다.
- 격자: 늘리면 한 번에 보는 카메라가 많아지고 각 칸은 작아집니다.
- 다운샘플링: 높이면 미리보기 화질과 PC 부담이 함께 줄어듭니다.
- 갱신률: 낮추면 미리보기가 덜 매끄럽고 PC 부담이 줄어듭니다.
- 자동 전환: 태그와 가중치로 다음 카메라를 고릅니다. 가중치 0인 카메라는 자동 선택되지 않습니다.
- 카메라별 Spout2: 선택한 카메라 영상을 별도 이름으로 OBS에 보냅니다. 최대 3개를 추가 출력할 수 있습니다.

## 배경

![배경 종류 설정](img/guide-background.png)

| 선택 | 보이는 결과 |
|---|---|
| 단색 | 고른 색으로 배경을 채웁니다. |
| 초록 | OBS에서 크로마키로 지울 수 있는 배경입니다. 의상과 다른 색을 고르세요. |
| 투명 | Spout2·NDI에서 배경 없이 합성합니다. 받는 쪽도 알파 합성을 지원해야 합니다. |
| 이미지 | PNG·JPG 그림을 배경으로 사용합니다. |
| 하늘 | 하늘 풍경을 배경으로 사용합니다. |

이미지의 확대·축소는 그림 크기를, 좌우·상하 위치는 그림이 놓이는 자리를 바꿉니다. 채우기를 켜면 비율을 유지하며 가장자리를 잘라 채웁니다.

휴대폰·캠코더처럼 보이는 촬영 화면 장식은 스튜디오 → 사진 및 녹화 탭으로 옮겨졌습니다. [사진과 녹화](09-output.md#사진과-녹화)를 보세요.

## 조명

![조명 프리셋과 개별 라이트 설정](img/guide-lighting.png)

프리셋으로 전체 분위기를 고르고, 개별 라이트를 눌러 세부 조절합니다. 프리셋 목록은 종류별로 접혀 있고, 직접 저장한 프리셋이 맨 위에 놓입니다.

| 항목 | 바꾸면 |
|---|---|
| 세기 | 높이면 밝아집니다. 너무 높으면 피부·머리카락이 하얗게 날아갑니다. |
| 색상 | 아바타를 비추는 빛의 색을 바꿉니다. |
| 색온도 | 낮으면 주황빛, 높으면 푸른빛에 가까워집니다. |
| 범위 | 점광·스폿의 빛이 더 먼 곳까지 닿습니다. |
| 스폿 각도 | 좁히면 한 부분을, 넓히면 주변까지 비춥니다. |
| 그림자 강도 | 높이면 그늘이 짙어집니다. |
| 그림자 부드러움 | 높이면 그늘의 경계가 흐려집니다. |
| 환경광 | 라이트가 직접 닿지 않는 부분을 밝힙니다. |

### 위치와 대상

![라이트의 위치·방향·대상 설정](img/guide-light-detail.png)

- 위치 따라가기: 아바타나 뼈가 이동할 때 라이트도 따라옵니다.
- 대상 바라보기: 라이트를 대상 쪽으로 돌립니다.
- 부드러움: 높이면 대상의 작은 떨림을 덜 따라갑니다.
- 라이트 그룹: 여러 라이트를 묶어 위치·회전·밝기를 함께 바꿉니다.
- 볼류메트릭 스폿 (Pro): 공기 중에 빛기둥을 만듭니다. 밀도를 높이면 빛줄기가 진해집니다.

## 방과 소품

![방 프리셋과 배치 설정](img/guide-room.png)

방 프리셋을 골라 배경 공간을 놓습니다. 위치·회전·크기로 무대와 아바타의 자리를 맞춥니다. BOOTH에서 산 추가 방은 [DLC 방 팩](08-rooms.md)을 보세요.

로우폴리 인테리어 팩에서는 건물 전체를 고르는 선택지가 없어졌고, 나뉜 방 28개를 그대로 쓸 수 있습니다. 건물 전체를 고른 채 저장한 예전 장면은 방 없이 열립니다.

![오브젝트와 소품 라이브러리](img/guide-props.png)

- 오브젝트 추가: 텍스트·이미지·도형·3D 소품을 놓습니다.
- 월드 고정: 아바타가 움직여도 물체는 제자리에 남습니다.
- 아바타·뼈에 붙이기: 몸이나 손·머리를 따라 움직입니다.
- 오프셋: 붙인 지점에서 조금 옮기거나 돌립니다. 손에 쥔 물건의 위치를 맞출 때 씁니다.
- 아바타 소속: 다른 장면으로 옮겨도 해당 아바타를 따라갑니다.
- 스튜디오 소속: 현재 장면에 남습니다.

소품과 아바타의 이용 권한은 각각 원제작자의 약관을 따릅니다. 자세한 내용은 [아바타와 소품](13-license.md#아바타와-소품)을 확인하세요.
