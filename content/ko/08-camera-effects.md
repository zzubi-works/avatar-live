# 카메라 효과

스튜디오 → 효과를 엽니다. 제목을 누르면 조절 항목이 펼쳐지고, 오른쪽 스위치를 켜면 효과가 적용됩니다.

## 포스트 프로세싱

기본적인 색감·빛 번짐·렌즈 효과를 조절합니다.

### 안티에일리어싱

![안티에일리어싱 방식 선택](img/guide-post-aa.png)

머리카락이나 의상의 계단처럼 보이는 윤곽을 부드럽게 합니다.

| 선택 | 보이는 차이 |
|---|---|
| Off | 윤곽 보정을 끕니다. |
| FXAA | 가볍게 보정합니다. 작은 무늬가 조금 흐려질 수 있습니다. |
| SMAA | 세부를 살리며 윤곽을 정리합니다. |
| TAA | 시간에 걸쳐 화면을 안정시킵니다. 움직일 때 잔상이 생길 수 있습니다. |

### 블룸

![블룸의 세기·임계값·확산 설정](img/guide-post-bloom.png)

밝은 머리카락·발광 장식 주위에 빛이 번지게 합니다.

| 조절 | 높이면 |
|---|---|
| 세기 | 빛 번짐이 진해집니다. |
| 임계값 | 더 밝은 부분에만 번짐이 생깁니다. 낮추면 보통 밝기의 면도 번집니다. |
| 소프트 니 | 번짐이 시작되는 밝기 경계가 완만해집니다. |
| 확산 | 빛이 더 넓게 퍼집니다. |
| 아나모픽 비율 | 번짐을 가로 또는 세로로 늘립니다. |
| 색상 | 번지는 빛의 색을 정합니다. |

### 색 보정

![노출·대비·채도·색온도·틴트](img/guide-post-color.png)

| 조절 | 값을 바꾸면 |
|---|---|
| 노출 | 높이면 화면 전체가 밝아지고, 낮추면 어두워집니다. |
| 대비 | 높이면 밝고 어두운 차이가 커집니다. |
| 채도 | 높이면 색이 진해지고, 낮추면 흑백에 가까워집니다. |
| 색온도 | 낮으면 차갑게, 높으면 따뜻하게 보정합니다. |
| 틴트 | 녹색과 자홍색 사이의 색 기운을 맞춥니다. |

### 비네팅

![비네팅의 세기·부드러움·모양](img/guide-post-vignette.png)

화면 가장자리를 어둡게 만들어 가운데로 시선을 모읍니다.

- 세기: 높이면 가장자리가 더 어두워집니다.
- 부드러움: 높이면 어두워지는 경계가 넓게 퍼집니다.
- 둥근 정도: 가장자리 모양을 바꿉니다.
- 색상: 가장자리에 섞을 색입니다.

### 필름 그레인

![필름 그레인의 세기와 입자 크기](img/guide-post-grain.png)

화면에 필름 같은 작은 입자를 더합니다.

- 세기: 높이면 입자가 더 잘 보입니다.
- 크기: 높이면 입자가 커집니다.
- 색상 사용: 켜면 색이 있는 입자를 사용합니다.

### 색수차

![색수차 설정](img/guide-post-chromatic.png)

윤곽 가장자리에 빨강·초록·파랑이 어긋나는 렌즈 효과를 만듭니다. 세기를 높일수록 색이 더 벌어집니다.

### 피사계 심도

![자동 초점·조리개·렌즈 설정](img/guide-post-dof.png)

초점이 맞는 얼굴은 선명하게 두고, 앞뒤를 흐리게 합니다.

| 조절 | 바꾸면 |
|---|---|
| 얼굴 자동 초점 | 켜면 움직이는 얼굴에 초점을 맞춥니다. |
| 초점 거리 | 자동 초점을 끈 상태에서 선명하게 보일 거리를 정합니다. |
| 조리개 | f 숫자가 작을수록 앞뒤 흐림이 강해집니다. |
| 렌즈 | 긴 렌즈일수록 초점 앞뒤가 더 쉽게 흐려집니다. |
| 흐림 품질 | 높이면 흐림이 매끄러워지고 PC 부담이 늘어납니다. |

조리개를 너무 낮추거나 초점 거리가 얼굴과 맞지 않으면 얼굴도 흐려집니다.

### 모션 블러

![모션 블러의 셔터 각도와 샘플 수](img/guide-post-motion.png)

빠른 움직임에 잔상을 더합니다.

- 셔터 각도: 높이면 잔상이 더 길게 번집니다.
- 샘플 수: 높이면 잔상이 매끄러워지고 PC 부담이 늘어납니다.

## 후처리 효과 (Pro)

Beautify 기반의 별도 카메라 효과입니다. 화면에는 후처리 효과라는 이름으로 표시됩니다.

### 색·톤

![후처리 효과의 색·톤 설정](img/guide-fx-color.png)

| 조절 | 바뀌는 것 |
|---|---|
| LUT | 정해진 색감 필터를 고릅니다. |
| LUT 세기 | 높이면 필터의 색감이 강해집니다. |
| ACES 톤맵 | 밝은 곳과 어두운 곳의 표현을 바꿉니다. |
| 채도 | 높이면 색이 진해집니다. |
| 대비 | 밝고 어두운 차이를 바꿉니다. |
| 밝기 | 전체 화면의 밝기를 바꿉니다. |
| 색조·세기 | 선택한 색을 화면에 섞습니다. 세기 0이면 색을 골라도 보이지 않습니다. |

### 선명하게·디더

![선명도와 디더 설정](img/guide-fx-sharpen.png)

- 선명하게: 윤곽을 또렷하게 합니다. 0이면 꺼집니다. 너무 높으면 가장자리가 거칠어집니다.
- 디더: 배경 그라데이션의 색 띠를 작은 노이즈로 덜 보이게 합니다.

### 블룸

![후처리 블룸의 거리 감쇠와 고품질 설정](img/guide-fx-bloom.png)

- 세기: 빛 번짐의 진하기입니다.
- 문턱값: 높일수록 더 밝은 부분에만 번짐을 만듭니다.
- 색조·세기: 번지는 빛에 섞을 색과 양입니다.
- 거리 감쇠: 먼 곳의 블룸을 줄입니다.
- 가까이 감쇠 거리: 카메라에 가까운 곳의 블룸을 줄일 범위입니다.
- 고품질: 번짐 품질을 높이며 PC 부담이 늘어납니다.

### 아나모픽 플레어

![아나모픽 플레어의 세기·번짐·방향](img/guide-fx-flares.png)

밝은 부분에서 길게 뻗는 빛줄기를 만듭니다.

- 세기: 빛줄기가 진해집니다.
- 문턱값: 높일수록 더 밝은 부분만 빛줄기를 만듭니다.
- 번짐: 빛줄기가 더 길게 퍼집니다.
- 세로: 켜면 세로 방향, 끄면 가로 방향으로 퍼집니다.
- 색조·세기: 빛줄기의 색을 정합니다.

### 피사계 심도

![후처리 피사계 심도의 초점과 보케](img/guide-fx-dof.png)

- 머리에 자동 초점: 머리를 따라 초점을 맞춥니다.
- 초점 맞출 거리: 자동 초점을 끄고 선명하게 보일 거리를 직접 정합니다.
- 초점 속도: 높이면 움직이는 대상에 더 빨리 초점을 맞춥니다.
- 렌즈·조리개: 흐려지는 범위를 조절합니다.
- 보케: 흐려진 밝은 점을 빛망울처럼 만듭니다.
- 보케 문턱값: 높일수록 더 밝은 점만 빛망울이 됩니다.
- 보케 세기: 빛망울의 밝기를 바꿉니다.

아래 블러를 켜면 이 피사계 심도는 꺼집니다.

### 색수차

![후처리 색수차의 세기와 완만함](img/guide-fx-chromatic.png)

- 세기: 윤곽의 색 어긋남이 커집니다.
- 완만함: 색이 벌어지는 변화가 부드러워집니다.

투명 배경에서는 이 효과가 꺼집니다.

### 렌즈 먼지

![렌즈 먼지의 텍스처와 세기](img/guide-fx-dirt.png)

밝은 곳에 렌즈 얼룩이 겹치는 연출입니다.

- 텍스처: 사용할 얼룩 무늬를 고릅니다. 없음이면 사용하지 않습니다.
- 세기: 얼룩이 더 진하게 보입니다.
- 문턱값: 얼룩이 반응할 밝기 기준입니다.

### 비네트

![후처리 비네트 설정](img/guide-fx-vignette.png)

- 색: 화면 가장자리에 사용할 색입니다.
- 가장자리 흐림: 가장자리의 어두운 부분을 조절합니다.
- 깜빡임: 눈을 감듯 화면을 가리는 정도를 바꿉니다.

### 야간 시야

![야간 시야와 색 설정](img/guide-fx-night.png)

선택한 색으로 야간 카메라 같은 화면을 만듭니다. 스위치로 켜고 색상에서 연출 색을 바꿉니다.

### 블러

![전체 화면 블러 설정](img/guide-fx-blur.png)

화면 전체를 흐리게 합니다. 세기를 높일수록 더 흐려집니다. 얼굴만 선명하게 남기려면 블러 대신 피사계 심도를 사용하세요.

### 픽셀화

![픽셀화와 픽셀 크기 설정](img/guide-fx-pixelate.png)

화면을 큰 네모 픽셀로 만듭니다. 픽셀 크기를 높일수록 모자이크가 굵어집니다.

## 환경 광 차폐 (Pro)

![환경 광 차폐의 반지름·세기·품질 설정](img/guide-fx-hbao.png)

HBAO 기반으로 턱 아래·옷 주름·방 구석처럼 표면이 가까운 부분에 그늘을 더합니다.

| 조절 | 높이면 |
|---|---|
| 반지름 | 그늘이 퍼지는 범위가 넓어집니다. |
| 최대 반지름 | 화면에 그늘을 계산하는 최대 범위가 커집니다. |
| 세기 | 그늘이 짙어집니다. |
| 색 | 그늘의 색을 바꿉니다. |
| 품질 | 그늘이 매끄러워지고 PC 부담이 늘어납니다. |

눈·코 주변이 너무 검어지면 세기나 반지름을 낮추세요.
