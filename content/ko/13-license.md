# 13. 에디션 · 라이선스 · 고지

| | **Basic** | **Pro** |
|---|---|---|
| 가격 (BOOTH) | 1,990엔 | 3,980엔 |
| 이용 범위 | 개인 사용 (친구와의 비공개 Discord 공유 포함) | 방송 · 영상 공개 · 상업적 이용 |
| 아바타 · 트래킹 · 메뉴 · 조명 · 효과 | ✅ | ✅ |
| 내 표정 · 자동 표정 · 계층 구조 · 쉐이프키 · 사진 | ✅ | ✅ |

| 최대 출력 | 1080p | 4K |
| 워터마크 | 있음 | 없음 |
| 포징 · 포즈 라이브러리 · 오브젝트 · 화면 공유 추가 소스 | — | ✅ |

가격은 BOOTH 상품 페이지의 표시를 따릅니다.

## 업그레이드와 체험판

- **Basic → Pro**: BOOTH에서 **업그레이드(1,990엔)**를 구매해 Basic을 쓰는 PC의 **설정 › 라이선스 › Pro로 업그레이드**에 입력하면 Pro가 됩니다. 업그레이드한 구매는 그 라이선스에 함께 묶입니다.
- **체험 중에 구매했다면** **설정 › 라이선스 › 구매한 코드 입력**에 입력해 주세요.
- **체험판이 끝나면** 입력 화면이 나옵니다. 구매한 라이선스를 입력하면 계속 사용할 수 있습니다.

## 라이선스 이용 조건 (요약)

- 1인 1기기입니다.
- 다른 PC로 옮기는 것은 본인이 직접 **1회** 할 수 있습니다. 그 뒤에는 부득이한 경우 문의를 통해 도와드리고 있지만 쉽지 않을 수 있으니, **처음 활성화할 PC를 신중하게 정해 주세요.**
- 활성화와 라이선스 확인에 인터넷 연결이 필요합니다.
- 프로그램과 라이선스는 구매하신 분만 사용해 주세요. 재배포, 판매, 대여, 공유, 수정, 리버스 엔지니어링, 라이선스 확인 우회는 허용되지 않습니다.

자세한 조건은 [이용약관](legal-terms.md)을 따릅니다.

## 실험적 기능

Ultraleap, OSC, VMC 출력, 혀 · 볼 카메라 감지처럼 앱에 **실험적**으로 표시된 기능은 정상적으로 동작할 것으로 예상하지만, 아직 개발자 환경에서 모든 장치와 앱으로 테스트하지는 못했습니다. 웹캠(전신 · 손가락 관절 포함), iPhone, VMC 입력은 실제 장비로 확인했습니다.

## 내가 만든 파일

- Exporter로 만든 `.vavatar` · `.vprop` 파일은 사용자의 것입니다.
- 파일 안의 아바타, 의상, 셰이더의 권리는 각 제작자에게 있습니다. 공유하거나 방송에 쓸 때는 원 제작자의 약관을 확인해 주세요.
