# 3. 시작 화면과 아바타 라이브러리

## v2.0.0 라이브러리: 아바타 선택 결과가 달라지는 경우

![v45 아바타 로딩 후 메뉴](img/v45-menu.png)

- **.vavatar 가져오기**는 Exporter 1.0.6에서 나온 Windows 파일을 라이브러리에 등록합니다. Unity 원본 프로젝트를 직접 읽는 방식은 아닙니다. **.vrm 가져오기**는 VRM 0.x·1.0을 지원하지만 모델에 포함된 일부 비표준/미지원 셰이더가 안 보일 수 있습니다.
- **최근 사용/폴더/가져온 파일**은 아바타 목록을 어디에서 고를지 바꿀 뿐, 실제로 트래킹 입력이나 방송 카메라를 켜거나 끄는 설정이 아닙니다.
- **기본 아바타 / 마지막 아바타 / 매번 묻기**: 기본은 고정 지정한 모델, 마지막은 직전에 열었던 모델, 매번 묻기는 시작 때 목록을 표시합니다. 방송마다 다른 캐릭터를 사용하면 매번 묻기가 실수를 줄입니다.
- **시작 시 카메라·마이크 자동 켜기**는 프로그램 실행 직후 장치를 점유할 수 있습니다. 다른 화상 회의 앱과 충돌한다면 시작 설정에서 끄고 앱 안에서 직접 켜세요.
- **아바타 전환 시** 기존 아바타의 표정·포즈·카메라 프리셋 등은 그 아바타의 설정 범위에 따라 유지됩니다. 이전 아바타의 프로필을 모두 새 모델로 복사하는 동작은 아닙니다.
- **멀티 아바타 (Pro)**는 한 명을 완전히 교체하는 대신 같은 스튜디오에 여러 캐릭터를 동시에 배치합니다. 각 캐릭터를 **조종 대상**으로 선택한 후 수정하세요.

**세션에 관한 중요한 구분:** 라이브러리에 저장한 아바타 원본은 내 PC에 있습니다. [원격 세션](09-output.md)의 **내 아바타 데이터 보내기**는 별도 동의가 있을 때만 켜는 기능이고, 다른 참여자가 받는 데이터는 세션 전용 암호화 임시 캐시로 관리됩니다. 아바타 라이브러리에 누군가의 원본을 자동으로 등록하는 기능이 아닙니다.

## 시작 화면

![시작 화면](img/launcher.png)

| 항목 | 하는 일 |
|---|---|
| **아바타 열기…** | `.vavatar` 파일을 엽니다. 창에 끌어다 놓아도 됩니다. |
| **최근 · 폴더 · 가져옴** | 최근에 연 아바타, 아바타 폴더의 아바타, 가져온 아바타를 보여 줍니다. |
| **기본으로 지정** | 이 아바타로 바로 시작하게 합니다. |
| **카메라 · 마이크** | 시작할 때 함께 켤 장치를 고릅니다. |
| **얼굴 · 손** | 트래킹 방식을 고릅니다. |
| **시작 설정** | 매번 묻기 · 마지막 아바타 · 기본 아바타 중에서 고릅니다. |
| **▶ Avatar Live 시작** | 고른 아바타로 시작합니다. |

> 💡 **Shift**를 누른 채 실행하면 웹캠 · 마이크 없이 안전하게 시작합니다. 장치 문제로 시작이 잘 안 될 때 사용해 보세요.

## 실행 중에 아바타 바꾸기

<div class="shot" markdown="1">

![아바타 라이브러리](img/avatar-pop.png)

- 왼쪽 위 **아바타 이름**을 누르면 라이브러리가 열립니다.
- 목록에서 아바타를 누르면 그 아바타로 바뀝니다.
- **아바타 파일 추가…** 로 새 아바타를 가져옵니다.
- 켜 둔 웹캠과 마이크는 바꾼 뒤에도 그대로 켜집니다.

</div>

## 메뉴를 처음 열 때

아바타를 불러올 때 메뉴 레이아웃을 미리 준비하므로 각 메뉴를 처음 열 때 생기던 지연이 줄었습니다. 초기 아바타 로딩은 조금 길어질 수 있습니다. 왼쪽 상단 로고에서 재시작 없이 아바타 선택으로 돌아갈 수 있습니다.

## 시작 화면으로 돌아가기

왼쪽 위 **로고**를 누르고 **다시 시작**을 선택합니다.
