# 아바타 메뉴

의상·머리·표정 등 아바타 제작자가 넣은 기능을 사용합니다. 모델에 따라 메뉴 이름과 항목이 다릅니다.

## 의상과 표정 바꾸기

![일반 표정 버튼이 있는 하위 메뉴](img/guide-avatar-menu.png)

| 조작 | 작동 방식 |
|---|---|
| 켜기·끄기 | 한 번 누르면 켜지고, 다시 누르면 꺼집니다. 의상이나 장식을 바꿀 때 주로 사용합니다. |
| 누르는 버튼 | 누르고 있는 동안만 적용됩니다. 놓으면 풀립니다. |
| 원형 슬라이더 | 손잡이를 움직여 0~100% 사이 값을 정합니다. 연결된 색·크기·표정 강도 등이 변합니다. |
| 방향 패드 | 손잡이를 좌우·위아래로 움직여 여러 표정이나 값을 함께 조절합니다. |
| 폴더 | 하위 메뉴를 엽니다. 뒤로를 누르면 상위 메뉴로 돌아갑니다. |

## 자주 쓰는 항목 바로 꺼내기

![표정 버튼을 우클릭해 연 퀵 액션·단축키·즐겨찾기 메뉴](img/guide-menu-context.png)

- 즐겨찾기: 메뉴 위쪽에서 빠르게 찾습니다.
- 퀵 액션에 추가: 하단 도구막대에 실행 버튼을 만듭니다.
- 단축키 지정: 키보드로 해당 항목을 실행합니다.

단축키에서 누르는 동안은 키를 놓으면 풀리고, 토글은 다시 누를 때까지 유지됩니다.

## 자세와 추적 (Pro)

![저장된 자세와 내 표정](img/guide-menu-poses.png)

1. 자세 타일을 눌러 적용합니다.
2. 자세 옆 카메라 아이콘으로 추적 설정을 펼칩니다.
3. 페이셜·머리·팔·손가락·몸통을 각각 켜거나 끕니다.

켜진 부위는 내 움직임을 따르고, 꺼진 부위는 저장한 자세를 유지합니다. 예를 들어 머리를 끄고 페이셜을 켜면 고개는 고정한 채 표정만 움직입니다.

### 자세별 추적

![자세 카드의 부위별 추적 설정](img/guide-pose-tracking.png)

자세 옆 카메라 버튼을 누르면 페이셜·머리·팔·손가락·몸통을 각각 켜고 끕니다.

- 켜진 부위: 내 움직임을 따라갑니다.
- 꺼진 부위: 저장한 자세를 유지합니다.
- 예: 팔을 끄고 머리·페이셜을 켜면 팔 포즈를 유지하며 고개와 표정은 움직입니다.

## 기본 자세와 대기 자세

![기본 자세와 AFK 자세 선택](img/guide-default-pose.png)

| 선택 | 사용할 때 |
|---|---|
| 기본 자세 | 평소 추적하지 않는 부분의 기준 자세입니다. |
| AFK 대기 자세 | 추적을 잃었을 때 사용할 자세입니다. |
| 대기 표정 | AFK 중 자동으로 적용할 표정입니다. |
| 책상 자세 | 손이 카메라에 안 보일 때 사용할 팔·손 자세입니다. |

대기 자세로 넘어가는 시간은 [추적을 잃었을 때](#추적을-잃었을-때)에서 맞춥니다.

### 추적을 잃었을 때

![추적 상실과 AFK 전환 시간](img/guide-motion-afk.png)

AFK는 얼굴과 몸의 추적을 모두 잃었을 때 사용하는 대기 상태입니다. 메뉴 → 기본·AFK 자세에서 시간을 정합니다.

| 시간 | 길게 하면 |
|---|---|
| 기다리는 시간 | 잠깐 입력이 끊겨도 자세를 유지하고 더 기다립니다. |
| 전환 시간 | 대기 자세로 천천히 넘어갑니다. |
| 복귀 시간 | 입력이 돌아온 뒤 정상 동작으로 천천히 돌아옵니다. |

대기 중 사용할 자세와 표정은 [기본 자세와 대기 자세](#기본-자세와-대기-자세)에서 고릅니다.

## 내 표정

새 표정 만들기로 얼굴 모양을 조절해 저장하거나, `.anim` 표정 파일을 불러옵니다. 만든 표정은 타일로 적용하고 우클릭으로 퀵 액션이나 단축키에 연결합니다.

![직접 만든 표정과 표정 추가](img/guide-my-expression.png)

1. 새 표정 만들기를 누릅니다.
2. 얼굴의 쉐이프키를 움직여 표정을 만듭니다.
3. 미리보기 강도로 0% 무표정부터 100% 표정까지 확인합니다.
4. 저장합니다.
5. 내 표정 타일을 눌러 적용합니다.

.anim 불러오기로 Unity 표정 애니메이션을 추가할 수도 있습니다. 움직이는 파일은 시간에 따라 표정이 변하고, 반복 여부는 파일 설정을 따릅니다.

### .anim으로 다른 아바타에 옮기기

내 표정 타일을 우클릭하고 **.anim 내보내기…**를 선택해 파일을 저장합니다. 같은 쉐이프 키가 있는 다른 아바타에서 **.anim 불러오기**로 추가하면 같은 표정을 사용할 수 있습니다. Unity에서도 사용할 수 있습니다. 움직이는 표정은 곡선과 반복 설정을 유지합니다. 눈 깜박임과 눈·입 추적 일시 정지는 .anim에 포함되지 않으므로 적용할 아바타에서 설정하세요.

## 손 제스처

![왼손과 오른손 제스처 설정](img/guide-gestures.png)

왼손과 오른손의 주먹·가위·펼침 등을 고릅니다. 아바타에 손 모양별 표정이 연결되어 있으면 표정도 함께 바뀝니다. 웹캠 손 모양으로 제스처를 켜면 실제 손 모양을 사용합니다.

## 되돌리기

아바타 파라미터 → 기본값으로 되돌리기를 누르면 의상·표정 등의 메뉴 값이 아바타의 기본값으로 돌아갑니다.

## 계층 구조와 쉐이프키

- 계층 구조: 아바타의 부품을 트리로 보여 줍니다. 체크로 부품을 켜고 끕니다.
- 눈 아이콘: 부품의 작동은 유지하면서 화면에서만 숨깁니다.
- 메시: 외형을 그리는 부품을 검색합니다.
- 쉐이프키: 얼굴이나 몸의 변형량을 직접 조절합니다. 직접 고정한 값은 추적보다 우선할 수 있습니다.
