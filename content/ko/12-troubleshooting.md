# 12. 문제 해결

## v2.0.0 · 증상별 확인 순서

![v45 설정 및 진단 화면](img/v45-settings.png)

| 증상 | 원인 판단과 단계별 해결 |
|---|---|
| **OBS에 Spout2 Capture 항목이 없어요** | OBS 수신 플러그인 미설치 가능성이 큽니다. OBS 종료 → [OBS Spout2 공식 Releases](https://github.com/Off-World-Live/obs-spout2-plugin/releases) 설치 → 재실행 → 소스 추가에서 Spout2 Capture 찾기. 이름이 안 맞으면 Avatar Live 송신 이름을 OBS 소스에서 다시 선택하세요. |
| **OBS에 NDI Source가 없어요** | [DistroAV 공식 릴리스](https://github.com/DistroAV/DistroAV/releases)를 설치하고 요구되는 NDI Runtime도 설치하세요. OBS를 재시작하고, 기존 OBS-NDI와 충돌하는지 확인합니다. **NDI 출력은 Basic도 사용 가능합니다.** |
| **NDI 소스가 검게 보이거나 안 잡혀요** | Avatar Live 출력 → NDI 켬 → 두 PC가 서로 통신 가능한지 확인 → Windows 방화벽 → NDI Tools의 Studio Monitor에서 검색 → OBS의 송신 이름/알파 옵션을 점검합니다. 게스트 Wi-Fi 기기 격리가 원인일 수 있습니다. |
| **Spout2에서 배경이 검게 나와요** | 스튜디오 배경 **투명** → 앱 출력 알파 → OBS 수신 플러그인의 **Composite with alpha** 등 합성 설정을 확인합니다. 단순 창 캡처의 검은 배경과 구분하세요. |
| **가상 카메라 설치 버튼을 눌러도 반응이 없어요** | Windows 관리자 권한이 필요한 설치일 수 있습니다. 프로그램 재실행 → 설치 폴더 **VirtualCamera/Install.bat** 확인 → 설치 후 Discord/Zoom 완전 재시작 → 장치 목록의 **Avatar Live Camera** 선택. |
| **인터넷의 친구가 원격 세션에 못 들어와요** | 방장 서버 ON → 같은 v2.0.0 → 포트 기본 **47700** → TCP·UDP 둘 다 공유기 포트포워딩 → Windows 방화벽 허용 → 공인 WAN IP인지(CGNAT 아님) 확인 → **외부 네트워크**에서 재시험. 같은 LAN이라면 포트포워딩 없이 내부 주소로 시험하세요. |
| **다른 참가자가 대체 아바타로 보여요** | 참가자의 **내 아바타 데이터 보내기** 동의 여부와 재배포 허용 에셋인지 확인합니다. 동일한 합법적 VRM을 소유했다면 로컬 Vrm 폴더에 넣고 **다시 찾기**를 누르세요. 파일 추출/재배포로 해결하지 마세요. |
| **카메라가 아바타를 이상한 방향에서 촬영해요** | [스튜디오 카메라의 위치/회전 기준](08-scene.md#대상에-고정--대상-따라-회전-차이를-실제로-이해하기)을 확인합니다. **대상에 고정**은 렌즈를 얼굴로 향하게 하는 옵션이 아닙니다. **대상 응시**나 **화면 구도**와 함께 설정하세요. |
| **iPhone이 연결인데 얼굴이 안 움직여요** | 첫 유효 얼굴 데이터 이후 약 **3초** 보정을 기다린 뒤 원본 앱의 실제 추적 상태를 확인합니다. 반복되거나 멈춘 트래킹 데이터를 정상 얼굴 움직임으로 오인하지 마세요. 장치 재연결/AFK 설정도 확인합니다. |
| **웹캠 팔·손이 뒤틀려요** | 동작 → 웹캠 팔을 **이전 방식**으로 바꿔 1.1.6에 가까운 동작을 비교하고, 실험적 손 거리/깊이 추정을 끄고, 팔 스무딩을 지나치게 높이지 않았는지 확인합니다. |
| **SteamVR 트래커 자세가 어긋나요** | 먼저 SteamVR 자체에서 HMD/트래커 위치와 보정 상태를 확인한 후 Avatar Live의 각 부위 입력 매핑과 전신 캘리브레이션을 다시 합니다. |
| **녹화·멀티뷰 켜면 느려져요** | 불필요한 별도 Spout2 송신자, 멀티뷰 칸 수/갱신률, 볼류메트릭/HBAO, 출력 FPS·해상도를 하나씩 낮추며 OBS 최종 화면을 비교합니다. |

**해결되지 않으면** 설정 → 진단 → **오류 리포트 보내기**에서 발생 직전의 행동, 사용 기기와 아바타 종류, 앱 버전(v2.0.0 / v45), 어떤 항목을 변경했는지 적어 보내 주세요. 자동 보고가 아니라 사용자가 전송을 선택하는 방식입니다. 자세한 송출 연결 절차는 [출력·원격 세션](09-output.md)을 참고하세요.

> 💡 해결되지 않는 버그나 문제는 **설정 › 진단 › 오류 리포트 보내기**로, 필요한 기능이나 개선 사항은 **설정 › 정보 › 개선 사항 보내기**로 알려 주세요.

## 시작 · 설치

| 증상 | 해결 방법 |
|---|---|
| "Windows의 PC 보호" 창 | **추가 정보 → 실행** |
| "Avatar Live 파일이 변경되었습니다" | BOOTH에서 받은 원본으로 다시 설치해 주세요. 아바타와 설정은 그대로입니다. |
| 시작이 잘 안 됨 | **Shift**를 누른 채 실행해서 안전 시작 |

## 아바타

| 증상 | 해결 방법 |
|---|---|
| 일부가 분홍색으로 보임 | VRChat 업로드가 정상인지 확인한 뒤 다시 내보내기 |
| 아바타가 보이지 않음 | 뷰의 빈 곳을 더블클릭 |
| 자세가 굳거나 머리카락이 엉킴 | 위쪽 **⟲** |
| 아바타 효과음이 들리지 않음 | 아바타 효과음은 재생되지 않습니다. |

## 웹캠 · 얼굴

| 증상 | 해결 방법 |
|---|---|
| 카메라가 켜지지 않음 | 다른 앱이 카메라를 쓰고 있는지 확인 |
| 표정이 작거나 크게 나옴 | **자동 얼굴 설정**을 다시 하거나 **얼굴 조정** |
| 아바타가 옆을 봄 | **정면 보정** |
| 윙크가 안 됨 | 깜빡임 방식을 **따로**로 |
| PC가 무거움 | 트래킹 품질을 **균형**이나 **절약**으로 |
| 손 · 손가락이 떨림 | **장치 › 트래킹 소스 › 손 떨림 보정**을 높이기 |
| 아바타가 움직이지 않음 | **장치 › 트래킹 소스**에서 부위의 소스가 쓰지 않는 장치(VMC 등)로 되어 있지 않은지 확인 |
| VMC로 받은 자세가 어긋남 | **VMC 설정**에서 **T자세** 또는 **정렬** |

## 출력 · 화면 공유

| 증상 | 해결 방법 |
|---|---|
| OBS에 Spout2 소스가 없음 | OBS에 Spout2 플러그인 설치 |
| OBS에서 배경이 검게 보임 | 배경을 **투명**으로, OBS에서 **Composite with alpha** 선택 |
| Discord 목록에 없음 | **화면 공유**를 켠 뒤 **애플리케이션** 탭 확인 |
| 게임이 검게 보임 | 게임을 창 모드로 |
| "Avatar Live Basic" 글씨 | Basic 워터마크입니다. Pro에서는 표시되지 않습니다. |

## 1.1.5 이후 확인할 문제

| 증상 | 해결 방법 |
|---|---|
| 추적이 끊겨도 AFK 자세가 적용되지 않음 | 동작 › 몸의 추적 상실 대기·전환 시간을 확인하고, [대기 자세](11-pro-features.md)를 지정했는지 확인 |
| iPhone 미러 모드에서 윙크 좌우가 반대 | 1.1.4 이상으로 업데이트하고 미러 스위치를 확인 |
| iPhone 단독 상태에서 팔이 책상 자세로 내려가지 않음 | 동작 › 손 · 책상과 팔의 추적 소스를 확인. 전신 추적은 웹캠 또는 VMC 필요 |
| 손을 앞으로 뻗으면 팔이 떨림 | 실험적 손 깊이 추정을 OFF로 변경하고 웹캠 보정 확인 |
| 원하는 설정을 찾지 못함 | 상단 돋보기에서 AFK, 미러, Spout2, 언어 등 검색 |
| 버그가 재현되지만 원인을 모르겠음 | 설정 › 진단 › 오류 리포트 보내기로 재현 방법과 로그 전송 |

## 지원 범위

| | 내용 |
|---|---|
| ✅ VRChat 아바타 | Expression 메뉴, 애니메이터, PhysBone, Contact, Constraint, Eye Look, LipSync |
| ✅ 제작 도구 | NDMF · Modular Avatar · VRCFury를 쓴 아바타 |
| ✅ 셰이더 | Poiyomi, lilToon 등 |
| ✅ 얼굴 | 아바타 설정을 따름: VRCFaceTracking, ARKit 52개 쉐이프키(Perfect Sync), MMD 눈 모프 |
| ✅ 트래킹 | 웹캠(얼굴 · 팔 · 손 · 손가락), iPhone(iFacialMocap · FaceMotion3D), VMC(부위별: 팔 · 손 · 손가락 · 몸 · 머리 · 눈) |
| 🧪 실험적 기능 | Ultraleap, OSC, VMC 출력, 혀 · 볼 카메라 감지 |
| ⚠️ 지원하지 않음 | 아바타 효과음, AudioLink, 미러 감지, VRM 파일, Live2D, macOS · Linux |

웹캠(전신 · 손가락 관절 포함), iPhone, VMC 입력은 실제 장비로 확인했습니다. 실험적 기능은 정상적으로 동작할 것으로 예상하지만, 아직 개발자 환경에서 모든 장치와 앱으로 테스트하지는 못해 앱에 **실험적**으로 표시해 두었습니다. 써 보시고 문제가 있으면 **오류 리포트 보내기**로 알려 주세요.

## 자주 묻는 질문

**VRChat 계정이 필요한가요?**
필요하지 않습니다. Avatar Live는 VRChat과 통신하지 않습니다.

**방송에 써도 되나요?**
방송, 영상 공개, 상업적 이용에는 **Pro**를 이용해 주세요. 친구와의 비공개 Discord 공유는 Basic으로도 할 수 있습니다.

**키보드 입력이 기록되나요?**
기록되지 않습니다. 책상 손 동작은 입력한 글자를 저장하거나 전송하지 않습니다.

**아바타 파일을 다른 사람에게 줘도 되나요?**
아바타와 의상 제작자의 이용 약관을 따라 주세요.
