# 6. 设备

## v2.0.0：每个设备具体控制哪个部位？

![v45 设备界面](img/v45-input.png)

追踪来源可以**按身体部位分别选择**，例如 iPhone 控制面部、摄像头控制手臂、VMC 接收骨盆和腿部追踪。如果某个部位意外保留了没有信号的 VMC 来源，即使摄像头已连接该部位也可能不动。

| 选项 | 调整后的实际效果 |
|---|---|
| **摄像头质量／平衡／节能** | 提高质量可能增加 CPU 占用；节能降低负担但快速手指或身体动作可能不够准确。 |
| **手部防抖/平滑** | 提高可减少细小抖动，但手快速移动时跟随更慢；降低则更敏捷但较容易抖。 |
| **摄像头全身追踪** | 尝试跟随可见的躯干与腿。桌下看不见的腿可能使用推测或静态姿势。 |
| **手指关节追踪** | 跟随每节手指的弯曲与展开；手太小或被遮挡可能导致追踪不稳定。 |
| **iPhone 面部输入** | 通过 iFacialMocap/FaceMotion3D 获取表情与头部；第一次有效面部数据约 3 秒后进行初始校准，请短暂正对镜头。 |
| **VMC 各部位** | 选择外部追踪器或手套的数据，检查实际动作与 T Pose 对齐，不要只看连接数量。 |
| **SteamVR** | 连接头显、手柄与身体追踪器，应先确认 SteamVR 已正确追踪，再进行程序内全身校准。 |
| **话筒噪声门** | 提高阈值可减少键盘声导致的口型动作，但太高也可能忽略轻声说话。 |

![v45 高级追踪设置](img/v45-devices-advanced.png)

建议按**设备连接 → 各部位来源 → 正面/T-Pose 校准 → 平滑与丢失追踪恢复 → 实际输出检查**的顺序操作。VRM 0.x/1.0 可直接导入，但部分不受支持的 VRM 0.x 着色器无法加载。与他人会话时也必须遵守模型授权。

## 摄像头与麦克风

<div class="shot" markdown="1">

![设备页面](img/devices.png)

- 打开 **摄像头** 开关，即开始面部和手部追踪。
- 在摄像头列表中选择要使用的摄像头。
- **正面校准** — 将当前的面部朝向设为正面。
- **追踪质量** — 与游戏同时使用时，建议选择 **均衡** 或 **节能**。
- 打开 **麦克风** 开关后，说话时嘴巴就会动。
- **噪声门** — 让嘴巴不会因键盘声等杂音而动。
- **检测背景噪声** — 保持安静时点击此按钮，即可自动设定噪声基准。

</div>

## 追踪来源

<div class="shot" markdown="1">

![追踪来源](img/sources.png)

- 为面部、嘴、头部、眼睛、手臂、手、手指、身体分别选择用什么来驱动。
- 每个部位都可以混用 **摄像头**、**iPhone**、**VMC**、**Ultraleap**（手）。例如，面部用 iPhone，身体用全身追踪器，手用摄像头。
- **面部引擎** — 选择摄像头引擎或面部应用（iPhone · VMC）。各设备的设置会显示在使用该设备的部位下方。
- 将 **嘴** 设为 **面部 + 麦克风** 后，说话时跟随声音，不说话时跟随嘴形。
- **手部防抖** — 静止时让手和手指不会抖动。

</div>

## 全身 · 手指关节（摄像头）

- 将 **身体** 设为摄像头后，会出现 **全身** 开关。开启后会跟随摄像头中可见的躯干和腿部，旁边会显示 **坐姿 · 站姿 · 腿部追踪 · 腿部推定**。
- 在桌前等看不到腿部时，仅凭肩部动作也能让上半身倾斜和转动。看不到的腿部保持角色自身的姿势。
- 将 **手指** 设为摄像头后，会出现 **手指关节追踪** 开关。开启后，摄像头会跟随每个手指关节的弯曲、张开以及拇指的动作。

## 通过 VMC 接收（全身追踪器 · 手套 · 其他应用）

<div class="steps" markdown="1">

1. 在发送端应用（全身追踪器应用、手套应用、动作捕捉应用等）中开启 VMC 发送，并发送到本机。
2. 在 **追踪来源** 中，将要通过 VMC 接收的部位的来源选为 **VMC**。其他部位可以继续使用摄像头 · iPhone。
3. 在 **VMC 设置** 中确认接收的骨骼数量以及数据是否传入。
4. 姿势有偏差时，点击 **T 姿势** 或 **对齐**。用 **重置** 恢复原状。

</div>

- 手指会如实反映每个关节的旋转、张开，乃至拇指的动作。
- 通过 VMC 接收手臂时，如果输入中断，手臂会回到桌面（键盘 · 鼠标）姿势。

> 💡 摄像头（含全身 · 手指关节）、iPhone、VMC 输入已用实际设备确认。标有 **实验性** 的功能（Ultraleap、OSC 等）预计可以正常运行，但尚未在开发者环境中使用所有设备和应用进行测试。如有问题，请通过 **设置 › 诊断 › 发送错误报告** 告诉我们。

## iPhone镜像与追踪丢失

- iFacialMocap镜像模式会正确交换眨眼等左右表情通道。若角色闭错眼睛，请检查镜像设置。
- 当iPhone通过trackingStatus报告面部追踪丢失时，可以切换到指定的AFK姿势。恢复时间在动作 › 身体调整。
- 单纯使用iPhone面部追踪不会自动得到全身数据。没有摄像头全身数据时也能使用桌面模式的手臂休息姿势；全身动作需要摄像头或VMC输入。

## 实验性的摄像头手部深度估算

动作 › 手 › 摄像头伸手中的深度估算仍在测试，可能导致手臂或手腕扭曲、抖动。普通使用建议OFF。参见[动作说明](07-motion.md)。

## 用 iPhone 进行面部追踪（iFacialMocap · FaceMotion3D）

<div class="steps" markdown="1">

1. 将 iPhone 和电脑连接到同一个 Wi-Fi。
2. 在 **面部引擎** 中选择面部应用 **iFacialMocap** 或 **FaceMotion3D**，然后 **复制** **本机地址**。
3. 在 iPhone 的 iFacialMocap 应用中，点击齿轮 › **Destination IP address**（目标 IP 地址），输入该地址。使用 FaceMotion3D 时，请在应用的连接设置中设为发送到本机地址。
4. 打开开关后，iPhone 的表情就会应用到角色上。表情如何呈现取决于角色自身的设置（参见 [表情的驱动方式](07-motion.md#表情的驱动方式)）。
5. 无法连接时，点击 **测试连接**，确认是否有数据传入。

</div>

> 💡 **iPhone地址（可选）** 栏可以留空。仅在 iFacialMocap 应用中不使用 Destination IP address 时才需要填写。

> 💡 开启 **断开时由摄像头接替** 后，iPhone 连接断开时，摄像头会暂时代为追踪。
