# 10. 设置

## 常规

| 项目 | 作用 |
|---|---|
| **启动时打开菜单** | 关闭后将不显示 UI 启动 |
| **重置** | 将追踪、手、PhysBone 等恢复到初始状态 |
| **全部重置** | 连同参数、角色位置、姿势、相机一起恢复到初始状态 |

## 快捷键 · 快捷操作

### 全局（全局快捷键）

在游戏中或 Avatar Live 位于后台时也能使用的按键。不会阻止其他程序的按键输入。

1. **+ 添加快捷键**
2. 选择动作：角色菜单 · 手势 · 相机视图 · 已保存的视图 · 追踪重置 · 灯光预设 · PhysBone 重置 · 全部重置
3. 点击 **设置按键…**，然后按下想要的组合键

- 菜单按钮和手势可以选择 **按住时** / **按下切换**。
- **F1** 不能单独使用（专用于纯净视图）。

### 快捷操作

以按钮形式放置与全局快捷键相同的动作。请参阅 [第 5 章](05-avatar-menu.md#快捷操作)。

## 设置文件

| 项目 | 作用 |
|---|---|
| **打开文件夹** | 打开设置文件夹 |
| **重置应用设置** | 将应用设置恢复为初始状态（每个角色的设置和设备设置保留，快捷键和快捷操作会被清除） |

## 许可证

显示当前版本和许可证 ID。

| 按钮 | 作用 |
|---|---|
| **输入其他代码** | 切换到其他许可证 |
| **升级到 Pro**（Basic 时） | 再购买一次 Basic 并输入即可升级为 Pro（2 个 Basic = Pro） |
| **输入购买的代码**（试用期间） | 用购买的许可证取代试用版 |
| **立即确认** | 重新确认许可证 |
| **在 BOOTH 购买** | 购买 Pro |

| **打开日志文件夹** | 打开日志文件夹 |
| 查看日志 | 确认错误和警告 |

## 更新

| 项目 | 作用 |
|---|---|
| **立即检查** | 检查新版本 |
| **下载** | 下载新版本 |
| **重新启动并安装** | 立即安装 |
