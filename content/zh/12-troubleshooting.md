# 12. 故障排除

> 请先查看 **设置 › 诊断**，如果仍未解决，请通过 **发送错误报告** 告知我们。
> 如果因设备问题无法启动，请尝试 **按住 Shift 运行**（安全启动）。

## 启动与安装

| 症状 | 解决方法 |
|---|---|
| “Windows 已保护你的电脑”窗口 | **更多信息 → 仍要运行** |
| “Avatar Live 的文件已被更改” | 使用从 BOOTH 下载的原始文件重新安装（角色和设置会保留） |
| 无法激活 | 确认网络连接后重试 |
| 运行后只有窗口被调到前台 | 程序已在运行（请查看托盘） |

## 角色

| 症状 | 解决方法 |
|---|---|
| 部分显示为粉色 | 确认能否正常上传后重新导出 |
| “它由更新版本的导出器制作” | 更新 Avatar Live |
| 头和手不动 | 确认是否为人形（Humanoid）角色 |
| 角色音效不响 | 不会播放角色音效 |
| 看不到角色 | 双击视图空白处，或点击场景工具 **⌂** |
| 姿势僵住、头发缠在一起 | 顶部 **⟲ 重置** |

## 摄像头与面部

| 症状 | 解决方法 |
|---|---|
| 摄像头“失败” | 确认是否有其他应用正在使用摄像头 |
| 摄像头画面全黑 | 确认镜头盖和 Windows 摄像头隐私设置 |
| 表情过小 / 过大 | 重新进行 **自动面部设置**，使用 **面部调整** |
| 角色看向侧面 | **正面校准** |
| 无法眨单眼 | 将眨眼模式设为 **独立** 或 **智能** |
| 左右相反 | **镜像** |
| CPU 占用高 | 将追踪质量设为 **均衡** 或 **节能** |

## 麦克风

| 症状 | 解决方法 |
|---|---|
| “无信号” | 在 Windows 设置 › 隐私 › 麦克风 中允许桌面应用 |
| “几乎无声” | 如果使用混音应用，请选择该应用的虚拟麦克风 |
| 噪声让嘴巴动起来 | **检测背景噪声** |
| 嘴巴动得不够 | **语音校准**、**灵敏度** |

## 输出

| 症状 | 解决方法 |
|---|---|
| OBS 中没有 Spout2 来源 | 在 OBS 中安装 Spout2 插件 |
| OBS 中背景为黑色 | 背景设为 **透明** + OBS 中选择 **Composite with alpha** |
| Discord 中没有虚拟摄像头 | 安装虚拟摄像头后完全退出 Discord 再重新启动 |
| 4K 以 1080p 输出 | 当前为 Basic 版（Pro 支持 4K） |
| “Avatar Live Basic”字样 | Basic 的水印（Pro 没有） |

## Discord 屏幕共享

| 症状 | 解决方法 |
|---|---|
| Discord 列表中没有 | 开启 **屏幕共享**，并查看 Discord 的 **应用程序** 标签页 |
| 黑屏 | 不以管理员权限运行 Avatar Live，将游戏设为窗口模式 |
| 没有声音 | 在 Discord 中开启声音，安装虚拟播放设备 |
| 声音听到两次 | 将 **Discord 音频设备** 设为不用于收听的设备 |
| 视频为黑色 | 受保护的视频（DRM）无法捕获 |

## 支持范围

| | 内容 |
|---|---|
| ✅ VRChat 角色功能 | Expression 菜单与参数、FX 等动画器、PhysBone、Contact、Constraint、Eye Look、LipSync |
| ✅ 制作工具 | 使用 NDMF、Modular Avatar、VRCFury 等的角色 |
| ✅ 着色器 | Poiyomi、lilToon 等 |
| ✅ 面部 | VRCFaceTracking、ARKit（Perfect Sync）、MMD 眼部变形 |
| ⚠️ 无法运行 | 角色音效、AudioLink、镜子和相机检测、Light Volumes、用户脚本 |
| 🧪 实验性功能 | Ultraleap、OSC·VMC、舌头与脸颊的摄像头检测 — 预计能够正常运行，但这些设备和应用尚未在开发者环境中测试 |
| ❌ 不支持 | VRM 文件、Live2D、macOS·Linux |

## 常见问题

**Q. 需要 VRChat 账号吗？**
不需要。Avatar Live 不与 VRChat 通信。

**Q. 可以用于直播吗？**
直播、公开发布视频和商业用途需要 **Pro**。

**Q. 键盘输入会被记录吗？**
不会。桌面手部动作不会保存、记录或发送输入的文字。

**Q. 可以把角色文件给别人吗？**
请遵守角色和服装制作者的使用条款。

**Q. 可以同时显示多个角色吗？**
一次只能显示一个。可在左上角的角色名称处切换。
