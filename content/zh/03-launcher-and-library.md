# 3. 开始界面与角色库

## v2.0.0：角色库的每项选择会改变什么

![v45 角色加载后](img/v45-menu.png)

- **导入 .vavatar**会注册由 Exporter 1.0.6 生成的文件，不是直接打开 Unity 项目。**导入 .vrm**支持 VRM 0.x / 1.0，但部分模型使用不受支持的着色器可能无法显示。
- **最近使用／文件夹／已导入**只改变角色库列表的筛选范围，不会自动改变追踪设备或广播摄像机。
- **默认／上一次／每次询问**决定启动时自动加载哪个角色。每次直播使用不同模型时建议开启“每次询问”。
- **启动时自动开启摄像头与麦克风**可能让其他视频会议应用无法使用设备。存在冲突时先关闭自动启动，进入应用后再手动开启。
- 切换角色后使用的是**该角色自己保存的**表情、姿势与编辑视角，不会把前一个模型的所有设置无条件复制过来。
- **多个角色 (Pro)**是让同一工作室同时存在多个模型，不等于只切换唯一角色。修改之前请先选中正确的模型。

**与会话不同：** 角色库原始文件保留在你自己的电脑中。[远程会话](09-output.md)的**发送我的角色数据**需要单独同意，在参与者电脑上使用会话专用的加密临时缓存，不会把别人原始资产永久加入你的角色库。

## 开始界面

![开始界面](img/launcher.png)

| 项目 | 作用 |
|---|---|
| **打开角色…** | 打开 `.vavatar` 文件。也可以拖放到窗口中。 |
| **最近 · 文件夹 · 已导入** | 显示最近打开的角色、角色文件夹中的角色和已导入的角色。 |
| **设为默认** | 让程序直接以此角色启动。 |
| **摄像头 · 麦克风** | 选择启动时一并开启的设备。 |
| **面部 · 手部** | 选择追踪方式。 |
| **启动设置** | 从每次询问 · 上次使用 · 默认角色中选择。 |
| **▶ 启动 Avatar Live** | 以所选角色启动。 |

> 💡 按住 **Shift** 运行，即可不使用摄像头 · 麦克风安全启动。因设备问题无法正常启动时，请试试这个方法。

## 运行中切换角色

<div class="shot" markdown="1">

![角色库](img/avatar-pop.png)

- 点击左上角的 **角色名称**，即可打开角色库。
- 在列表中点击角色，即可切换到该角色。
- 用 **添加角色文件…** 导入新角色。
- 已开启的摄像头和麦克风，切换后也会照常开启。

</div>

## 首次打开菜单

加载角色时会提前准备菜单布局，减少首次打开各菜单的卡顿。初次加载角色可能稍久一些。点击左上角的图标即可返回角色选择，而无须重启程序。

## 返回开始界面

点击左上角的 **标志**，然后选择 **重新启动**。
