# 角色菜单

使用服装、发型、表情等由角色制作人添加的功能。根据模型，菜单名称和项目会有所不同。

## 更换服装和表情

![带有普通表情按钮的子菜单](img/guide-avatar-menu.png)

| 操作 | 运行方式 |
|---|---|
| 开/关 | 按一次开启，再按一次关闭。主要用于更换服装或装饰。 |
| 按下按钮 | 仅在按下时有效。松开则取消。 |
| 圆形滑块 | 移动手柄以设置 0~100% 之间的数值。连接的颜色、大小、表情强度等会发生变化。 |
| 方向键 | 手柄可以左右、上下移动，同时调整多种表情或数值。 |
| 文件夹 | 打开子菜单。按返回键可回到上级菜单。 |

## 快速取用常用项目

![右键点击表情按钮打开的快速操作·快捷键·收藏菜单](img/guide-menu-context.png)

- 收藏夹：在菜单上方快速查找。
- 添加到快速操作：在底部工具栏创建一个执行按钮。
- 快捷键指定：使用键盘执行该项目。

在快捷键中，按住时按键松开就会取消，而切换模式则会保持，直到再次按下为止。

## 姿势与跟踪 (Pro)

![已保存的姿势和我的表情](img/guide-menu-poses.png)

1. 点击姿势图块以应用。
2. 点击姿势旁的相机图标展开追踪设置。
3. 分别开启或关闭面部、头部、手臂、手指、身体。

开启的部位会跟随我的动作，关闭的部位则保持已保存的姿势。例如关闭头部并开启面部时，只会移动表情而头部保持固定。

### 按姿势跟踪

![姿势卡片的部位追踪设置](img/guide-pose-tracking.png)

按姿势侧面的相机按钮可以分别开启或关闭面部、头部、手臂、手指和躯干。

- 点亮的部位：跟随我的动作。
- 熄灭的部位：保持储存的姿势。
- 例：关闭手臂，开启头部·面部时，会保持手臂姿势，同时头部和表情会移动。

## 基本姿势和待机姿势

![选择基本姿势和AFK姿势](img/guide-default-pose.png)

| 选择 | 使用时 |
|---|---|
| 基本姿势 | 通常不追踪部分的基准姿势。 |
| AFK 待机姿势 | 当失去追踪时使用的姿势。 |
| 待机表情 | 自动在离开时应用的表情。 |
| 桌面姿势 | 当手不出现在相机画面中时使用的手臂·手姿势。 |

转入待机姿势的时间在 [追踪丢失时](#追踪丢失时) 调整。

### 追踪丢失时

![追踪丢失与AFK切换时间](img/guide-motion-afk.png)

AFK是在脸部和身体追踪都丢失时使用的待机状态。在菜单 → 基本·AFK姿势中设置时间。

| 时间 | 延长会怎么样 |
|---|---|
| 等待时间 | 即使输入暂时中断，也会保持姿势并多等待。 |
| 切换时间 | 缓慢过渡到待机姿势。 |
| 恢复时间 | 输入恢复后缓慢恢复正常动作。 |

待机时使用的姿势和表情可在[基本姿势与待机姿势](#基本姿势和待机姿势)中选择。

## 我的表情

通过创建新表情调整面部形状并保存，或加载 `.anim` 表情文件。创建的表情可通过图块应用，并通过右键连接至快速操作或快捷键。

![自制表情与添加表情](img/guide-my-expression.png)

1. 点击“创建新表情”。
2. 调整面部形状键以形成表情。
3. 通过预览强度从 0%（无表情）到 100%（完整表情）查看效果。
4. 保存。
5. 点击“我的表情”图块以应用。

也可以通过加载 .anim 文件添加 Unity 表情动画。动画文件会随时间改变表情，是否循环由文件设置决定。

### 使用.anim转移到其他模型

右键点击我的表情图块，选择 **导出 .anim…** 保存文件。在具有相同形态键的其他模型上使用 **导入 .anim** 添加相同表情，也可在Unity中使用。动态表情保留曲线和循环。眨眼与眼睛、嘴部跟踪暂停不保存在文件中，请在目标模型上设置。

## 手势

![左手和右手手势设置](img/guide-gestures.png)

选择左手和右手的拳头、剪刀、张开等手势。如果角色手型与表情绑定，表情也会随手势变化。当通过摄像头启用手势时，将使用真实手型。

## 恢复

在角色参数 → 点击恢复到默认值，服装·表情等菜单的数值将恢复为角色的默认值。

## 层级结构和形态键

- 层级结构：以树状显示角色部件。可通过勾选控制部件的开关。
- 眼睛图标：保持部件运行，但只在屏幕上隐藏。
- 网格：搜索用于绘制外观的部件。
- 形状键：可以直接调节脸部或身体的变形量。直接设定的数值可能优先于追踪。
