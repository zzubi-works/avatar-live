# 5. 角色菜单

在 **菜单** 页面中，可以直接使用在 VRChat 中使用的 **角色自带的 Expression 菜单**。服装、发型开关，表情按钮，Radial 和 Puppet 的运行方式与 VRChat 相同。

## Expression 菜单

![角色菜单](img/menu.png)

| 类型 | 作用 |
|---|---|
| **Toggle** | 开启 / 关闭 |
| **Button** | 按住期间开启 |
| **Sub Menu** | 打开子菜单（用 **返回** 回到上一级） |
| **Radial Puppet** | 用滑块设定数值 |
| **Two Axis / Four Axis Puppet** | 用方向盘设定方向 |

### 右键菜单项

| 项目 | 作用 |
|---|---|
| **添加到快捷操作** | 将此项设为工具栏按钮 |
| **设置快捷键…** | 为此项设置快捷键 |
| **收藏** | 添加到菜单上方的收藏 |
| **参数信息** | 查看此项的参数 |

## 收藏

可以在菜单最上方直接使用已收藏的项目。子菜单中的项目也可以直接操作。

## 手势

选择左手 / 右手手势（**自然 · 握拳 · 张开 · 指向 · 胜利 · 摇滚 · 手枪 · 点赞**），触发角色的手势表情。

- **用摄像头手形触发手势** — 开启后，摄像头追踪到的手形会成为手势。

## 角色参数

- **恢复默认值** — 将所有菜单值恢复为角色的默认值（与 VRChat 的 Reset Avatar 相同）。

服装状态等在 VRChat 中会被保存的值，下次运行时也会保留。

## 快捷操作

将常用动作做成 **按钮** 或 **按键**。

**添加位置**
- 右键菜单项 → **添加到快捷操作**
- 设置 › **快捷键 · 快捷操作** › **添加快捷操作**

**可加入的动作**：角色菜单项 · 手势 · 相机视图 · 已保存的视图 · 追踪重置 · 灯光预设 · PhysBone 重置 · 全部重置

**右键按钮**：**重命名** · **显示位置**（顶部 HUD / 底部工具栏 / 仅快捷键）· **设置快捷键…** · **移除**

## 重置与全部重置

| | **重置** | **全部重置** |
|---|---|---|
| 执行 | 点击顶部 **⟲**，设置 › 常规 | 右键 ⟲，设置 › 常规 |
| 恢复的内容 | 追踪、手部姿势、按下的按钮、PhysBone、Contact | 以上内容 + 所有参数（包括服装）、角色位置和大小、姿势、相机 |
| 保留的内容 | 服装和开关、灯光、相机 | 物体、已保存的姿势和表情、设置 |

直播中角色僵住或头发缠在一起时，请点击 **⟲ 重置**。
