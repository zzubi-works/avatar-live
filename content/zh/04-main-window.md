# 主屏幕

从左侧选择设置，在中间查看并调整角色。

![主屏幕](img/guide-main.png)

## 左侧菜单

| 菜单 | 可进行的操作 |
|---|---|
| 菜单 | 应用服装、表情、手势以及保存的姿势。 |
| 设备 | 连接摄像头、麦克风、iPhone、追踪器。 |
| 动作 | 调整面部、身体和手部的移动幅度与流畅度。 |
| 工作室 | 布置背景、灯光、道具、角色、拍摄摄像机。 |
| 输出 | 连接OBS、虚拟摄像头、屏幕共享、远程联机。 |
| 设置 | 更改窗口、性能、语言、快捷键、更新。 |

## 使用设置面板

- 卡片标题：点击展开或折叠详细设置。
- 开关：开启或关闭该功能。与展开标题无关。
- 固定：即使在面板外点击，设置面板也不会折叠。
- 数字：可以直接输入或通过旁边的滑块调整。
- 拖动卡片标题：将常用卡片移动到上方。
- 顶部放大镜：搜索设置名称，点击结果即可直接跳转。

## 摄像机工具栏

![底部摄像机工具栏与构图设置](img/guide-camera-toolbar.png)

| 项目 | 更改内容 |
|---|---|
| 脸部·上半身·全身 | 将选定的虚拟形象显示在屏幕上的对应大小。 |
| 已保存视图 | 返回保存的位置和方向。 |
| 保存视图 | 保存当前看到的构图。 |
| 锁定相机 | 锁定构图以防鼠标改变。虚拟形象仍然会移动。 |
| 视野角度 | 降低时虚拟形象看起来更大，提高时周围环境看得更广。 |
| 固定·自由·轨道 | 改变用鼠标移动工作屏幕的方式。 |

在设置面板上滚动滚轮可以滚动设置。在虚拟形象可见区域滚动时会改变相机距离。

## 工作屏幕与直播屏幕

| 屏幕 | 观看者 | 移动时 |
|---|---|---|
| 场景视图 | 我正在编辑的工作屏幕 | 我的操作视点会改变。如果场景视图正在直播，广播也会跟着改变。 |
| 工作室相机 | 选定拍摄相机的观众屏幕 | 根据该相机的设置，构图会改变。 |

如需在保持直播构图的同时编辑灯光或道具，请选择[工作室相机](08-scene.md#摄像机-pro)作为直播目标。

## 常用操作

| 操作 | 结果 |
|---|---|
| F1 | 隐藏菜单。再次按下则显示。 |
| Ctrl+Z | 撤销支持的编辑操作一步。 |
| 顶部重置 | 恢复跟踪、手部姿势和物理运动。 |
| 左下角电源 | 退出程序。 |

包括更换衣服和位置的全部重置适用范围更大。如果只是头发短暂打结，请先使用普通重置。
