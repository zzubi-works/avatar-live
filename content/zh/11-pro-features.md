## 摆姿势

直接移动骨骼来摆出角色姿势并保存。

**开始**：场景 › **摆姿势** › **摆姿势模式**，或左侧场景工具中的人形图标

| 操作 | 作用 |
|---|---|
| 点击骨骼（Ctrl：多选） | 选择骨骼 |
| 拖动骨骼 | 移动（拖动手或脚会带动整条手臂或腿） |
| 拖动圆环 | 旋转（Ctrl：15° 步进） |
| **Ctrl + Z / Ctrl + Y** | 撤销 / 重做 |
| **恢复原状** | 将所选骨骼恢复为原来的动作 |
| **左右** | 左右翻转 · 把左侧复制到右侧 · 把右侧复制到左侧 |
| **全部重置** | 恢复初始姿势 |
| **显示手指骨骼** | 显示手指骨骼 |

> 关闭摆姿势模式后姿势会解除。请先保存。

### 姿势

| 项目 | 作用 |
|---|---|
| **+ 添加姿势** | **保存当前姿势** · **导入 .anim 文件…** · **保存为桌面姿势（手臂和手）** |
| 点击姿势 | 应用 / 解除 |
| **编辑姿势** | 修改已保存的姿势 |
| **重命名 / 用当前姿势覆盖 / 删除** | 管理姿势 |
| **设为休息姿势（全身）** | 看不到面部时使用此姿势 |
| **设为桌面姿势（手臂和手）** | 用作桌面手部姿势 |

在角色菜单的 **姿势** 卡片中也可以一键开启或关闭姿势。

## 物体

将文字、图片、形状、3D 模型附加到场景或角色上（帽子、头顶文字、椅子、桌子等）。

| 项目 | 作用 |
|---|---|
| **基础环境（地面网格）** | 显示地面 |
| **+ 添加物体** | **文字** · **图片文件…** · **3D 模型（.vprop）…** · **形状**（立方体·球体·圆柱·胶囊·板） |
| 显示开关 · ⋯ | 隐藏，重命名 · 复制 · 回到初始位置 · 删除 |
| **颜色** | 更改颜色 |
| **附着位置** | 固定在场景 / 头部 / 胸部 / 躯干 / 左手 / 右手 |
| **平滑跟随** | 稍微延迟地跟随骨骼 |
| **保持比例 / 大小** | 调整大小 |
| **始终显示在最前 / 始终朝向镜头** | 显示方式 |
| 文字：**字体 · 粗体 · 斜体 · 描边 · 背景板** | 装饰文字 |

在视图中用场景工具（移动、旋转、缩放）移动物体。双击文字即可直接编辑。

### 制作 3D 模型

在 Unity 中通过 **Curious Bobby → Prop Exporter** 将 GameObject 或预制体导出为 **.vprop**。模型的摆动骨骼和动画也会一起运行。

## 屏幕共享更多来源

在 输出 › 屏幕共享 › **更多来源** 中叠加更多窗口或显示器（聊天窗口、音乐播放器等）。

| 项目 | 作用 |
|---|---|
| **添加来源** | 添加窗口或显示器 |
| 👁 | 显示 / 隐藏 |
| ⋯ | 前移 · 后移 · 回到初始位置 · 删除 |

## 我的表情

用角色的形态键直接制作表情。

1. **新建表情**
2. **搜索形态键** → 用 **+** 添加 → 调整强度
3. **显示此表情时**：不眨眼 · 暂停眼部追踪 · 暂停嘴部追踪
4. **保存**

- 用 **导入 .anim** 也可以使用在 Unity 中制作的表情动画。
- 在角色菜单或场景的 **我的表情** 卡片中点击即可开启或关闭。

## 自动表情

微笑或惊讶时，角色会自动做出预先设定的表情。

| 项目 | 作用 |
|---|---|
| **自动表情** | 开启 / 关闭 |
| 检测的表情 | 微笑 · 惊讶 · 生气 · 悲伤 · 眨眼（左/右）· 噘嘴 · 困倦 |
| **显示的表情** | 从我的表情 · 手势 · 角色菜单项 · 表情剪辑中选择对应 |
| **阈值** | 表情要多明显才会触发 |
| **时机** | 平滑 · 开始延迟 · 至少保持 |

**表情剪辑** 是在导出器中导出时加入的额外表情（[第 2 章](02-avatar-exporter.md#导出)）。
