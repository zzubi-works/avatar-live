# 1. 快速上手

## 准备事项

| 项目 | 要求 |
|---|---|
| 操作系统 | **Windows 10 / 11（64 位）** |
| 显卡 | 支持 **DirectX 11** 的 GPU |
| 摄像头 | 普通彩色摄像头（用于面部、手臂、手部追踪） |
| 麦克风 | 用于口型同步（可选） |
| 网络 | 激活和许可证确认时需要 |
| 角色 | VRChat 角色的 **Unity 项目**（Unity 2022.3.22f1）— 在 [第 2 章](02-avatar-exporter.md) 中导出为 `.vavatar` |
| 可选设备 | Leap Motion / Ultraleap 手部追踪器、iPhone（iFacialMocap） |

## 选择版本

| | Basic | Pro |
|---|---|---|
| 用途 | 个人使用 | **直播、公开发布视频、商业用途** |
| 输出 | 最高 1080p，有水印 | 最高 4K，无水印 |
| 摆姿势 · 物体 · 屏幕共享更多来源 | — | ✅ |

> 直播（Live Streaming）、上传视频等 **公开或商业用途需要 Pro**。详情请参阅 [第 13 章](13-license.md)。

## 安装

1. 在 BOOTH 购买记录中下载 Avatar Live 的 ZIP 文件。
2. 将其 **解压** 到任意文件夹。解压后的文件夹即为安装文件夹。
3. 运行 `AvatarLive.exe`。

> **如果出现“Windows 已保护你的电脑”窗口**，请点击 **更多信息 → 仍要运行**。

> ⚠️ **请勿更改安装文件夹中的文件，也不要放入其他程序。** 与原始文件不一致时 Avatar Live 将无法启动。此时请使用从 BOOTH 下载的原始文件重新安装（角色和设置会保留）。

## 产品激活

首次运行时会显示 **产品激活** 界面。

1. 在右上角选择语言。
2. 输入购买时收到的信息，然后点击 **激活**。
3. 显示“已激活。”即完成。

### 转移到其他电脑

- 许可证为 **一人一台设备**。
- 转移到其他电脑 **仅限一次**。转移后，之前的电脑将无法再使用，**之后无论任何情况都无法再次转移。**
- 请慎重决定要转移到的电脑后再进行操作。

## 首次直播前的步骤

1. **制作角色** — 在角色的 Unity 项目中导出 `.vavatar`（[第 2 章](02-avatar-exporter.md)）
2. **打开角色** — 在开始界面点击 **打开角色…** → **▶ 启动 Avatar Live**（[第 3 章](03-launcher-and-library.md)）
3. **开启摄像头** — **设备** → **摄像头** 开关（[第 6 章](06-devices.md)）
4. **开启麦克风** — **设备** → **麦克风** 开关
5. **匹配面部** — **动作** → **自动面部设置**（[第 7 章](07-motion.md)）
6. **选择背景** — **场景** → **背景**（[第 8 章](08-scene.md)）
7. **输出** — **输出** → Spout2 / 虚拟摄像头 / 屏幕共享（[第 9 章](09-output.md)）
8. **F1** — 隐藏全部 UI 的纯净画面

## 退出

- 窗口的 **X** 默认是 **最小化到托盘**。角色和输出会继续运行。
- 要完全退出，请 **右键托盘图标 → 退出**。
- 若要点击 X 直接退出，请在 设置 › 窗口 › **关闭按钮（×）** 中选择 **退出**。
